# Bridge

The Dashboard does not currently include a Bridge screen. This page exists so you can find out what is and is not available: cross-chain transfers cannot be started from the Dashboard today, and there is no `/bridge` page (opening `dashboard.qorechain.io/bridge` returns "not found").

:::caution Qualified status
The cross-chain bridge itself is still in testnet and being rolled out progressively. It is not yet a production mainnet system, and its chain routes are still pending on both networks. Do not rely on any route being live.
:::

## Innovations {#innovations}

There is nothing to use on the Dashboard yet, so there are no Dashboard innovations to list. How the chain validates cross-chain transfers is described in [Bridge Architecture](/architecture/bridge-architecture).

## How to use {#how-to-use}

You cannot start a bridge transfer from the Dashboard. For how cross-chain transfers are intended to work, read [Bridging Assets](/user-guide/bridging-assets) and [Bridge Architecture](/architecture/bridge-architecture). This page will describe the Dashboard flow once a Bridge screen ships.

## How to access {#how-to-access}

Not available. There is no route, no sidebar entry and no sign-in or network setting that turns it on.

## Where it is published {#where-published}

Nowhere on the Dashboard. A "Bridge" badge series exists on the Badges page for a feature that is not live; ignore it for now.

## Limits and known issues {#limits}

- No Dashboard Bridge screen exists on mainnet or testnet.
- An earlier preview was withdrawn.
- The bridge is a testnet and in-progress system; its routes are pending on both networks.
