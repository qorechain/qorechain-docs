# Bridge

The Dashboard does not currently include a Bridge screen. An earlier preview has been withdrawn, and cross-chain transfers cannot be started from the Dashboard today.

:::caution Qualified status
The cross-chain bridge itself is still in testnet and being rolled out progressively — it is not yet a production mainnet system, and its chain routes are still pending on both networks. Do not rely on any route being live.
:::

To understand how cross-chain transfers are validated, see [Bridge Architecture](/architecture/bridge-architecture) and [Bridging Assets](/user-guide/bridging-assets). This page will describe the Dashboard flow once a Bridge screen ships.
