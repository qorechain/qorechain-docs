# Depanare

Întrebări frecvente și remedieri rapide pentru aplicația și extensia QoreX.

| Simptom | Cauză / remediere |
|---|---|
| **„Securizează-ți mai întâi dispozitivul”** la onboarding | Configurează Face ID / o amprentă **sau o blocare a ecranului (PIN / model)** în setările sistemului, apoi revino. Un portofel poate fi creat doar pe un dispozitiv cu un factor de deblocare puternic. Pe Android, deblocarea facială 2D, de una singură, este o biometrie *slabă* - PIN-ul din spatele ei este cel care califică. |
| **Fereastra de conectare s-a închis** / „Acea încercare de conectare a expirat” | O încercare anterioară a fost abandonată - apasă din nou pe conectare. |
| **„Adaugă o passkey” lipsește** după conectarea cu Google / Dashboard | Comportament așteptat: passkey-urile se atașează doar conturilor cu cod pe e-mail (vezi nota din [Cont și Dashboard](/qorex/account-and-dashboard#sign-in)). |
| **„Handle-urile vin în curând”** | Registrul de @handle-uri este temporar inaccesibil. Portofelul tău nu este afectat; handle-urile se activează automat la revenirea acestuia. |
| **Extensie: plata unui @handle eșuează cu o eroare legată de căutare** | Remediat în extensia **0.3.7** și în cele ulterioare (fiecare magazin servește acum 0.3.8 sau o versiune ulterioară). Dacă extensia ta este mai veche, actualizeaz-o din pagina de extensii a browserului; până atunci lipește în schimb adresa `qor1…` sau folosește aplicația mobilă. |
| **Extensia nu are nicio modalitate de a revendica un @handle** | Comportament așteptat: revendicarea necesită un cont autentificat și se face în aplicația mobilă. Odată revendicat, îl poți plăti și rezolva din extensie. |
| **Un handle pe care am încercat să îl revendic este refuzat ca rezervat** | Numele care imită QoreChain (denumirile sale de brand sau cuvinte de încredere precum *official*, *support*, *airdrop*, *treasury*, inclusiv scrieri asemănătoare) sunt rezervate. Alege un alt handle. |
| **O aprobare spune că QoreX nu poate afișa cererea sau o refuză ca fiind ambiguă** | QoreX nu va afișa o cerere pe care nu o poate decoda sau ai cărei octeți pot fi citiți în două moduri (de exemplu un câmp repetat astfel încât un comision sau o sumă să se citească diferit pe ecran față de pe lanț). Nu căuta o soluție ocolitoare - site-ul trimite ceva nesigur sau neacceptat. |
| **QoreX avertizează că adresa unui handle s-a schimbat** | Comportament de securitate așteptat, nu o eroare - QoreX reține adresa la care a rezolvat un handle prima dată când l-ai plătit și semnalează o schimbare ulterioară în loc să o accepte în tăcere. Confirmă noua adresă printr-un canal separat cu destinatarul înainte de a continua. |
| **Trimiterea este refuzată pentru „mai mult decât soldul tău disponibil”** pe un cont cu vesting | O parte din soldul tău este încă blocată printr-un program de vesting. Doar partea **disponibilă** (afișată pe Acasă, Trimite și Detalii activ) poate fi trimisă; restul se deblochează treptat. |
| **O cerere din portofel spune că este „pentru testnet/mainnet, dar portofelul tău este pe…”** | Cererea (de exemplu, din Dashboard) vizează o altă rețea decât cea la care ești conectat în prezent. Comută tu însuți rețelele mai întâi, dacă asta ai intenționat - QoreX nu va comuta pentru tine. |
| **„Cod greșit sau QR deteriorat”** în timpul asocierii dispozitivului | Verifică din nou codul de 10 caractere (alfabetul omite caracterele care se confundă ușor: fără 0/O/1/I/L) și scanează din nou. Ambele artefacte sunt de unică folosință. |
| **Ecranul camerei spune că este necesară permisiunea** | iOS: Setări → QoreX → Cameră. Android: Informații aplicație → Permisiuni → Cameră. |
| **Extensie: niciun portofel la prima deschidere** | Extensia este un portofel **de sine stătător** - deschide fereastra pop-up și alege **Creează un portofel nou** sau **Importă o frază de recuperare**. Nu necesită aplicația mobilă. |
| **Trimiterea de la o adresă doar-citire este refuzată** | Acea adresă aparține altui portofel (eticheta arată căruia). QoreX poate semna doar pentru propriile conturi derivate - trimite din portofelul care o deține. |
| **Se afișează insigna testnet** | Setări → **„Folosește testnet (dezvoltatori)”** este activat. Dezactivează-l pentru a reveni la mainnet. |
| **Butonul de Swap este dezactivat** | Comportament așteptat deocamdată (Android) - Swap se activează automat odată ce lichiditatea din pool este disponibilă; nu este necesară nicio actualizare a aplicației. Fila Swap nu este afișată pe iOS, iar extensia nu are ecran de Swap. |
| **Am dezinstalat aplicația / am eliminat extensia și acum nu văd niciun portofel** | Seiful a existat doar pe acel dispozitiv sau în acel browser. Dacă ți-ai făcut backup la fraza de 24 de cuvinte, restaurează cu ea. Dacă ai configurat [recuperarea socială](/qorex/security-and-recovery#social-recovery), pornește o recuperare cu gardienii tăi. Fără niciuna dintre ele, portofelul nu poate fi recuperat - vezi [Fă backup acum](/qorex/security-and-recovery#back-up-now) pentru a proteja imediat orice portofel nou. |
| **Nu îmi găsesc cele 24 de cuvinte / aplicația nu mi le-a arătat niciodată** | Aplicația mobilă nu afișează fraza în timp ce creează portofelul. Deschide **Settings → Security → Reveal recovery phrase** și confirmă cu biometria sau cu PIN-ul dispozitivului, apoi notează cuvintele. În extensie, folosește **Reveal recovery phrase** din fereastra pop-up (este necesară parola ta). Dacă portofelul se află doar pe un telefon pe care l-ai pierdut deja, QoreChain nu îl poate recupera - vezi [Fă backup acum](/qorex/security-and-recovery#back-up-now). |
| **Un cont finanțat a dispărut din „Conturile tale”** | Nimic nu este pierdut - fiecare cont se re-derivă din fraza ta de recuperare, deci este o problemă de afișare, nu o pierdere de date. Aceasta a fost o eroare reală, acum reparată, în versiunile mobile de dinainte de **1.0.9**: o citire eșuată de moment din stocarea securizată a dispozitivului (cel mai probabil chiar la deblocare) putea afișa o listă de conturi scurtată. Actualizează QoreX (remedierea a apărut în 1.0.9 și în toate versiunile ulterioare); dacă ești deja la zi și acest lucru se întâmplă, închiderea și redeschiderea aplicației ar trebui să îl aducă înapoi - apăsarea pe „adaugă un cont” ar crea un cont **nou** în loc să restaureze cel lipsă, așa că evită acest lucru până când contul existent reapare. |
| **„Lane-ul EVM are nevoie de o fereastră de autorizare deschisă pentru acest cont. Deschide una aici mai întâi - MetaMask nu poate.”** (sau „Fereastra ta de autorizare EVM s-a epuizat”, sau „Acea fereastră de autorizare a fost refuzată”) | O tranzacție MetaMask / pe lane-ul EVM a fost refuzată deoarece contul nu are nicio fereastră deschisă (sau aceasta a rămas fără blocuri, tranzacții sau valoare). Deschide una la [Fereastra de acces EVM](/qorex/security-and-recovery#evm-window) (este pentru conturile în stil Ethereum, coin 60), apoi reîncearcă. Deschide-o *înainte* de a trimite - deschiderea unei ferestre avansează nonce-ul contului, așa că o tranzacție pregătită mai devreme eșuează cu „nonce too low”. Dacă contul tău nu are încă o cheie ML-DSA-87, QoreX îți spune să înregistrezi mai întâi una. |
| **„Această rețea are nevoie de un QoreX actualizat. Actualizează aplicația și încearcă din nou - nu a fost trimis nimic.”** | Rețeaua verifică o formă de semnare mai nouă decât cea produsă de versiunea ta. Actualizează QoreX din magazinul de aplicații și reîncearcă; nu a fost trimis nimic și nu s-a perceput niciun comision. |
| **„Prea multe tranzacții de la acest cont într-un timp scurt. Așteaptă un minut și încearcă din nou.”** | Rețeaua limitează câte tranzacții poate trimite un cont într-o perioadă scurtă. Așteaptă un minut. |
| **„Acea adresă nu poate primi transferuri obișnuite.”** | Rețeaua refuză transferurile simple către acea adresă (unele adrese de sistem sau de modul). Verifică destinatarul. |
| **„Nu ai suficient QOR deblocat pentru a plăti comisionul de rețea. QOR aflat în vesting nu poate plăti comisioane…”** sau **„Revendicarea necesită aproximativ … QOR deblocat”** | Revendicările și unstaking-ul își plătesc comisionul din soldul tău *deblocat* (înainte să ajungă recompensele). Trimite o sumă mică de QOR la acea adresă, apoi încearcă din nou. |
| **„Rețeaua a rămas fără gas înainte de a termina. Comisionul a fost perceput și nimic nu s-a mutat - recompensele tale sunt încă acolo.”** | Tranzacția a ajuns într-un bloc și a eșuat acolo. Încearcă din nou; comisionul încercării eșuate este consumat. |
| **„Unstaking-ul unei sume atât de mari ar coborî self-bond-ul validatorului tău sub pragul necesar de 100,000 QOR.”** | Se aplică doar operatorilor de validatori: pragul self-bond se aplică atât timp cât validatorul funcționează. Fă unstaking pentru mai puțin. |
| **„Account 'qor1…' does not exist on chain”** la trimiterea dintr-un cont restaurat din Dashboard sau MetaMask | Actualizează QoreX la versiunea curentă; contul este un cont în stil Ethereum (coin 60) - vezi [Restaurarea unei fraze din MetaMask sau Dashboard](/qorex/getting-started#restore-dashboard). Prima trimitere înregistrează și cheia ML-DSA-87 a contului respectiv (un mic comision suplimentar). |
| **Mi-am restaurat fraza și al doilea cont / fondurile mele lipsesc** | Restaurarea readuce doar **Account 1**. Apasă **Add an account** (și, pentru o frază folosită în MetaMask sau în Dashboard, **Add an Ethereum account (coin 60)**) în Settings → Your accounts - conturile se re-derivă la aceleași adrese. |
| **Extensie: „Wallets” spune că passkey-ul a fost dezactivat** | Adăugarea sau eliminarea unui portofel resigilează seiful și anulează deblocarea cu passkey (nu putea acoperi noul portofel). Reactivează-l din ecranul principal al ferestrei pop-up; Firefox nu oferă niciodată deblocare cu passkey. |
| **Nu a sosit nicio notificare push** | Notificările push sunt doar pentru mainnet și necesită notificări permise pentru QoreX în setările telefonului, plus comutatorul **Push notifications** activat (Home → clopoțel). Îți spune doar că a sosit QOR, nu și suma; lista **Notifications** din aplicație arată detaliile. |
| **Android: butonul Înapoi** | Înapoi te duce la ecranul anterior; pe Home închide aplicația. |
