# Bridge

Dashboard-ul nu include în prezent un ecran Bridge. Această pagină există pentru a putea afla ce este și ce nu este disponibil: transferurile cross-chain nu pot fi inițiate astăzi din Dashboard și nu există o pagină `/bridge` (deschiderea `dashboard.qorechain.io/bridge` returnează „not found").

:::caution Status calificat
Bridge-ul cross-chain în sine se află încă pe testnet și este lansat progresiv. Nu este încă un sistem de producție pe mainnet, iar rutele sale de lanț sunt încă în așteptare pe ambele rețele. Nu te baza pe faptul că vreo rută este activă.
:::

## Inovații {#innovations}

Nu există încă nimic de folosit în Dashboard, deci nu există inovații ale Dashboard-ului de enumerat. Modul în care lanțul validează transferurile cross-chain este descris în [Arhitectura Bridge](/architecture/bridge-architecture).

## Cum se folosește {#how-to-use}

Nu poți iniția un transfer prin bridge din Dashboard. Pentru modul în care sunt gândite să funcționeze transferurile cross-chain, citește [Transferul activelor (bridging)](/user-guide/bridging-assets) și [Arhitectura Bridge](/architecture/bridge-architecture). Această pagină va descrie fluxul din Dashboard odată ce va fi lansat un ecran Bridge.

## Cum se accesează {#how-to-access}

Indisponibil. Nu există nicio rută, nicio intrare în bara laterală și nicio setare de autentificare sau de rețea care să o activeze.

## Unde este publicat {#where-published}

Nicăieri în Dashboard. Pe pagina Badges există o serie de insigne „Bridge" pentru o funcție care nu este activă; ignoră-o deocamdată.

## Limite și probleme cunoscute {#limits}

- Nu există un ecran Bridge în Dashboard nici pe mainnet, nici pe testnet.
- O previzualizare anterioară a fost retrasă.
- Bridge-ul este un sistem de testnet, aflat în desfășurare; rutele sale sunt în așteptare pe ambele rețele.
