# Bridge

Dashboard-ul nu include în prezent un ecran Bridge. O previzualizare anterioară a fost retrasă, iar transferurile cross-chain nu pot fi inițiate astăzi din Dashboard.

:::caution Status calificat
Bridge-ul cross-chain în sine se află încă pe testnet și este lansat progresiv — nu este încă un sistem de producție pe mainnet, iar rutele sale între lanțuri sunt încă în așteptare pe ambele rețele. Nu te baza pe faptul că vreo rută este activă.
:::

Pentru a înțelege cum sunt validate transferurile cross-chain, vezi [Arhitectura Bridge](/architecture/bridge-architecture) și [Transferul activelor (bridging)](/user-guide/bridging-assets). Această pagină va descrie fluxul din Dashboard odată ce va fi lansat un ecran Bridge.
