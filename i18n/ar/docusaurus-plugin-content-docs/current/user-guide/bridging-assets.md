# جسر الأصول

يشرح هذا الدليل كيفية نقل الأصول بين QoreChain والشبكات اللامركزية الأخرى. تتألف طبقة التشغيل البيني الخاصة بـ QoreChain من **37 إعداد QCB (جسر QoreChain)** (بما في ذلك حلقة استرجاع QoreChain الداخلية) للشبكات غير المتجانسة، بالإضافة إلى **8 قنوات IBC** لسلاسل نظام Cosmos.

:::caution
لا يزال الجسر عبر السلاسل حاليًا في مرحلة **اختبار / ما قبل الإنتاج**. توافر الاتصال، والأصول المدعومة، ومعايير النهائية قابلة للتغيير ويجب ألا تُعامل كجاهزة للإنتاج. تحقّق من جميع التحويلات على **`qorechain-diana`** قبل الاعتماد عليها.
:::

:::note
تستخدم الأوامر أدناه شبكة الاختبار **`qorechain-diana`** (معرّف سلسلة EVM **9800**). الشبكة الرئيسية (**`qorechain-vladi`**، معرّف سلسلة EVM **9801**) تعمل مباشرة منذ 7 يونيو 2026 بإصدار السلسلة **v3.1.95** — استبدل معرّف السلسلة ونقاط النهاية الخاصة بالشبكة الرئيسية من صفحة **الاتصال بالشبكة الرئيسية** حيثما تم تفعيل دعم الجسر.
:::

## نظرة عامة على الاتصال

توفّر QoreChain بروتوكولين للجسر:

| البروتوكول                                | الاتصالات          | حالة الاستخدام                                                            |
| ------------------------------------------ | ------------------ | -------------------------------------------------------------------------- |
| **IBC** (التواصل بين السلاسل)              | 8 قنوات            | تشغيل بيني أصلي مع السلاسل المفعّلة لـ IBC                                 |
| **QCB** (جسر QoreChain)                    | 37 إعدادًا         | تحويلات عبر السلاسل مع شبكات غير IBC عبر تصديقات مؤمَّنة بتشفير ما بعد الكم |

توجد قائمة كاملة بكل إعدادات QCB وقنوات IBC في صفحة **بنية الجسر**. يركّز هذا الدليل على الاستخدام اليومي للجسر.

## قنوات IBC

السلاسل التالية المفعّلة لـ IBC أنشأت قنوات مع QoreChain:

| السلسلة               | القناة      | الحالة |
| ---------------------- | ----------- | ------ |
| Cosmos Hub              | `channel-0` | نشطة   |
| Osmosis                 | `channel-1` | نشطة   |
| Noble                   | `channel-2` | نشطة   |
| Celestia                | `channel-3` | نشطة   |
| Stride                  | `channel-4` | نشطة   |
| Akash                   | `channel-5` | نشطة   |
| Babylon                 | `channel-6` | نشطة   |
| QoreChain (حلقة استرجاع) | `channel-7` | نشطة   |

تستخدم تحويلات IBC وحدة `ibc-transfer` القياسية:

```bash
qorechaind tx ibc-transfer transfer transfer <channel> <recipient> <amount>uqor \
  --from mykey \
  --chain-id qorechain-diana \
  --fees 500uqor
```

## تدفق الإيداع (من سلسلة خارجية إلى QoreChain)

يتبع إيداع الأصول من سلسلة خارجية إلى QoreChain التسلسل التالي:

1. **القفل** — قفل الرموز على السلسلة الخارجية عبر إرسالها إلى عقد أو عنوان جسر QCB.
2. **التصديق** — يراقب مدقّقو الجسر معاملة القفل وينتجون تصديقات موقّعة بتشفير ما بعد الكم.
3. **العتبة** — بمجرد جمع **7 من أصل 10** تصديقات من المدقّقين، يُنهي الجسر عملية الإيداع.
4. **السك** — تُسكّ الرموز الملفوفة المكافئة على QoreChain وتُضاف إلى عنوانك `qor1...`.

**أمر واجهة سطر الأوامر:**

```bash
qorechaind tx bridge deposit \
  --chain ethereum \
  --amount 1000000 \
  --from mykey \
  --chain-id qorechain-diana \
  --fees 500uqor
```

## تدفق السحب (من QoreChain إلى سلسلة خارجية)

سحب الأصول من QoreChain إلى سلسلة خارجية:

1. **الحرق** — حرق الرموز الملفوفة على QoreChain.
2. **التصديق** — يراقب مدقّقو الجسر عملية الحرق وينتجون تصديقات موقّعة بتشفير ما بعد الكم.
3. **العتبة** — بمجرد جمع **7 من أصل 10** تصديقات، يُنهى السحب.
4. **فك القفل** — تُطلَق الرموز الأصلية على السلسلة الخارجية إلى عنوان الوجهة المحدد.

**أمر واجهة سطر الأوامر:**

```bash
qorechaind tx bridge withdraw \
  --chain ethereum \
  --amount 1000000 \
  --to 0xYourEthereumAddress \
  --from mykey \
  --chain-id qorechain-diana \
  --fees 500uqor
```

## نموذج الأمان

جسر QoreChain مؤمَّن بطبقات دفاع متعددة:

| الآلية                          | الوصف                                                                                                                                    |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **توقيع متعدد بنظام 7 من 10 بتشفير ما بعد الكم** | تتطلب كل عملية جسر تصديقات من 7 مدقّقين على الأقل من أصل 10 مدقّقي جسر، كل منهم يستخدم توقيعات تشفير ما بعد الكم.             |
| **فترة تحدٍّ مدتها 24 ساعة**    | عمليات السحب التي تتجاوز حدًّا قابلًا للتهيئة تدخل نافذة تحدٍّ مدتها 24 ساعة يمكن خلالها للمدقّقين أو المراقبين الإبلاغ عن معاملات احتيالية. |
| **قواطع الدارة**                | مُحدِّدات معدل آلية توقف عمليات الجسر إذا اكتُشف حجم غير طبيعي أو أنماط مشبوهة. تُستأنف عمليات الجسر بعد مراجعة يدوية.                     |

## الاستعلام عن حالة الجسر

تحقّق من حالة عملية جسر معلّقة:

```bash
qorechaind query bridge pending-deposits --address <your_qor_address>
```

```bash
qorechaind query bridge pending-withdrawals --address <your_qor_address>
```

عرض جميع اتصالات الجسر النشطة:

```bash
qorechaind query bridge connections
```

## نصائح

* عادةً ما تكتمل ودائع الجسر خلال دقائق بمجرد جمع تصديقات 7 من 10 المطلوبة.
* عمليات السحب الكبيرة تُفعِّل فترة التحدي البالغة 24 ساعة تلقائيًا. خطّط مسبقًا للتحويلات الحساسة للوقت.
* تحقّق دائمًا من أن تنسيق عنوان الوجهة يطابق السلسلة المستهدفة (مثلًا `0x...` لسلاسل EVM، وترميز base58 لـ Solana).
* تحويلات IBC عمومًا أسرع من تحويلات QCB لأنها تستخدم تواصلًا أصليًا على مستوى البروتوكول.
* تُحرق رسوم الجسر عبر قناة الحرق `bridge_fee` (راجع [عمليات الرمز](/user-guide/token-operations)).
