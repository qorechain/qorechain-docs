# عمليات الرموز

يغطي هذا الدليل رمز QOR، وكيفية إرسال الرموز واستلامها، والاستعلام عن الأرصدة، وفهم نموذج توزيع الرسوم في QoreChain.

:::note
تستخدم الأوامر أدناه شبكة الاختبار **`qorechain-diana`** (معرّف سلسلة EVM رقم **9800**). الشبكة الرئيسية (**`qorechain-vladi`**، معرّف سلسلة EVM رقم **9801**) أصبحت فعّالة منذ 29 يونيو 2026 على خط الإصدارات v3.2 (إصدار العقدة **v3.2.1**؛ وتعمل شبكة الاختبار بإصدار **v3.2.2**) — استبدل معرّف السلسلة ونقاط النهاية الخاصة بالشبكة الرئيسية من صفحة **Connecting to Mainnet** عند إجراء المعاملات على الشبكة الرئيسية.
:::

:::caution وقّع باستخدام `tx pqc cosign`
تتطلب الشبكة الرئيسية وشبكة الاختبار توقيعًا هجينًا ما بعد كمومي على كل معاملة في مسار Cosmos، لذلك لا تُبثّ الأوامر في هذه الصفحة كما هي مكتوبة. أضف `--generate-only > tx.json` إلى الأمر، ثم نفّذ `qorechaind tx pqc cosign tx.json --from mykey --pqc-key mypqc --chain-id <chain-id>`. راجع [التوقيع الهجين](/cli-reference/transaction-commands#hybrid-signing). يتولى [QoreX](/qorex/overview) و[لوحة التحكم](/dashboard/overview) هذا التوقيع نيابةً عنك.
:::

## معلومات الرمز

| الخاصية                  | القيمة                        |
| ------------------------ | ----------------------------- |
| **تسمية العرض**          | QOR                           |
| **التسمية الأساسية**    | uqor                          |
| **التحويل**              | 1 QOR = 1,000,000 uqor (10^6) |
| **معرّف السلسلة**        | `qorechain-vladi` (الشبكة الرئيسية) / `qorechain-diana` (شبكة الاختبار) |
| **بادئة Bech32**         | `qor` (مثال: `qor1abc...xyz`) |

تُحدَّد جميع المبالغ على السلسلة بوحدة **uqor**. عند إرسال المعاملات، حدّد المبالغ دائمًا بوحدة uqor.

## إرسال الرموز

لتحويل رموز QOR من حساب إلى آخر:

```bash
qorechaind tx bank send <from_address> <to_address> <amount>uqor \
  --chain-id qorechain-diana \
  --gas 400000 --fees 40000uqor
```

**مثال:** إرسال 5 QOR (5,000,000 uqor) إلى عنوان آخر:

```bash
qorechaind tx bank send qor1sender... qor1recipient... 5000000uqor \
  --chain-id qorechain-diana \
  --gas 400000 --fees 40000uqor
```

يمكنك أيضًا استخدام اسم مفتاح بدلًا من عنوان خام للمرسِل:

```bash
qorechaind tx bank send mykey qor1recipient... 5000000uqor \
  --chain-id qorechain-diana \
  --gas 400000 --fees 40000uqor
```

## الاستعلام عن الأرصدة

تحقّق من رصيد أي حساب:

```bash
qorechaind query bank balances <address>
```

**مثال:**

```bash
qorechaind query bank balances qor1abc...xyz
```

**نموذج للمخرجات:**

```yaml
balances:
- amount: "15000000"
  denom: uqor
pagination:
  next_key: null
  total: "0"
```

يشير هذا إلى أن الحساب يحتفظ بـ 15 QOR (15,000,000 uqor).

## هيكل الرسوم

تُوزَّع رسوم المعاملات في QoreChain على خمس وجهات لمواءمة حوافز الشبكة:

| الوجهة          | الحصة | الغرض                                                            |
| --------------- | ----- | ----------------------------------------------------------------- |
| **المُدقِّقون**  | 37%   | يكافئ منتجي الكتل ويؤمّن الشبكة                                  |
| **المحروقة**    | 30%   | تُزال نهائيًا من المعروض                                          |
| **الخزينة**     | 20%   | تموّل تطوير البروتوكول ومِنح النظام البيئي                        |
| **المُخزِّنون**  | 10%   | تُوزَّع تناسبيًا على جميع المُفوِّضين                             |
| **العُقَد الخفيفة** | 3%  | مخصصة لمكافآت العُقَد الخفيفة (راجع الملاحظة أدناه)                |

ينطبق التقسيم على كل ما يدخل جامع الرسوم (fee collector)، الذي يحتوي على رسوم المعاملات وانبعاثات التخزين المسكوكة في كل حقبة. تتراكم حصة العُقَد الخفيفة في احتياطي؛ وتسجيل مكافآت العُقَد الخفيفة غير مفتوح بعد، لذلك لا تُدفع منها أي مكافأة لأي عقدة حاليًا (راجع [العقدة الخفيفة](/light-node/overview)). منذ ترقية v3.2.0 تُدفع حصة المُخزِّنين كمكافأة تخزين عادية (راجع [الاقتصاد الرمزي](/architecture/tokenomics#stranded-and-reserve)).

## قنوات الحرق

تعرّف وحدة الحرق في QoreChain 12 مصدرًا للحرق. يُزال QOR المحروق عبر أي منها نهائيًا من التداول. على الشبكة الرئيسية لم تسجّل حتى الآن عمليات حرق سوى قناة رسوم الغاز؛ أما القنوات الأخرى فهي معرّفة لكنها لم تسجّل شيئًا.

| القناة                | الوصف                                                              |
| --------------------- | -------------------------------------------------------------------- |
| `gas_fee`             | يُحرق 30% من جميع رسوم الغاز                                        |
| `contract_create`     | رسم ثابت قدره 100 QOR يُحرق عن كل إنشاء عقد (غير نشطة: رفع CosmWasm مغلق) |
| `ai_service`          | يُحرق 50% من رسوم خدمات الذكاء الاصطناعي (غير نشطة: رسوم خدمات الذكاء الاصطناعي غير مفعّلة) |
| `bridge_fee`          | يُحرق 100% من رسوم الجسر (غير نشطة: الجسر غير مفعّل)               |
| `treasury_buyback`    | إعادة شراء وحرق دوريان من الخزينة                                   |
| `failed_tx`           | غاز المعاملات الفاشلة؛ تطبّقه السلسلة منذ v3.2.2 (على شبكة الاختبار فقط حتى الآن) |
| `xqore_penalty`       | غرامات الخروج المبكر من xQORE المُوجَّهة عبر الحرق (xQORE غير مفعّل) |
| `auto_buyback`        | عمليات حرق آلية على مستوى البروتوكول (غير نشطة)                     |
| `tge`                 | محجوزة؛ جرى حرق TGE قبل التكوين الأول (genesis) ولا تسجّل هذه القناة شيئًا |
| `rollup_create`       | يُحرق 1% من حصة إنشاء الرول-أب                                      |
| `milestone`           | عمليات حرق مجدولة عند أعداد تراكمية ثابتة من المعاملات (لم يُفعَّل أيٌّ منها بعد) |
| `amm`                 | محجوزة لرسوم بروتوكول AMM (لم يُسجَّل شيء)                          |

ليس لوحدة الحرق استعلام عبر واجهة سطر الأوامر؛ اقرأ إجمالي الحرق التراكمي لكل مصدر عبر REST:

```bash
curl -s https://api.qore.host/qorechain/burn/v1/stats
```

تسرد الاستجابة `total_burned` و`burns_by_source` (بوحدة uqor). يُحصل على إجمالي المعروض الحالي عبر `qorechaind query bank total-supply-of uqor`.

## نصائح

:::caution
تحقّق دائمًا مرتين من عناوين المستلِمين قبل إرسال الرموز. المعاملات في QoreChain لا يمكن التراجع عنها.
:::

:::tip

* استخدم العَلَم `--dry-run` لمحاكاة معاملة دون بثّها.
* حدّد `--gas` صراحةً (400,000 كافية لتحويل موقّع هجينيًا).
* الحد الأدنى للرسوم هو **0.1 uqor لكل وحدة غاز**، لذا يتطلب حد غاز قدره 400,000 ما لا يقل عن **40,000 uqor**.

:::
