# تكديس xQORE

يغطي هذا الدليل آلية تكديس الحوكمة xQORE، التي تتيح لحاملي QOR قفل رموزهم للحصول على قوة حوكمة معززة، وذلك عبر نموذج إعادة توازن (rebase) من نوع "لاعب ضد لاعب" (PvP) يكافئ المشاركين على المدى الطويل.

:::note
تستخدم الأوامر أدناه شبكة الاختبار **`qorechain-diana`** (معرّف سلسلة EVM **9800**). الشبكة الرئيسية (**`qorechain-vladi`**، معرّف سلسلة EVM **9801**) تعمل منذ 7 يونيو 2026 وتشغّل إصدار السلسلة **v3.1.95** — استبدل معرّف سلسلة الشبكة الرئيسية ونقاط النهاية الخاصة بها من صفحة **الاتصال بالشبكة الرئيسية** عند التكديس على الشبكة الرئيسية.
:::

---

## نظرة عامة

xQORE هو رمز تكديس الحوكمة الخاص بـ QoreChain. عندما تقوم بقفل QOR، تحصل على xQORE بنسبة **1:1**. امتلاك xQORE يوفر ميزة كبيرة في الحوكمة: تُحتسب رموز xQORE بوزن **مضاعف** في صيغة قوة التصويت QDRW (راجع [الحوكمة](/user-guide/governance)).

```
VP = sqrt(staked + 2 * xQORE) * ReputationMultiplier(r)
```

هذا يعني أن قفل QOR في xQORE يضاعف فعليًا تأثيره على الحوكمة مقارنة بالتكديس العادي وحده.

---

## قفل QOR للحصول على xQORE

قم بقفل رموز QOR لسك xQORE بنسبة 1:1:

```bash
qorechaind tx xqore lock <amount>uqor \
  --from mykey \
  --chain-id qorechain-diana \
  --fees 500uqor
```

**مثال:** قفل 1,000 QOR:

```bash
qorechaind tx xqore lock 1000000000uqor \
  --from mykey \
  --chain-id qorechain-diana \
  --fees 500uqor
```

بعد هذه المعاملة، سيحتفظ حسابك بـ 1,000,000,000 uxqore (1,000 xQORE).

---

## فك قفل xQORE

قم بحرق xQORE لاستعادة QOR. قد تُطبَّق **غرامة خروج** حسب مدة قفل الرموز:

```bash
qorechaind tx xqore unlock <amount>uqor \
  --from mykey \
  --chain-id qorechain-diana \
  --fees 500uqor
```

**مثال:** فك قفل 500 xQORE:

```bash
qorechaind tx xqore unlock 500000000uqor \
  --from mykey \
  --chain-id qorechain-diana \
  --fees 500uqor
```

## جدول غرامة الخروج

السحب المبكر من xQORE يستوجب غرامة. كلما طالت مدة الاحتفاظ، انخفضت الغرامة:

| مدة القفل           | غرامة الخروج |
| -------------------- | ------------ |
| أقل من 30 يومًا       | **50%**      |
| من 30 إلى 90 يومًا    | **35%**      |
| من 90 إلى 180 يومًا   | **15%**      |
| أكثر من 180 يومًا     | **0%**       |

**مثال:** إذا قمت بقفل 1,000 QOR وفككت القفل بعد 45 يومًا، فستحصل على 650 QOR (بعد تطبيق غرامة 35%). يُعاد توزيع الـ 350 QOR المتبقية على حاملي xQORE الآخرين عبر آلية إعادة التوازن PvP.

---

## آلية إعادة التوازن PvP

الغرامات المُحصَّلة من عمليات الخروج المبكر **لا يتم حرقها**. بل يُعاد توزيعها بشكل تناسبي على جميع حاملي xQORE المتبقين. هذا يخلق ديناميكية "لاعب ضد لاعب" حيث يستفيد الحاملون الصبورون من تعجّل الآخرين.

آلية العمل:

1. يقوم مستخدم بفك قفل xQORE قبل بلوغ عتبة الـ 180 يومًا التي تُلغي الغرامة.
2. تُخصم غرامة الخروج من مبلغ QOR المُعاد إليه.
3. يُوزَّع مبلغ الغرامة بشكل تناسبي على جميع مراكز xQORE المتبقية.
4. يزداد مبلغ QOR القابل للمطالبة لكل xQORE لدى كل حامل متبقٍ.

تحفّز هذه الآلية الالتزام طويل المدى بالحوكمة وتكافئ الحاملين الذين يحافظون على مراكزهم.

## الاستعلام عن مركزك

تحقق من مركز xQORE الحالي الخاص بك، ومدة القفل، وغرامة الخروج المطبَّقة:

```bash
qorechaind query xqore position <address>
```

**مثال:**

```bash
qorechaind query xqore position qor1abc...xyz
```

**نموذج الإخراج:**

```yaml
position:
  address: qor1abc...xyz
  locked_amount: "1000000000"
  xqore_balance: "1000000000"
  lock_timestamp: "2026-01-15T12:00:00Z"
  current_penalty_rate: "0.150000000000000000"
  accrued_rebase: "25000000"
```

## الوصول عبر JSON-RPC

بالنسبة للتطبيقات التي تتكامل مع QoreChain عبر JSON-RPC، يمكن الاستعلام عن مركز xQORE باستخدام:

```
qor_getXQOREPosition
```

**الطلب:**

```json
{
  "jsonrpc": "2.0",
  "method": "qor_getXQOREPosition",
  "params": ["qor1abc...xyz"],
  "id": 1
}
```

**الاستجابة:**

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {

    "xqore_balance": "1000000000",
```

## نصائح

* قم بقفل QOR في xQORE قبل التصويتات المهمة على الحوكمة بوقت كافٍ لتعظيم قوة تصويتك.
* عتبة الـ 180 يومًا للخروج بدون غرامة تكافئ المشاركين الصبورين في الحوكمة.
* راقب تراكمات إعادة التوازن PvP. فكلما خرج آخرون مبكرًا، ازدادت قيمة مركزك.
* xQORE غير قابل للتحويل. لا يمكن سكّه إلا بقفل QOR، ولا حرقه إلا بفك القفل.
* ضع غرامة الخروج في الحسبان جيدًا قبل القفل. عمليات القفل قصيرة المدى تحمل غرامات كبيرة.
