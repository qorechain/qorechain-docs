# الحوكمة

يغطّي هذا الدليل كيفية عمل الحوكمة على السلسلة في QoreChain: كيف تُحتسب الأصوات، وكيفية تقديم المقترحات، وكيفية التصويت.

:::note
تستخدم الأوامر أدناه شبكة الاختبار **`qorechain-diana`** (معرّف سلسلة EVM **9800**). أمّا الشبكة الرئيسية (**`qorechain-vladi`**، معرّف سلسلة EVM **9801**) فهي قيد التشغيل منذ 7 يونيو 2026 وتعمل بالإصدار **v3.2.4** منذ 23 أكتوبر 2026؛ بينما تعمل شبكة الاختبار بالإصدار **v3.2.6** (منذ 27 أكتوبر 2026) — استبدل معرّف سلسلة الشبكة الرئيسية ونقاط النهاية من صفحة **الاتصال بالشبكة الرئيسية** عند المشاركة في الحوكمة على الشبكة الرئيسية.
:::

:::caution وقّع باستخدام `tx pqc cosign`
تتطلب الشبكة الرئيسية وشبكة الاختبار توقيعاً هجيناً مقاوماً للحوسبة الكمّية على كل معاملة في مسار Cosmos، لذا لا تُبَثّ الأوامر في هذه الصفحة كما هي مكتوبة. أضف `--generate-only > tx.json` إلى الأمر، ثم نفّذ `qorechaind tx pqc cosign tx.json --from mykey --pqc-key mypqc --chain-id <chain-id>`. راجع [التوقيع الهجين](/cli-reference/transaction-commands#hybrid-signing).
:::

## قوة التصويت {#voting-power}

تُحتسب المقترحات على أساس **الحصة المرهونة**: كل QOR فوّضتَه إلى مدقّق مرهون يُحتسب وحدة واحدة من قوة التصويت، دون أي مُضاعِف. إذا لم تصوّت بنفسك، فإن تفويضك يتبع تصويت مدقّقك؛ أمّا الإدلاء بصوتك الخاص فيتجاوز ذلك بالنسبة لحصتك. يُقَرّ المقترح عندما تتحقق جميع الشروط التالية:

| القاعدة   | القيمة الحالية | المعنى                                                                        |
| --------- | ---------- | ----------------------------------------------------------------------------- |
| النصاب    | 33.4%      | نسبة الحصة المرهونة التي يجب أن تصوّت                                         |
| العتبة    | 50%        | نسبة "نعم" بين الأصوات غير الممتنعة اللازمة للإقرار                           |
| النقض     | 33.4%      | إذا بلغت نسبة "لا مع النقض" هذه القيمة، يُرفض المقترح ويُحرق إيداعه           |

قُرئت هذه القيم من الشبكة الرئيسية في 27 أكتوبر 2026. وللشبكة الاختبارية الإيداعات والنصاب والعتبات نفسها لكن بفترات تصويت أقصر بكثير (التصويت 4 ساعات، والتصويت المعجَّل ساعة واحدة)؛ تحقّق منها باستخدام `qorechaind query gov params`، إذ يمكن للحوكمة تغييرها.

:::note نظام QDRW مُصمَّم لكنه غير مُفعَّل
يتضمن تصميم QoreChain صيغة قوة التصويت **الموزونة بالتفويض والسمعة التربيعية (QDRW)**، `VP = sqrt(staked + 2 * xQORE) * ReputationMultiplier(r)`، التي من شأنها تخميد الحصص الكبيرة وترجيح السمعة. وهي مُنفَّذة في وحدة `x/qca` لكنها **معطَّلة** على كلتا الشبكتين (قيمة `qdrw_enabled` هي `false` في `qorechaind query qca config`) وليست جزءاً من احتساب أصوات الحوكمة، لذا فهي لا تؤثر في أي تصويت اليوم. كما أن xQORE غير مُفعَّل بعد (راجع [مراهنة xQORE](/user-guide/xqore-staking)).
:::

## تقديم مقترح

يمكن لأي مالك QOR تقديم مقترح حوكمة. يلزم إيداع بحد أدنى لكي يدخل المقترح فترة التصويت.

```bash
qorechaind tx gov submit-proposal <proposal_file.json> \
  --from mykey \
  --chain-id qorechain-diana \
  --gas 400000 --fees 40000uqor
```

**مثال على ملف مقترح** (`proposal.json`). المقترح هو قائمة رسائل تنفّذها وحدة الحوكمة إذا أُقرّ، إضافةً إلى عنوان وملخّص وإيداع. يرفع هذا المثال الحد الأقصى لعدد المدقّقين من 100 إلى 150؛ و`authority` هو حساب وحدة الحوكمة (`qorechaind query auth module-account gov`):

```json
{
  "messages": [
    {
      "@type": "/cosmos.staking.v1beta1.MsgUpdateParams",
      "authority": "qor10d07y265gmmuvt4z0w9aw880jnsr700jwfyxr3",
      "params": {
        "unbonding_time": "1814400s",
        "max_validators": 150,
        "max_entries": 7,
        "historical_entries": 10000,
        "bond_denom": "uqor",
        "min_commission_rate": "0.000000000000000000"
      }
    }
  ],
  "metadata": "",
  "deposit": "10000000uqor",
  "title": "Increase maximum validator count",
  "summary": "Raise the active validator set from 100 to 150 to improve decentralization.",
  "expedited": false
}
```

تستبدل `MsgUpdateParams` مجموعة المعاملات كاملةً، لذا انسخ القيم الحالية من `qorechaind query staking params` وغيّر الحقل الذي تقصده فقط. يستخدم المقترح النصي (الإشاري) `"messages": []`. ويولّد الأمر `qorechaind tx gov draft-proposal` هيكلاً أولياً.

## التصويت على المقترحات

بمجرّد دخول المقترح فترة التصويت، يمكن لأي مراهن الإدلاء بصوته:

```bash
qorechaind tx gov vote <proposal_id> <option> \
  --from mykey \
  --chain-id qorechain-diana \
  --gas 400000 --fees 40000uqor
```

**خيارات التصويت:**

| الخيار         | الوصف                                                                                              |
| -------------- | -------------------------------------------------------------------------------------------------------- |
| `yes`          | تأييد المقترح                                                                                     |
| `no`           | معارضة المقترح                                                                                      |
| `abstain`      | الإقرار بالمقترح دون اتخاذ موقف                                                       |
| `no_with_veto` | معارضة المقترح والإشارة إلى أنه ما كان ينبغي تقديمه (يحرق الإيداع إذا استُوفيت العتبة) |

**مثال:**

```bash
qorechaind tx gov vote 1 yes \
  --from mykey \
  --chain-id qorechain-diana \
  --gas 400000 --fees 40000uqor
```

## أنواع المقترحات

يحمل المقترح صفراً أو أكثر من الرسائل التي تُنفَّذ إذا أُقرّ. الحالات الشائعة:

| النوع                 | الوصف                                                                                     |
| -------------------- | ----------------------------------------------------------------------------------------------- |
| **نصّي**             | مقترح إشاري بلا رسائل ودون تنفيذ آلي على السلسلة. يُستخدم لفحص مشاعر المجتمع. |
| **تغيير معامِل** | رسالة `MsgUpdateParams` لوحدة معيّنة، يرسلها حساب وحدة الحوكمة. وهي تستبدل مجموعة معاملات تلك الوحدة كاملةً. |
| **ترقية برمجية** | رسالة `MsgSoftwareUpgrade` تجدول ترقية سلسلة منسّقة عند ارتفاع كتلة محدّد. |
| **إنفاق مجتمعي**  | رسالة `MsgCommunityPoolSpend` ترسل أموالاً من مجمّع المجتمع إلى عنوان مستلِم. |
| **معجَّل**        | اضبط `"expedited": true` للحصول على فترة تصويت أقصر مع إيداع وعتبة إقرار أعلى (انظر أدناه). |

## الاستعلام عن المقترحات

اسرد جميع المقترحات:

```bash
qorechaind query gov proposals
```

استعلم عن مقترح محدّد بالمعرّف:

```bash
qorechaind query gov proposal <proposal_id>
```

تحقّق من العدّ الحالي للأصوات على مقترح:

```bash
qorechaind query gov tally <proposal_id>
```

اعرض صوتك أنت على مقترح:

```bash
qorechaind query gov vote <proposal_id> <voter_address>
```

## معاملات الحوكمة

استعلم عن معاملات الحوكمة الحالية:

```bash
qorechaind query gov params
```

تشمل المعاملات الرئيسية:

| المعامِل            | الوصف                                                      | قيمة الشبكة الرئيسية (27 أكتوبر 2026) |
| -------------------- | ---------------------------------------------------------------- | ------------------------ |
| `min_deposit`        | الحد الأدنى للإيداع المطلوب لدخول المقترح في التصويت          | 10 QOR (`10000000uqor`)  |
| `max_deposit_period` | النافذة الزمنية للوصول إلى الحد الأدنى للإيداع                     | يومان                   |
| `voting_period`      | مدة فترة التصويت بمجرّد أن يصبح المقترح نشطاً          | يومان                   |
| `quorum`             | الحد الأدنى للمشاركة المطلوب لصحّة التصويت                  | 0.334                    |
| `threshold`          | الحد الأدنى لنسبة "نعم" للنجاح (باستثناء الامتناع)            | 0.5                      |
| `veto_threshold`     | الحد الأدنى لنسبة "لا مع النقض" للرفض وحرق الإيداع | 0.334                    |
| `expedited_voting_period` / `expedited_threshold` / `expedited_min_deposit` | فترة التصويت وعتبة الإقرار والإيداع للمقترحات المعجَّلة | يوم واحد / 0.667 / 50 QOR |

## الحوكمة على الشبكة الرئيسية حتى الآن {#mainnet-history}

استُخدمت حوكمة الشبكة الرئيسية في تغييرات المعاملات، وقرارات قاطع الدارة، والترقيات المنسّقة، ومنذ أكتوبر 2026 في الإفراج عن مبالغ سجّلتها السلسلة عند ترقية v3.2.0. أُقرّت المقترحات من 7 إلى 13 على الشبكة الرئيسية في أكتوبر 2026، ومنها المقترح 12 (إفراج آخر، أُقرّ في 21 أكتوبر) والمقترح 13 (ترقية v3.2.4، طُبّقت عند الارتفاع 3,742,566 في 23 أكتوبر)؛ وكان المقترح 14 (ترقية منسّقة إلى v3.2.5 عند الارتفاع 3,906,833) في فترة التصويت وقت كتابة هذا النص؛ والقائمة والنتائج في [سجل الإصدارات](/appendix/version-history#governance-timeline)، ويمكن قراءة كل مقترح مباشرةً عبر `GET /cosmos/gov/v1/proposals`.

---

:::tip

* صوّت قبل انتهاء فترة التصويت؛ لا يُحتسب صوتك إلا إذا أُدلي به أثناء فترة التصويت على المقترح.
* استخدم `no_with_veto` بحذر. إذا تم بلوغ عتبة النقض، يُحرق إيداع المقترح.
* تُزال المقترحات التي لا تبلغ الحد الأدنى للإيداع خلال فترة الإيداع تلقائياً.

:::
