# الجسر

لا تتضمن لوحة التحكم حاليًا شاشة جسر. فقد سُحبت معاينة سابقة، ولا يمكن بدء عمليات التحويل عبر السلاسل من لوحة التحكم اليوم.

:::caution حالة مشروطة
الجسر عبر السلاسل نفسه لا يزال في الشبكة التجريبية ويجري طرحه تدريجيًا — وهو ليس بعدُ نظام شبكة رئيسية للإنتاج، ولا تزال مسارات سلاسله معلّقة على كلتا الشبكتين. لا تعتمد على أن أي مسار يعمل فعليًا.
:::

لفهم كيفية التحقق من عمليات التحويل عبر السلاسل، راجع [بنية الجسر](/architecture/bridge-architecture) و[جسر الأصول](/user-guide/bridging-assets). ستصف هذه الصفحة تدفق لوحة التحكم عند إطلاق شاشة جسر.
