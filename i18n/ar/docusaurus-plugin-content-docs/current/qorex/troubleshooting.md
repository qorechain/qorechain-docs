# استكشاف الأخطاء وإصلاحها

أسئلة شائعة وحلول سريعة لتطبيق QoreX والإضافة.

| العرض | السبب / الحل |
|---|---|
| **"قم بتأمين جهازك أولاً"** عند الإعداد | سجّل Face ID / بصمة إصبع في إعدادات نظامك، ثم عُد إلى التطبيق. لا يمكن إنشاء المحفظة إلا على جهاز محمي ببيانات حيوية. |
| **إغلاق ورقة تسجيل الدخول** / "انتهت صلاحية محاولة تسجيل الدخول تلك" | تم التخلي عن محاولة سابقة — ما عليك سوى النقر على تسجيل الدخول مرة أخرى. |
| **اختفاء "إضافة مفتاح مرور"** بعد تسجيل الدخول عبر Google / Dashboard | هذا متوقع: مفاتيح المرور ترتبط فقط بالحسابات المستندة إلى رمز البريد الإلكتروني (راجع الملاحظة في [الحساب و Dashboard](/qorex/account-and-dashboard#sign-in)). |
| **"المُعرّفات قريبًا"** | سجل @handle غير قابل للوصول مؤقتًا. محفظتك غير متأثرة؛ تُفعَّل المُعرّفات تلقائيًا عند عودته. |
| **"رمز خاطئ أو رمز QR تالف"** أثناء ربط الجهاز | أعد التحقق من الرمز المكوّن من 10 أحرف (تحذف الأبجدية الأحرف المتشابهة: لا يوجد 0/O/1/I/L) وأعد المسح. كلا العنصرين لمرة واحدة فقط. |
| **شاشة الكاميرا تقول إن الإذن مطلوب** | iOS: الإعدادات ← QoreX ← الكاميرا. Android: معلومات التطبيق ← الأذونات ← الكاميرا. |
| **الإضافة: "لا توجد محفظة بعد"** | تقترن الإضافة بمحفظة تم إنشاؤها في تطبيق QoreX للهاتف المحمول — أنشئ واحدة هناك أولاً. |
| **رفض الإرسال من عنوان للقراءة فقط** | ذلك العنوان يخص محفظة أخرى (تُظهر التسمية أيها). لا يمكن لـ QoreX التوقيع إلا لحساباته المشتقة الخاصة — أرسل من المحفظة التي تملكه. |
| **ظهور شارة الشبكة التجريبية (testnet)** | الإعدادات ← **"استخدام الشبكة التجريبية (للمطورين)"** مُفعّل. أوقفه للعودة إلى الشبكة الرئيسية (mainnet). |
| **زر المبادلة (Swap) معطّل** | هذا متوقع في الوقت الحالي — تُفعَّل المبادلة تلقائيًا بمجرد توفر سيولة المجمّع؛ لا حاجة إلى تحديث التطبيق. |

## لا تزال عالقًا؟

- راجع صفحة [الأمان والاسترداد](/qorex/security-and-recovery) للاطلاع على الأوصياء وربط الأجهزة.
- للأسئلة حول QoreChain نفسها، راجع [التوثيق الرئيسي](/introduction/what-is-qorechain) أو قنوات المجتمع المرتبطة على [qorechain.io](https://qorechain.io).
