# الأحجام والنقل

| العنصر | البايتات | المصدر |
|---|---|---|
| المفتاح العام ML-DSA-87 | 2592 | FIPS 204, Table 2 |
| المفتاح السري ML-DSA-87 | 4896 | FIPS 204, Table 2 |
| توقيع ML-DSA-87 | 4627 | FIPS 204, Table 2 |
| بذرة ML-DSA-87 | 32 | FIPS 204 |
| المفتاح العام المضغوط secp256k1 | 33 | SEC 1 |
| توقيع secp256k1 (r, s) | 64 | |
| امتداد PQC في الجسم | نحو 4640 (التوقيع مع إطار protobuf؛ يضاف 2595 عند تضمين المفتاح العام) | `qorechain.pqc.v1.PQCHybridSignature` |

## الانعكاسات على المحافظ {#consequences}

- المعاملة الهجينة أكبر بنحو 4.7 كيلوبايت من المعاملة الكلاسيكية. يتناسب الغاز والرسوم مع حجم المعاملة؛ حاكِ قبل التوقيع (`simulateTx`) واستخدم حد الغاز المقترح.
- يتسع رمز QR ثابت واحد لما لا يزيد على 2953 بايتًا (الإصدار 40، ثنائي، تصحيح أخطاء منخفض)، فلا يتسع توقيع ML-DSA-87 ولا مفتاحه العام في رمز واحد. تحتاج أجهزة التوقيع المعزولة عن الشبكة إلى ترميزات متعددة الأجزاء (QR متحرك أو بترميز نافوري).
- احفظ البذرة ذات 32 بايتًا، لا المفتاح السري ذا 4896 بايتًا، عندما تحتاج إلى حفظ مفتاح ML-DSA-87؛ إذ تعيد `pqKeyFromSeed` إنشاء زوج المفاتيح.

تُعرَّف بنية الامتداد في [توقيع المعاملات الهجين v1](/qoresign/spec/hybrid-signing-v1#extension).
