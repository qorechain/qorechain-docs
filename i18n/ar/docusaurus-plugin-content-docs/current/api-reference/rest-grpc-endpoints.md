# نقاط نهاية REST / gRPC

توفر QoreChain ثلاث واجهات رئيسية للوصول البرمجي:

| الواجهة | المنفذ الافتراضي | البروتوكول | الوصف                                        |
| ------- | ---------------- | ---------- | -------------------------------------------- |
| REST    | `1317`           | HTTP/1.1   | واجهة REST API لعميل LCD (Light Client Daemon) |
| gRPC    | `9090`           | HTTP/2     | خدمة gRPC مرمَّزة بصيغة Protobuf              |
| RPC     | `26657`          | HTTP + WS  | واجهة RPC لمحرك إجماع QoreChain               |

تعيد جميع نقاط نهاية REST استجابات بصيغة JSON. تستخدم نقاط نهاية gRPC صيغة Protocol Buffers ويمكن استهلاكها بأي عميل gRPC. وتوفر واجهة RPC استعلامات على مستوى الإجماع وبثّ المعاملات.

:::note
هذه الواجهات متاحة على كلٍّ من الشبكة الرئيسية **`qorechain-vladi`** (تعمل منذ 7 يونيو 2026 على إصدار السلسلة **v3.1.92**) وشبكة الاختبار **`qorechain-diana`**. تفترض عناوين URL الأساسية أدناه وجود عقدة تعمل محليًا؛ أما نقاط النهاية العامة المستضافة (`rpc/api/evm/svm.qore.host` ونظائرها ذات اللاحقة `-testnet`) فهي مدرجة في [الشبكات](/appendix/networks#public-endpoints).
:::

## عناوين URL الأساسية

```
REST:  http://localhost:1317
gRPC:  localhost:9090
RPC:   http://localhost:26657
```

## وحدة الجسر {#bridge-module}

اعتبارًا من إصدار السلسلة **v3.1.77**، أصبحت حالة القراءة فقط لوحدة الجسر معروضة عبر REST من خلال grpc-gateway تحت البادئة `/qorechain/bridge/v1/...` (كانت سابقًا متاحة عبر gRPC فقط). تقدم نقاط النهاية هذه بيانات JSON حقيقية من السلسلة عبر HTTP لمستكشفات الكتل وقياسات العقد الخفيفة عن بُعد. يُبلغ `config` الخاص بالجسر على سبيل المثال عن `min_validators=10` و`threshold=7`.

| الطريقة | نقطة النهاية                                | الوصف                                    |
| ------- | ------------------------------------------- | ---------------------------------------- |
| GET     | `/qorechain/bridge/v1/config`               | التهيئة الحالية لوحدة الجسر              |
| GET     | `/qorechain/bridge/v1/chains`               | تسرد جميع سلاسل الجسر المسجَّلة          |
| GET     | `/qorechain/bridge/v1/chains/{chain_id}`    | تفاصيل سلسلة مجسورة محددة                |
| GET     | `/qorechain/bridge/v1/validators`           | تسرد مدققي الجسر المسجَّلين              |
| GET     | `/qorechain/bridge/v1/validators/{address}` | تفاصيل مدقق جسر محدد                     |
| GET     | `/qorechain/bridge/v1/operations`           | تسرد عمليات الجسر                        |
| GET     | `/qorechain/bridge/v1/operations/{id}`      | تفاصيل عملية جسر محددة                   |

ولا تزال نقاط النهاية التالية ذات المسارات الأقصر متاحة:

| GET     | `/bridge/v1/chains/{id}`            | تفاصيل سلسلة مجسورة محددة                      |
| GET     | `/bridge/v1/validators`             | تسرد مدققي الجسر النشطين                       |

## الوحدة متعددة الطبقات {#multilayer-module}

اعتبارًا من إصدار السلسلة **v3.1.80**، أصبحت خدمة الاستعلام الكاملة للوحدة متعددة الطبقات معروضة عبر REST من خلال grpc-gateway تحت البادئة `/qorechain/multilayer/v1/...` (كانت سابقًا متاحة عبر gRPC فقط)، بما في ذلك **استعلاما قراءة لمرساة الحالة**: يعيد `anchor/{layer_id}` أحدث مرساة تسوية لطبقة ما، ويعيد `anchors/{layer_id}` سجل مراسيها. تحمل كل مرساة توقيع **ML-DSA-87 (Dilithium-5)** على حقولها القانونية، بحيث يستطيع العميل جلب مرساة والتحقق منها بشكل مستقل — وهذا هو الأساس على السلسلة لـ[إيصالات التسوية](/rollups/settlement-receipts) الخاصة بأداة Rollup Development Kit.

| الطريقة | نقطة النهاية                                   | الوصف                                        |
| ------- | ---------------------------------------------- | -------------------------------------------- |
| GET     | `/qorechain/multilayer/v1/params`              | المعاملات الحالية للوحدة متعددة الطبقات      |
| GET     | `/qorechain/multilayer/v1/layers`              | تسرد جميع الطبقات المسجَّلة                  |
| GET     | `/qorechain/multilayer/v1/layers/{layer_id}`   | تفاصيل طبقة محددة                            |
| GET     | `/qorechain/multilayer/v1/anchor/{layer_id}`   | أحدث مرساة حالة لطبقة ما                     |
| GET     | `/qorechain/multilayer/v1/anchors/{layer_id}`  | سجل مراسي الحالة لطبقة ما                    |
| GET     | `/qorechain/multilayer/v1/routing-stats`       | إحصاءات توجيه المعاملات عبر الطبقات          |

يحتوي `StateAnchorView` على `layer_id` و`layer_height` و`state_root` و`validator_set_hash` و`main_chain_height` و`anchored_at` و`pqc_aggregate_signature` و`transaction_count` و`compressed_state_proof`. الرسالة القانونية الموقَّعة هي `layer_id || layer_height || state_root || validator_set_hash`، ويجري التحقق منها مقابل مفتاح PQC المسجَّل لمنشئ الطبقة.

ولا تزال نقاط النهاية التالية ذات المسارات الأقصر متاحة:

| الطريقة | نقطة النهاية                   | الوصف                                   |
| ------- | ------------------------------ | ---------------------------------------- |
| GET     | `/multilayer/v1/layer/{id}`    | تفاصيل طبقة محددة                       |
| GET     | `/multilayer/v1/layers`        | تسرد جميع الطبقات المسجَّلة             |
| GET     | `/multilayer/v1/anchor/{id}`   | تفاصيل سجل مرساة محدد                   |
| GET     | `/multilayer/v1/anchors`       | تسرد عمليات إرسال المراسي الأخيرة       |
| GET     | `/multilayer/v1/routing-stats` | إحصاءات توجيه المعاملات عبر الطبقات     |
| GET     | `/multilayer/v1/params`        | المعاملات الحالية للوحدة متعددة الطبقات |

## انعكاس gRPC

انعكاس خادم gRPC مفعَّل افتراضيًا، ما يتيح لأدوات مثل `grpcurl` اكتشاف الخدمات المتاحة:

```bash
grpcurl -plaintext localhost:9090 list
```

للاستعلام عن خدمة محددة:

```bash
grpcurl -plaintext localhost:9090 qorechain.pqc.v1.Query/Params
```

## المصادقة

جميع نقاط نهاية REST وgRPC غير مصادَق عليها افتراضيًا. لعمليات النشر الإنتاجية، ضع وكيلًا عكسيًا (مثل Nginx أو Caddy) أمام العقدة للتعامل مع إنهاء TLS والتحكم في الوصول.
