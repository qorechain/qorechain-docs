# نقاط REST / gRPC

توفّر QoreChain ثلاث واجهات أساسية للوصول البرمجي:

| الواجهة | المنفذ الافتراضي | البروتوكول | الوصف                              |
| ------- | ---------------- | ---------- | ----------------------------------- |
| REST    | `1317`           | HTTP/1.1   | واجهة LCD (Light Client Daemon) REST |
| gRPC    | `9090`           | HTTP/2     | خدمة gRPC مُرمّزة بـ Protobuf         |
| RPC     | `26657`          | HTTP + WS  | واجهة RPC لمحرّك إجماع QoreChain      |

تُعيد جميع نقاط REST بيانات JSON. تستخدم نقاط gRPC صيغة Protocol Buffers ويمكن استهلاكها بأي عميل gRPC. توفّر واجهة RPC استعلامات على مستوى الإجماع وبثّ المعاملات.

:::note
هذه الواجهات متاحة على كلٍّ من شبكة **`qorechain-vladi`** الرئيسية (تعمل منذ 7 يونيو 2026 بإصدار السلسلة **v3.1.97**) وشبكة الاختبار **`qorechain-diana`**. تفترض عناوين URL الأساسية أدناه عقدة تعمل محليًا؛ نقاط النهاية العامة المستضافة (`rpc/api/evm/svm.qore.host` ونظيراتها بلاحقة `-testnet`) مُدرجة في [الشبكات](/appendix/networks#public-endpoints).
:::

## عناوين URL الأساسية

gRPC:  localhost:9090

## وحدة الجسر (Bridge Module) {#bridge-module}

اعتبارًا من إصدار السلسلة **v3.1.77**، أصبحت حالة القراءة فقط لوحدة الجسر مُتاحة عبر REST من خلال grpc-gateway ضمن البادئة `/qorechain/bridge/v1/...` (كانت مقتصرة على gRPC سابقًا). تُقدّم هذه النقاط بيانات JSON حقيقية على السلسلة عبر HTTP للمستكشفات وقياس عن بُعد للعقد الخفيفة. يُظهر إعداد `config` الخاص بالجسر مثلًا `min_validators=10` و`threshold=7`.

| الطريقة | نقطة النهاية                                | الوصف                                    |
| ------- | -------------------------------------------- | ----------------------------------------- |
| GET     | `/qorechain/bridge/v1/config`               | إعدادات وحدة الجسر الحالية                |
| GET     | `/qorechain/bridge/v1/chains`               | يسرد كل السلاسل المسجَّلة في الجسر         |
| GET     | `/qorechain/bridge/v1/chains/{chain_id}`    | تفاصيل سلسلة مُجسَّرة محددة                |
| GET     | `/qorechain/bridge/v1/validators`           | يسرد مدقّقي الجسر المسجَّلين               |
| GET     | `/qorechain/bridge/v1/validators/{address}` | تفاصيل مدقّق جسر محدد                     |
| GET     | `/qorechain/bridge/v1/operations`           | يسرد عمليات الجسر                         |
| GET     | `/qorechain/bridge/v1/operations/{id}`      | تفاصيل عملية جسر محددة                    |

تبقى نقاط النهاية الأقصر التالية متاحة:

## وحدة الطبقات المتعددة (Multilayer) {#multilayer-module}

اعتبارًا من إصدار السلسلة **v3.1.80**، أصبحت خدمة الاستعلام الكاملة لوحدة الطبقات المتعددة مُتاحة عبر REST من خلال grpc-gateway ضمن البادئة `/qorechain/multilayer/v1/...` (كانت مقتصرة على gRPC سابقًا)، بما في ذلك استعلامَي قراءة **مرساة الحالة**: يُعيد `anchor/{layer_id}` أحدث مرساة تسوية لطبقة، ويُعيد `anchors/{layer_id}` سجل مراسيها التاريخي. تحمل كل مرساة توقيع **ML-DSA-87 (Dilithium-5)** فوق حقولها القانونية، بحيث يمكن للعميل جلب مرساة والتحقق منها بشكل مستقل — وهذا هو الأساس على السلسلة لـ[إيصالات التسوية](/rollups/settlement-receipts) الخاصة بحزمة تطوير التجميعات (Rollup Development Kit).

| الطريقة | نقطة النهاية                                     | الوصف                                            |
| ------- | -------------------------------------------------- | --------------------------------------------------- |
| GET     | `/qorechain/multilayer/v1/params`                 | معاملات وحدة الطبقات المتعددة الحالية               |
| GET     | `/qorechain/multilayer/v1/layers`                 | يسرد كل الطبقات المسجَّلة                            |
| GET     | `/qorechain/multilayer/v1/layers/{layer_id}`      | تفاصيل طبقة محددة                                   |
| GET     | `/qorechain/multilayer/v1/anchor/{layer_id}`      | أحدث مرساة حالة لطبقة                                |
| GET     | `/qorechain/multilayer/v1/anchors/{layer_id}`     | سجل مراسي الحالة لطبقة                               |
| GET     | `/qorechain/multilayer/v1/routing-stats`          | إحصاءات توجيه المعاملات عبر الطبقات                  |

يحتوي `StateAnchorView` على الحقول `layer_id` و`layer_height` و`state_root` و`validator_set_hash` و`main_chain_height` و`anchored_at` و`pqc_aggregate_signature` و`transaction_count` و`compressed_state_proof`. الرسالة القانونية الموقَّعة هي `layer_id || layer_height || state_root || validator_set_hash`، ويتم التحقق منها مقابل مفتاح PQC المسجَّل لمُنشئ الطبقة.

تبقى نقاط النهاية الأقصر التالية متاحة:

| الطريقة | نقطة النهاية                    | الوصف                                        |
| ------- | --------------------------------- | ------------------------------------------------ |
| GET     | `/multilayer/v1/layer/{id}`      | تفاصيل طبقة محددة                                |
| GET     | `/multilayer/v1/layers`          | يسرد كل الطبقات المسجَّلة                         |
| GET     | `/multilayer/v1/anchor/{id}`     | تفاصيل سجل مرساة محدد                             |
| GET     | `/multilayer/v1/anchors`         | يسرد آخر عمليات إرسال المراسي                     |
| GET     | `/multilayer/v1/routing-stats`   | إحصاءات توجيه المعاملات عبر الطبقات                |
| GET     | `/multilayer/v1/params`          | معاملات وحدة الطبقات المتعددة الحالية              |

## استكشاف gRPC (Reflection)

خاصية استكشاف خادم gRPC مُفعَّلة افتراضيًا، مما يسمح لأدوات مثل `grpcurl` باكتشاف الخدمات المتاحة:

```bash
grpcurl -plaintext localhost:9090 list
```

للاستعلام عن خدمة محددة:

```bash
grpcurl -plaintext localhost:9090 qorechain.pqc.v1.Query/Params
```

## المصادقة

جميع نقاط REST وgRPC غير مُصادَق عليها افتراضيًا. للنشر في بيئة الإنتاج، ضع وكيلًا عكسيًا (مثل Nginx أو Caddy) أمام العقدة للتعامل مع إنهاء TLS والتحكم في الوصول.
