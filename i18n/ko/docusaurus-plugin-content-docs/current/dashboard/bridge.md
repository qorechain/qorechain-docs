# 브리지

Dashboard에는 현재 브리지 화면이 없습니다. 이 페이지는 무엇이 가능하고 무엇이 불가능한지 확인할 수 있도록 마련되었습니다. 현재 Dashboard에서는 크로스체인 전송을 시작할 수 없으며, `/bridge` 페이지도 없습니다(`dashboard.qorechain.io/bridge`를 열면 "not found"가 반환됩니다).

:::caution 한정 상태
크로스체인 브리지 자체는 아직 테스트넷에 있으며 점진적으로 출시되고 있습니다. 아직 프로덕션 메인넷 시스템이 아니며, 체인 경로는 두 네트워크 모두에서 여전히 대기 중입니다. 어떤 경로도 라이브 상태라고 믿지 마세요.
:::

## 혁신 사항 {#innovations}

Dashboard에서 아직 사용할 수 있는 것이 없으므로, 나열할 Dashboard 혁신 사항도 없습니다. 체인이 크로스체인 전송을 검증하는 방식은 [브리지 아키텍처](/architecture/bridge-architecture)에 설명되어 있습니다.

## 사용 방법 {#how-to-use}

Dashboard에서는 브리지 전송을 시작할 수 없습니다. 크로스체인 전송이 어떻게 동작하도록 의도되었는지는 [자산 브리징](/user-guide/bridging-assets)과 [브리지 아키텍처](/architecture/bridge-architecture)를 읽어보세요. 이 페이지는 브리지 화면이 출시되면 Dashboard 흐름을 설명할 예정입니다.

## 접근 방법 {#how-to-access}

사용할 수 없습니다. 경로도, 사이드바 항목도 없으며, 이를 켜는 로그인이나 네트워크 설정도 없습니다.

## 게시 위치 {#where-published}

Dashboard의 어디에도 없습니다. 라이브 상태가 아닌 기능을 위한 "Bridge" 배지 시리즈가 Badges 페이지에 존재하지만, 지금은 무시하세요.

## 제한 사항 및 알려진 문제 {#limits}

- 메인넷과 테스트넷 모두에 Dashboard 브리지 화면이 없습니다.
- 이전 미리보기는 철회되었습니다.
- 브리지는 테스트넷 단계의 진행 중인 시스템이며, 경로는 두 네트워크 모두에서 대기 중입니다.
