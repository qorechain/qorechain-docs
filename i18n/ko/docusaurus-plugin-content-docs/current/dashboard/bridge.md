# 브리지

대시보드에는 현재 브리지 화면이 없습니다. 이전 미리보기는 철회되었으며, 현재는 대시보드에서 크로스체인 전송을 시작할 수 없습니다.

:::caution 한정 상태
크로스체인 브리지 자체는 아직 테스트넷에 있으며 점진적으로 출시되고 있습니다 — 아직 프로덕션 메인넷 시스템이 아니며, 체인 경로는 두 네트워크 모두에서 여전히 대기 중입니다. 어떤 경로도 라이브 상태라고 믿지 마세요.
:::

크로스체인 전송이 검증되는 방식은 [브리지 아키텍처](/architecture/bridge-architecture)와 [자산 브리징](/user-guide/bridging-assets)을 참조하세요. 이 페이지는 브리지 화면이 출시되면 대시보드 플로우를 설명할 예정입니다.
