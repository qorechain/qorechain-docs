# 스마트 컨트랙트 생성기

**스마트 컨트랙트 생성기**는 **QCAI**를 기반으로 일반 언어 설명으로부터 스마트 컨트랙트를 생성합니다. 원하는 내용을 설명하고 대상 블록체인을 선택하면 QCAI가 컨트랙트를 작성해 줍니다. AI 도구를 위한 **17개 블록체인**을 지원하므로, 구축하려는 생태계를 대상으로 지정할 수 있습니다.

지갑을 연결하면 생성한 컨트랙트를 저장하고 관리할 수 있습니다 — [개요 및 시작하기](/dashboard/overview#connect-your-wallet)를 참고하세요.

## 컨트랙트 생성하기

1. **컨트랙트를 설명하세요.** 프롬프트 입력란에 컨트랙트가 수행해야 할 일을 작성하세요 — 예를 들어 고정 공급량 토큰, NFT 컬렉션, 베스팅 스케줄 등입니다. 구체적으로 작성할수록 더 좋은 결과를 얻을 수 있습니다.
2. **블록체인을 선택하세요.** 지원되는 블록체인 중에서 대상을 선택하세요. 선택한 항목에 해당하는 컨트랙트 언어와 카테고리가 선택기 옆에 표시됩니다.
3. **컨트랙트 유형을 선택하세요** (선택 사항). 토큰, NFT, 거버넌스 컨트랙트 같은 시작 템플릿을 선택하여 생성 방향을 잡을 수 있습니다.
4. **생성하세요.** **Generate**를 선택하세요. QCAI가 컨트랙트를 생성하는 동안 진행 상태 표시기가 상태를 보여 줍니다.

## 결과 검토하기

생성이 완료되면 대시보드는 컨트랙트를 구문 강조 뷰로 표시하며, 컨트랙트 이름, 블록체인, 언어, 파일 크기, 생성 시각 같은 세부 정보를 함께 보여 줍니다. 사용한 프롬프트도 참고용으로 결과와 함께 표시됩니다.

여기에서 다음을 할 수 있습니다:

- 컨트랙트 코드를 클립보드로 **복사**합니다.
- 선택한 블록체인에 맞는 형식의 파일로 컨트랙트를 **다운로드**합니다.
- 컨트랙트를 **편집**하여 더 다듬을 수 있습니다.

## 컨트랙트 배포하기 {#deploy}

### 메인넷(EVM) — 논커스터디얼 배포 {#deploy-mainnet}

메인넷 배포는 논커스터디얼 방식입니다. 대시보드는 컨트랙트를 컴파일하고 **서명되지 않은** 배포 데이터를 반환할 뿐, 여러분의 키를 보관하지 않으며 여러분을 대신해 서명하지도 않습니다. 배포 트랜잭션의 서명과 브로드캐스트는 여러분의 지갑에서 직접 수행하며, 이후 대시보드가 생성된 컨트랙트를 기록합니다.

1. 배포할 컨트랙트(EVM 대상 컨트랙트)를 열고 **Mainnet**에서 **Deploy**를 선택하세요. 첫 메인넷 작업이라면 [1회성 위험 고지 동의](/dashboard/overview#risk-acknowledgement)에 동의해야 합니다.
2. **MetaMask**가 아직 연결되어 있지 않다면 연결하세요 — [개요 및 시작하기](/dashboard/overview#connect-your-wallet)를 참고하세요.
3. 대시보드가 컨트랙트를 컴파일하고 서명되지 않은 배포 트랜잭션을 지갑에 전달합니다.
4. MetaMask에서 트랜잭션 — 네트워크, 가스, 데이터 — 을 검토한 뒤 확인을 눌러 직접 서명하고 브로드캐스트하세요.
5. 배포가 온체인에서 확정되면, 대시보드가 생성된 컨트랙트 주소를 저장된 컨트랙트 목록에 함께 기록합니다.

메인넷에서는 현재 이 방식으로 **EVM** 배포만 가능하며, **Wasm** 및 **SVM** 배포는 테스트넷 전용입니다.

### 테스트넷 — 원클릭 {#deploy-testnet}

테스트넷 플로우는 이전과 동일합니다. 대시보드가 관리하는 테스트 지갑이 원클릭으로 배포를 서명하고 제출해 주므로, 메인넷으로 가기 전에 [Faucet](/dashboard/faucet) 토큰으로 빠르게 반복 개발할 수 있습니다. 테스트넷은 EVM, Wasm, SVM 배포를 지원합니다.

## 공유 및 재사용

생성된 각 컨트랙트에는 열거나 공유할 수 있는 전용 페이지가 있습니다. 자신이 소유하지 않은 컨트랙트를 열면 **포크**하여 자신의 사본을 만들고 거기서부터 이어서 작업할 수 있습니다.

:::tip 항상 검토하고 테스트하세요
QCAI가 생성한 코드는 훌륭한 출발점일 뿐 검토를 대체하지 않습니다. 컨트랙트를 읽어 보고, [테스트넷](/getting-started/connecting-to-testnet)에서 테스트하고, 가치 있는 것을 배포하기 전에 [컨트랙트 감사기](/dashboard/contract-auditor)로 점검하세요.
:::
