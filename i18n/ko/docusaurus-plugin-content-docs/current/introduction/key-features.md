# 주요 기능

다음 표는 QoreChain의 모든 주요 기능을 도입된 릴리스 단계별로 정리한 것입니다. 현재 체인 버전은 **v3.1.92**이며, 메인넷(`qorechain-vladi`, EVM 체인 ID 9801)은 2026년 6월 7일부터 가동 중이고, 병행하여 테스트넷(`qorechain-diana`, EVM 체인 ID 9800)이 운영되고 있습니다.

| 기능                    | 도입된 버전       | 설명                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------------- | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PQC 하이브리드 서명 (기본값으로 필수) | v1.1.0 (Security)   | 모든 코스모스 경로 트랜잭션에 적용되는 이중 서명입니다: 고전 방식의 secp256k1(ECDSA) 서명과 ML-DSA-87(Dilithium-5) 서명이 함께 사용됩니다. v3.1.71부터 네트워크 기본값은 **필수(required)**로 설정되어(`hybrid_signature_mode = required`, `allow_classical_fallback = false`) 고전 방식 서명만 사용한 코스모스 트랜잭션은 거부됩니다. 예외는 제네시스 gentx와 PQC 키 등록/마이그레이션 트랜잭션뿐입니다. EVM 트랜잭션은 별도의 `eth_secp256k1` 경로를 사용하며 영향을 받지 않습니다. 거버넌스로 제어되는 세 가지 시행 모드(disabled / optional / required)가 계속 제공됩니다. TX 확장 프로그램의 자동 등록을 통해 매끄러운 지갑 온보딩이 가능합니다.                                                                              |
| SHAKE-256 기본 해시     | v1.1.0 (Security)   | SHA-3 계열의 확장 출력 함수(XOF)입니다. v3.1.73부터 SHAKE-256(`qorehash` 패키지를 통해 제공)이 **기본 애플리케이션 해시**가 되어 PQC 기준선(Dilithium-5 + ML-KEM-1024 + SHAKE-256)이 완성되었습니다. 가변 길이 해싱, 고정 32바이트 출력, 머클 내부 노드 연결, 도메인 분리 해싱을 모두 순수 Go로 제공하며 FFI 의존성이 없습니다.                                                                                                                 |
| TEE 및 FL 인터페이스      | v1.1.0 (Security)   | 신뢰 실행 환경(TEE) 증명(SGX, TDX, SEV-SNP, ARM CCA)과 연합 학습(Federated Learning) 조정(FedAvg, FedProx, SCAFFOLD 집계 방식)을 위한 프로덕션급 인터페이스 사양입니다. 암호학적으로 보장된 하드웨어 엔클레이브 AI 추론과 프라이버시 보존형 분산 모델 학습을 가능하게 합니다.                                                                |
| 온체인 RL 합의 (PRISM) | v1.0.0 (Genesis) | Go 네이티브 고정소수점 MLP(파라미터 73,733개)가 블록 라이프사이클 내에서 직접 PPO 추론을 수행합니다. PRISM 최적화 레이어는 외부 오라클 없이 블록 시간, 가스 한도, 검증인 풀 가중치를 동적으로 조정합니다. 결정론적 테일러 급수 연산으로 모든 검증인 간에 동일한 결과가 보장됩니다. shadow, conservative, autonomous, paused의 네 가지 운영 모드가 있습니다. 안전을 위한 서킷 브레이커 보호 기능도 포함됩니다. |
| 트리플 풀 복합 PoS  | v1.0.0 (Genesis)    | 검증인은 QoreChain 합의 엔진에서 1,000블록마다 RPoS(평판 가중), DPoS(위임 가중), PoS(표준) 풀로 분류됩니다. 풀 가중 소티션은 순수 지분 우위를 넘어 블록 생성을 다변화합니다. 커스텀 본딩 커브는 자가 본딩된 지분, 충성 기간, 평판 품질, 프로토콜 단계를 반영합니다.                            |
| QDRW 거버넌스            | v1.0.0 (Genesis)    | 평판 가중 이차 위임(Quadratic Delegation with Reputation Weighting) 방식입니다. 투표력은 시그모이드 평판 승수로 감쇠된 제곱근 함수를 사용하여, 고래(대규모 보유자)의 지배를 방지하는 동시에 장기적이고 정직한 참여에 보상을 제공합니다. 지분이 100배 많아도 투표력은 약 10배에 그칩니다. xQORE 보유분은 투표 가중치를 두 배로 만듭니다.                                                                               |
| 소각 엔진                | v1.0.0 (Genesis)    | 열 가지 서로 다른 소각 채널이 있습니다: 트랜잭션 수수료, 거버넌스 페널티, 슬래싱, 브리지 수수료, 스팸 억제, 에포크 잉여분, 수동 소각, 컨트랙트 콜백, 크로스 VM 수수료, 롤업 생성 소각입니다. 징수된 수수료는 **검증인에 37%, 영구 소각 30%, 트레저리에 20%, 스테이커에 10%, 라이트 노드에 3%**로 분배됩니다.                                                            |
| xQORE 스테이킹              | v1.0.0 (Genesis)    | QOR을 잠그면 1:1 비율로 xQORE가 발행되어 QDRW 투표에서 거버넌스 가중치가 두 배가 됩니다. 단계적 탈퇴 페널티(30일 미만 50%, 30~90일 35%, 90~180일 15%, 180일 이후 0%)는 PvP 리베이스를 통해 남아 있는 보유자에게 재분배되며, 이는 장기 보유를 보상하고 단기 자본을 억제합니다.                                                                                      |
| 고정 공급 발행량     | v1.0.0 (Genesis)    | 총 공급량은 45억(4,500,000,000) QOR로 고정되어 있으며(TGE 시점에 8천만(80,000,000) QOR 소각), 스테이킹 보상 예산은 5억 9천만(590,000,000) QOR로 한정됩니다: 1년 차 연 8~12%(127,500,000 QOR), 2년 차 연 6~10%(106,250,000 QOR), 3~4년 차 연 5~8%(연간 85,000,000 QOR), 5년 차 이후는 거버넌스 결정(잔여 약 186,000,000 QOR)입니다. 소각 엔진과 결합되어, 트랜잭션 거래량이 증가할수록 QOR은 순 디플레이션 성향에 가까워집니다. |
| EVM 런타임                | v1.0.0 (Genesis)    | EIP-1559 가스 가격 책정, 포트 8545의 JSON-RPC(`eth_`, `web3_`, `net_`, `txpool_`, `qor_` 네임스페이스), Hardhat·Foundry·Remix 등 표준 툴링 지원을 포함한 완전한 이더리움 호환성을 제공합니다. 기존 이더리움 워크플로를 사용하여 Solidity 컨트랙트를 배포하고 상호작용할 수 있습니다.                                                                                                                    |
| CosmWasm 런타임           | v1.0.0 (Genesis)    | Rust 기반 컨트랙트를 위한 WebAssembly 스마트 컨트랙트 엔진입니다. 인스턴스화, 실행, 조회, 마이그레이션 등 전체 라이프사이클을 지원합니다. 컨트랙트는 결정론적 실행이 보장되는 샌드박스 Wasm 환경에서 실행됩니다.                                                                                                                                                                                       |
| SVM 런타임                | v1.0.0 (Genesis)    | Rust 기반 실행기를 통한 BPF 프로그램 배포 및 실행입니다. 포트 8899의 솔라나 호환 JSON-RPC 서버가 `getAccountInfo`, `getBalance`, `getSlot` 등을 지원합니다. 기존 솔라나 클라이언트와 툴링을 수정 없이 그대로 사용할 수 있습니다.                                                                                                                                    |
| 크로스 VM 브리지            | v1.0.0 (Genesis)    | 세 가지 VM 전반에 걸친 매끄러운 상호운용성을 제공합니다. EVM 컨트랙트는 프리컴파일을 통해 CosmWasm을 호출하고, CosmWasm 컨트랙트는 커스텀 메시지를 통해 EVM을 호출하며, SVM 프로그램은 비동기 이벤트 기반 브리징을 통해 참여합니다. 단일 체인 내에서 동기식 EVM-CosmWasm 호출과 비동기식 SVM 메시징이 모두 가능합니다.                                                                                                  |
| 크로스체인 연결성   | v1.2.0 (Interop)    | 8개의 IBC 채널(Cosmos Hub, Osmosis, Noble, Celestia, Stride, Akash, Babylon, Injective)과 **36개 외부 체인을 다루는 37개의 QCB 설정**(QoreChain 자체를 네이티브 루프백으로 포함)을 제공합니다. PQC로 서명된 검증인 증명, 체인별 확인 깊이, 서킷 브레이커 거래량 한도가 적용됩니다. 현재 테스트넷/보류 상태이며 아직 프로덕션 단계는 아닙니다.                               |
| BTC 리스테이킹              | v1.2.0 (Interop)    | 비트코인 파이널리티 보증을 위한 Babylon Protocol 통합입니다. 검증인은 BTC 스테이킹 포지션을 등록합니다(최소 100,000사토시). QoreChain 에포크 상태 루트는 IBC로 중계되는 Babylon 에포크를 통해 주기적으로 비트코인에 체크포인팅되어, BTC 해시레이트가 뒷받침하는 보조 파이널리티 레이어를 제공합니다.                                                                                           |
| 계정 추상화        | v1.2.0 (Interop)    | 프로토콜 계층에서 제공되는 프로그래머블 스마트 계정입니다(ERC-4337과 유사). 멀티시그, 소셜 리커버리, 세션 기반의 세 가지 계정 유형이 있습니다. 세분화된 권한과 만료 시점을 가진 세션 키, 계정별 일일 및 트랜잭션별 지출 규칙, 범위가 지정된 디놈(denom) 허용 목록, 합의 단계에서의 자동 규칙 시행을 포함합니다.                                                                      |
| MEV 방지             | v1.2.0 (Interop)    | 암호화된 멤풀을 위한 FairBlock 임계값 아이덴티티 기반 암호화(tIBE) 프레임워크입니다. 트랜잭션은 포함(인클루전) 이후까지 블록 제안자에게 암호학적으로 불투명한 상태로 유지되어, 프론트러닝과 샌드위치 공격을 방지합니다. FairBlockDecorator 안테 핸들러는 배선이 완료되어 대기 중이며, 키 세리머니 배포 이후 tIBE 임계값 복호화가 활성화됩니다.                                           |
| 가스 추상화            | v1.2.0 (Interop)    | 다중 토큰 가스 결제를 통해 트랜잭션 수수료 지불을 위해 네이티브 QOR을 보유해야 하는 요건이 제거됩니다. 사용자는 승인된 IBC 전송 토큰으로 결제할 수 있습니다: ibc/USDC는 1:1 비율, ibc/ATOM은 10:1 비율입니다. GasAbstractionDecorator는 표준 수수료 차감 전에 네이티브가 아닌 수수료 디놈을 검증하고 변환합니다.                                                                                      |
| 5레인 우선순위 지정      | v1.2.0 (Interop)    | 블록 공간은 다섯 개의 우선순위 레인으로 정적으로 분할됩니다: PQC(우선순위 100, 공간 15%), MEV(90, 20%), AI(80, 15%), Default(50, 40%), Free(10, 10%)입니다. 보안이 중요한 트랜잭션은 대량의 표준 트래픽에 의해 밀려날 수 없습니다.                                                                                                                                     |
| 온체인 유동성 (AMM)   | v1.2.0 (Interop)    | 네이티브 자동화된 마켓 메이커(`x/amm`)가 프로토콜 계층에서 온체인 유동성 풀과 스왑을 제공합니다.                                                                                                                                                                                                                                                                                     |
| RDK 롤업                | v1.3.0 (Rollups)    | 네 가지 정산 패러다임(optimistic, zk, based, sovereign), 다섯 가지 프리셋 프로필(defi, gaming, nft, enterprise, custom), SHA-256 블롭 저장소와 자동 정리 기능을 갖춘 네이티브 DA 라우터, 구성 가능한 생성 소각률을 가진 뱅크 에스크로 라이프사이클, EndBlocker 자동 파이널라이제이션, 합의 모듈을 통한 PRISM 지원 구성을 제공하는 롤업 개발 키트입니다. 롤업 기능은 호스트 체인 프레임워크 형태로 제공됩니다.                          |
| 체인 라이선싱            | v1.3.0 (Rollups)    | `x/license` 모듈은 프로토콜 네이티브 체인 라이선싱을 제공합니다.                                                                                                                                                                                                                                                                                                                              |

## 버전 기록

<details>

<summary>v1.0.0 — 제네시스 릴리스</summary>

포스트 퀀텀 암호화(Dilithium-5, ML-KEM-1024), 온체인 강화학습 합의 레이어인 PRISM, 크로스 VM 메시징을 갖춘 트리플 VM 런타임(EVM, CosmWasm, SVM), 고정 공급 토크노믹스 엔진(소각, xQORE, 한정된 발행 예산), 트리플 풀 복합 PoS 검증인 선정, QDRW 이차 거버넌스, AI 트랜잭션 처리 파이프라인 등 핵심 프로토콜을 확립했습니다.

</details>

<details>

<summary>v1.1.0 — 보안 강화 릴리스</summary>

고전 방식 secp256k1(ECDSA) 서명과 ML-DSA-87을 결합한 하이브리드 서명 아키텍처(거버넌스로 제어되는 세 가지 시행 모드 포함), 향후 머클 트리 교체를 위한 SHAKE-256 포스트 퀀텀 해시 기반, TEE 증명(SGX, TDX, SEV-SNP, ARM CCA) 및 연합 학습 조정(FedAvg, FedProx, SCAFFOLD)을 위한 프로덕션급 인터페이스 사양을 도입했습니다.

</details>

<details>

<summary>v1.2.0 — 상호운용성 및 UX 릴리스</summary>

크로스체인 연결성(8개 IBC 채널 + 36개 외부 체인을 다루는 37개 QCB 설정, 현재 테스트넷/보류 상태), Babylon Protocol을 통한 BTC 리스테이킹, 세션 키와 소셜 리커버리를 갖춘 스마트 계정 추상화, FairBlock MEV 방지 프레임워크, 다중 토큰 가스 추상화, 온체인 유동성(`x/amm`), 5레인 블록 공간 우선순위 지정을 추가했습니다.

</details>

<details>

<summary>v1.3.0 — 롤업 생태계 릴리스</summary>

네 가지 정산 패러다임(optimistic, zk, based, sovereign), 다섯 가지 프리셋 배포 프로필(defi, gaming, nft, enterprise, custom), 네이티브 DA 라우터, 뱅크 에스크로 라이프사이클 관리, EndBlocker 기반 자동 파이널라이제이션, PRISM 지원 롤업 구성, 체인 라이선싱(`x/license`)을 갖춘 롤업 개발 키트를 출시했습니다. 자동 사이드체인 등록 및 상태 앵커링을 위해 멀티레이어 아키텍처 모듈과 긴밀하게 통합됩니다.

</details>
