# QoreX 시작하기

이 페이지에서는 **모바일 앱**을 설치하고 지갑을 생성, 복구 또는 연결하는 과정을 안내합니다. 데스크톱 지갑은 [브라우저 확장 프로그램](/qorex/browser-extension) 문서를 참고하세요. Chrome, Firefox, Safari에서 이용할 수 있습니다.

:::note 모바일 이용 가능 여부
- **Android** — Google Play에서 정식 서비스 중(Android 7.0 이상): https://play.google.com/store/apps/details?id=network.qore.qorex
- **iOS** — App Store에서 정식 서비스 중(iOS 15.1 이상): https://apps.apple.com/us/app/qorex-wallet/id6791256626
:::

## 시작하기 전에: 기기를 보호하세요

QoreX 지갑은 기기에 **강력한 잠금 해제 수단**이 설정되어 있을 때만 생성하거나 가져올 수 있습니다. 이것이 하드웨어 보관소에서 키를 지켜주는 요소입니다. 다음 중 하나면 조건을 충족합니다.

- **iOS** — Face ID 또는 Touch ID.
- **Android** — Class-3 생체 인식(지문, 홍채 또는 3D 얼굴 인식) **또는** 기기 화면 잠금(PIN, 패턴 또는 비밀번호).

:::note Android 2D 얼굴 인식
카메라 기반 2D 얼굴 인식(일부 기기, 예를 들어 특정 Samsung 모델에 있음)은 *약한* 생체 인식으로 간주됩니다. 이것만 사용할 수 있는 경우 QoreX는 그 뒤에 있는 **PIN / 패턴**을 사용하며, 시스템 시트가 이를 자동으로 제공하므로 여전히 보호를 받습니다.
:::

강력한 인증 수단이 등록되어 있지 않으면 생성/가져오기 버튼이 비활성화된 상태로 유지되며, 화면에 무엇을 켜야 하는지 설명이 표시됩니다. 시스템 설정에서 Face ID, 지문 또는 화면 잠금을 설정한 뒤 QoreX로 돌아오세요.

## 첫 실행

앱은 **기기에 지갑이 하나도 없을 때만** 온보딩 화면으로 열립니다. 지갑을 만든 뒤에는 이후 실행할 때마다 곧바로 홈(지갑) 탭으로 이동합니다. 잔액 확인에는 생체 인증이 필요 없지만, **거래 서명에는 항상 필요합니다**.

설정 방법은 세 가지입니다.

### 1. 새 지갑 생성

1. **새 지갑 생성**을 누릅니다.
2. QoreX가 기기에서 **24단어 복구 문구**(256비트 엔트로피)를 생성하여 하드웨어 기반의 생체 인증으로 보호되는 보관소에 곧바로 봉인하고, QoreChain 신원을 파생합니다 — 코인 타입 118, `qor1…` 주소(ETH 및 SOL 계정도 동일한 시드에서 만들어집니다). **지갑을 만드는 동안 앱은 이 문구를 보여주지 않습니다.**
3. **문구를 확인하고 즉시 적어 두세요:** **설정 → 보안 → 복구 문구 보기**를 열고, 생체 인증 또는 기기 PIN으로 확인한 뒤, 24개 단어를 순서대로 종이에 옮겨 적습니다. 오프라인에 보관하세요. 이 문구는 기기를 분실했을 때 지갑을 복구할 수 있는 **유일한** 방법입니다.
4. 원한다면 [소셜 복구](/qorex/security-and-recovery#social-recovery)를 설정하세요. 홈의 **백업 상태** 카드는 소셜 복구만 추적합니다 — 문구를 적어 두었는지는 알 수 없으므로 알림을 보내지 않습니다.

:::danger 3단계를 지금 하세요 — 앱은 아무것도 알려주지 않습니다
지갑을 만든 뒤 앱이 곧바로 홈으로 이동하기 때문에, 문구를 한 번도 적지 않은 채 계속 사용하기 쉽습니다. **무언가를 받거나 보내기 전에 하세요.** 앱을 삭제하거나 분실하거나 휴대폰을 잃어버렸는데 적어 둔 문구도, 미리 설정한 [소셜 복구](/qorex/security-and-recovery#social-recovery)도 없다면, QoreChain Association을 포함해 그 누구도 자금을 되찾아 줄 수 없습니다.
:::

:::caution 복구 문구가 전부입니다
24개 단어를 가진 사람은 누구나 당신의 자금을 통제할 수 있으며, QoreChain Association을 포함해 그 누구도 대신 복구해 줄 수 없습니다. 절대로 문구를 웹사이트에 입력하거나, 공유하거나, 스크린샷 또는 클라우드 메모에 저장하지 마세요. **QoreX를 삭제(제거)하면 해당 기기에 저장된 키도 함께 삭제됩니다** — 직접 적어 둔 문구(또는 미리 설정해 둔 [소셜 복구](/qorex/security-and-recovery#social-recovery))가 없다면, 앱 삭제는 곧 영구적인 접근 상실을 의미합니다. 지갑에 자금을 넣기 전에 미리 백업하세요, 넣은 뒤가 아니라.
:::

### 2. 기존 지갑 복구 {#2-restore-an-existing-wallet}

1. **기존 지갑 복구**를 누릅니다.
2. **복구 문구**(24개 단어를 적어 두었다면) 또는 **소셜 복구**(가디언을 설정해 두었고 문구가 더 이상 없다면 — [소셜 복구](/qorex/security-and-recovery#social-recovery) 참고) 중에서 선택합니다.
3. 복구 문구 경로의 경우: 24개 단어를 순서대로 입력합니다. QoreX는 대소문자와 불필요한 공백을 정리하고 문구를 검증하며, 단어가 맞지 않으면 일반적인 오류 대신 명확하게 알려줍니다.
4. QoreX가 동일한 주소를 다시 파생합니다 — 어떤 기기에서든 지갑이 똑같이 보입니다.

:::note 추가 계정은 하나씩 복원됩니다
문구로 복구하면 **계정 1**이 복원됩니다. 이전 지갑에서 여러 계정을 사용했다면 **계정 추가**(설정 → 내 계정)를 눌러 다음 계정을 차례로 되살리세요 — 같은 문구에서 파생되므로 동일한 주소로 다시 나타납니다. 이더리움 방식 계정은 **이더리움 계정 추가(코인 60)**로 추가합니다. [MetaMask 또는 대시보드의 문구 복구하기](#restore-dashboard)를 참고하세요. 이전 지갑에서 만든 순서와 같은 순서로 추가하세요. 계정은 슬롯별로 번호가 매겨지므로, 새 기기에서 순서가 다르면 같은 슬롯에 다른 계정이 생길 수 있습니다.
:::

### 3. 다른 기기에서 연결

다른 휴대폰이나 태블릿에 이미 QoreX가 있다면 **서버도 필요 없고 입력할 것도 없이** 지갑을 옮길 수 있습니다 — [새 기기 연결](/qorex/security-and-recovery#link-device)을 참고하세요. 새 기기에서 **다른 기기에서 연결**을 선택해 시작하세요.

## 한 기기에 여러 지갑 {#several-wallets}

각 지갑에는 **자체 복구 문구**가 있습니다. 한 휴대폰에 여러 개를 두고 — 예를 들어 메인 지갑과 다른 서비스에서 복구한 지갑 — 한 번의 탭으로 전환할 수 있습니다.

- **모바일:** 설정 → **지갑**에 이 휴대폰의 지갑 목록이 표시됩니다. 하나를 누르면 활성 지갑이 되며 앱 전체가 그 지갑으로 전환됩니다(체인에서는 아무것도 이동하지 않습니다). **지갑 추가**에서는 새 지갑을 만들거나, 복구 문구로 복구하거나, 다른 기기에서 연결할 수 있으며, 기존 지갑은 그대로 유지됩니다. 이미 휴대폰에 있는 문구를 복구하면 해당 지갑으로 전환될 뿐입니다.
- **확장 프로그램:** 팝업의 **지갑** 화면에서 같은 작업을 할 수 있으며, 모든 지갑에 **비밀번호 하나**를 사용합니다. 지갑을 추가하거나 제거할 때는 보관소를 다시 봉인하기 위해 비밀번호를 한 번 묻고, 패스키 잠금 해제가 꺼집니다(홈 화면에서 다시 켜세요).
- **지갑 제거**(*이 휴대폰에서 제거* / *이 브라우저에서 제거*)는 해당 지갑의 키를 기기에서 삭제합니다. 자금은 체인에 그대로 남아 있지만, 복구 문구로만 되살릴 수 있으므로 먼저 적어 두세요.

## MetaMask 또는 대시보드의 문구 복구하기 {#restore-dashboard}

기본적으로 QoreX는 복구 문구에서 코인 타입 **118**로 `qor1…` 주소를 파생합니다. 처음에 MetaMask에서 사용했거나 QoreChain 대시보드에서 만든 지갑의 문구는 QOR를 대신 **이더리움 방식** 주소(코인 타입 **60**)에 보관하므로, 복구하면 **계정 1**이 비어 있는 것으로 보입니다. 잃어버린 것은 없습니다. 이더리움 방식 계정을 추가하세요.

1. 스토어에서 QoreX를 현재 버전으로 업데이트합니다.
2. **지갑 추가**(설정 → 지갑 → *지갑 추가* → *기존 지갑 복구*)를 누르고 문구를 입력합니다. 기존 지갑은 그대로 유지됩니다. 확장 프로그램에서는 **지갑** → 복구를 선택합니다.
3. 설정 → **내 계정**을 열고 **이더리움 계정 추가(코인 60)**를 누릅니다. 처음 누르면 인덱스 0의 계정이 추가됩니다 — MetaMask가 해당 단어에 대해 보여주는 것과 같은 `0x…` 주소이며, 그 계정의 QoreChain `qor1…` 주소와 같은 키입니다. QOR는 그곳에 있습니다.
4. 해당 계정으로 전환합니다(*Ethereum · coin 60*이라는 라벨이 붙어 있습니다). 이 계정에서 보내기, 스테이킹, 수령을 할 수 있습니다. 첫 전송 시 해당 계정의 양자 이후(post-quantum) 키도 함께 등록되며, 소액의 일회성 수수료가 듭니다.

이더리움 방식 계정에는 @handle이 없으며(handle은 코인 타입 118의 QoreChain `qor1…` 계정에서 등록합니다), 웹사이트는 이 계정으로 `signDirect` 대신 `signAndBroadcast`를 통해 서명합니다. **이더리움 계정 추가(코인 60)**를 누를 때마다 다음 인덱스가 추가됩니다.

## 앱 둘러보기 {#find-your-way}

- **검색** — 홈 상단의 돋보기로 화면("stake"), 코인("USDC"), 사람(@handle 또는 주소), 메모, 거래 해시의 앞부분을 검색할 수 있습니다. @handle이나 `qor1…` 주소를 입력하면 **… 에게 QOR 보내기**가 바로 표시됩니다.
- **투어** — 지갑을 처음 홈에서 열면 QoreX가 하는 일과 각 기능의 위치를 설명하는 짧은 카드 다섯 장이 나옵니다. 한 번만 실행되며, 설정 → **투어 다시 보기**에서 다시 볼 수 있습니다.

## 선택 사항: @handle 등록

지갑을 만든 뒤에는 고유한 **@handle**(예: `@liviu`)을 등록해서 `qor1…` 주소 대신 이름으로 송금을 받을 수 있습니다. 이는 선택 사항이며 건너뛸 수 있습니다 — 지갑이 여기에 의존하는 일은 없습니다. (브라우저 확장 프로그램에서는 일부 버전이 등록을 지원하지 않습니다. 팝업에 없으면 모바일 앱에서 등록하세요.) handle은 지갑 전체가 아니라 특정 주소에 연결되므로, 계정을 두 개 이상 갖게 되는 순간부터 중요해집니다 — [하나의 문구에서 나오는 여러 계정](/qorex/account-and-dashboard#accounts)과 [@handle](/qorex/account-and-dashboard#handle)을 참고하세요.

## 언어

QoreX는 영어, 루마니아어, 독일어, 스페인어, 프랑스어, 이탈리아어, 터키어, 아랍어, 일본어, 한국어 등 10개 언어로 제공되며, 휴대폰의 언어 설정을 자동으로 따르고 그 외 언어는 영어로 대체됩니다. **설정 → 언어**에서 언제든 감지된 언어를 재정의할 수 있으며, 아랍어를 선택하면 인터페이스도 오른쪽에서 왼쪽으로 바뀝니다.
