# QoreX 시작하기

이 페이지에서는 **모바일 앱**을 설치하고 지갑을 생성, 복구 또는 연결하는 과정을 안내합니다. 데스크톱 지갑은 [브라우저 확장 프로그램](/qorex/browser-extension) 문서를 참고하세요. Chrome, Firefox, Safari에서 이용할 수 있습니다.

:::note 모바일 이용 가능 여부
- **Android** — Google Play에서 정식 서비스 중: https://play.google.com/store/apps/details?id=network.qore.qorex
- **iOS** — App Store에서 정식 서비스 중: https://apps.apple.com/us/app/qorex-wallet/id6791256626
:::

## 시작하기 전에: 기기를 보호하세요

QoreX 지갑은 기기에 **강력한 잠금 해제 수단**이 설정되어 있을 때만 생성하거나 가져올 수 있습니다. 이것이 하드웨어 보관소에서 키를 지켜주는 요소입니다. 다음 중 하나면 조건을 충족합니다.

- **iOS** — Face ID 또는 Touch ID.
- **Android** — Class-3 생체 인식(지문, 홍채 또는 3D 얼굴 인식) **또는** 기기 화면 잠금(PIN, 패턴 또는 비밀번호).

:::note Android 2D 얼굴 인식
카메라 기반 2D 얼굴 인식(일부 기기, 예를 들어 특정 Samsung 모델에 있음)은 *약한* 생체 인식으로 간주됩니다. 이것만 사용할 수 있는 경우 QoreX는 그 뒤에 있는 **PIN / 패턴**을 사용하며, 시스템 시트가 이를 자동으로 제공하므로 여전히 보호를 받습니다.
:::

강력한 인증 수단이 등록되어 있지 않으면 생성/가져오기 버튼이 비활성화된 상태로 유지되며, 화면에 무엇을 켜야 하는지 설명이 표시됩니다. 시스템 설정에서 Face ID, 지문 또는 화면 잠금을 설정한 뒤 QoreX로 돌아오세요.

## 첫 실행

앱은 **기기에 지갑이 하나도 없을 때만** 온보딩 화면으로 열립니다. 지갑을 만든 뒤에는 이후 실행할 때마다 곧바로 홈(지갑) 탭으로 이동합니다. 잔액 확인에는 생체 인증이 필요 없지만, **거래 서명에는 항상 필요합니다**.

설정 방법은 세 가지입니다.

### 1. 새 지갑 생성

1. **새 지갑 생성**을 누릅니다.
2. QoreX가 기기에서 **24단어 복구 문구**(256비트 엔트로피)를 생성하고 QoreChain 신원을 파생합니다 — 코인 타입 118, `qor1…` 주소(ETH 및 SOL 계정도 동일한 시드에서 만들어집니다).
3. **24개 단어를 적어 두고** 오프라인에 보관하세요. 이 문구는 기기를 분실했을 때 지갑을 복구할 수 있는 **유일한** 방법입니다.
4. 문구를 확인하면 QoreX가 하드웨어 기반의 생체 인증으로 보호되는 보관소에 이를 봉인합니다.

:::caution 복구 문구가 전부입니다
24개 단어를 가진 사람은 누구나 당신의 자금을 통제할 수 있으며, QoreChain Association을 포함해 그 누구도 대신 복구해 줄 수 없습니다. 절대로 문구를 웹사이트에 입력하거나, 공유하거나, 스크린샷 또는 클라우드 메모에 저장하지 마세요. **QoreX를 삭제(제거)하면 해당 기기에 저장된 키도 함께 삭제됩니다** — 직접 적어 둔 문구(또는 미리 설정해 둔 [소셜 복구](/qorex/security-and-recovery#social-recovery))가 없다면, 앱 삭제는 곧 영구적인 접근 상실을 의미합니다. 지갑에 자금을 넣기 전에 미리 백업하세요, 넣은 뒤가 아니라.
:::

### 2. 기존 지갑 복구 {#2-restore-an-existing-wallet}

1. **기존 지갑 복구**를 누릅니다.
2. **복구 문구**(24개 단어를 적어 두었다면) 또는 **소셜 복구**(가디언을 설정해 두었고 문구가 더 이상 없다면 — [소셜 복구](/qorex/security-and-recovery#social-recovery) 참고) 중에서 선택합니다.
3. 복구 문구 경로의 경우: 24개 단어를 순서대로 입력합니다. QoreX는 대소문자와 불필요한 공백을 정리하고 문구를 검증하며, 단어가 맞지 않으면 일반적인 오류 대신 명확하게 알려줍니다.
4. QoreX가 동일한 주소를 다시 파생합니다 — 어떤 기기에서든 지갑이 똑같이 보입니다.

:::note 버전 요구 사항
복구 문구로 직접 복구하려면 QoreX 모바일 **1.0.4 이상**이 필요합니다. 이전 버전에서는 **기존 지갑 복구**에서 가디언 경로만 제공됩니다 — [어느 버전이 어디에 배포되어 있는지](/qorex/overview#platform-availability) 확인하고 필요하면 업데이트하세요.
:::

### 3. 다른 기기에서 연결

다른 휴대폰이나 태블릿에 이미 QoreX가 있다면 **서버도 필요 없고 입력할 것도 없이** 지갑을 옮길 수 있습니다 — [새 기기 연결](/qorex/security-and-recovery#link-device)을 참고하세요. 새 기기에서 **다른 기기에서 연결**을 선택해 시작하세요.

## 선택 사항: @handle 등록

지갑을 만든 뒤에는 고유한 **@handle**(예: `@liviu`)을 등록해서 `qor1…` 주소 대신 이름으로 송금을 받을 수 있습니다. 이는 선택 사항이며 건너뛸 수 있습니다 — 지갑이 여기에 의존하는 일은 없습니다. handle은 지갑 전체가 아니라 특정 주소에 연결되므로, 계정을 두 개 이상 갖게 되는 순간부터 중요해집니다 — [하나의 문구에서 나오는 여러 계정](/qorex/account-and-dashboard#accounts)과 [@handle](/qorex/account-and-dashboard#handle)을 참고하세요.

## 언어

QoreX는 영어, 루마니아어, 독일어, 스페인어, 프랑스어, 이탈리아어, 터키어, 아랍어, 일본어, 한국어 등 10개 언어로 제공되며, 휴대폰의 언어 설정을 자동으로 따르고 그 외 언어는 영어로 대체됩니다. **설정 → 언어**에서 언제든 감지된 언어를 재정의할 수 있으며, 아랍어를 선택하면 인터페이스도 오른쪽에서 왼쪽으로 바뀝니다.
