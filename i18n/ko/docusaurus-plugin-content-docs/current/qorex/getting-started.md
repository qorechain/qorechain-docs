# QoreX 시작하기

이 페이지에서는 모바일 앱을 설치하고 지갑을 생성, 복구 또는 연결하는 과정을 안내합니다.

## 시작하기 전에: 기기 보안 설정

QoreX 지갑은 기기에 **강력한 잠금 해제 수단**이 설정되어 있을 때에만 생성하거나 가져올 수 있습니다. 이것이 하드웨어 보관소 안의 키를 보호하는 수단입니다. 다음 중 어느 것이든 조건을 충족합니다:

- **iOS** — Face ID 또는 Touch ID.
- **Android** — Class-3 생체 인증(지문, 홍채 또는 3D 얼굴 인식) **또는** 기기 화면 잠금(PIN, pattern 또는 password).

:::note Android 2D 얼굴 인식
카메라 기반 2D 얼굴 인식(일부 기기, 예를 들어 특정 Samsung 모델에서 볼 수 있음)은 *약한* 생체 인증으로 간주됩니다. 이것만 사용할 수 있는 경우 QoreX는 그 뒤에 있는 **PIN / pattern**에 의존하며, 시스템 시트가 이를 자동으로 제공하므로 여전히 보호받습니다.
:::

강력한 인증 수단이 등록되어 있지 않으면 생성/가져오기 버튼이 비활성화된 상태로 유지되며, 화면에 무엇을 켜야 하는지 설명됩니다. 시스템 설정에서 Face ID, 지문 또는 화면 잠금을 설정한 다음 QoreX로 돌아오세요.

## 첫 실행

앱은 **기기에 지갑이 존재하지 않을 때에만** 온보딩 화면으로 열립니다. 지갑이 생성되면 이후의 모든 실행은 곧바로 홈(지갑) 탭으로 이동합니다. 잔액 조회에는 생체 인증이 필요 없지만, **트랜잭션 서명에는 항상 필요합니다**.

설정 방법은 세 가지입니다:

### 1. 새 지갑 생성

1. **Create a new wallet**를 탭합니다.
2. QoreX가 기기에서 **24단어 복구 문구**를 생성하고(256비트 엔트로피) QoreChain 신원을 파생합니다 — coin type 118, `qor1…` 주소(ETH 및 SOL 계정도 동일한 시드에서 생성됩니다).
3. **24개 단어를 적어서** 오프라인에 보관하세요. 이 문구는 기기를 분실했을 때 지갑을 복구할 수 있는 **유일한** 방법입니다.
4. 문구를 확인하면 QoreX가 이를 하드웨어 기반의 생체 인증 보관소에 봉인합니다.

:::caution 복구 문구가 전부입니다
24개 단어를 가진 사람은 누구든 자금을 통제할 수 있으며, QoreChain Association을 포함해 그 누구도 여러분을 대신해 복구해 줄 수 없습니다. 절대로 문구를 웹사이트에 입력하거나, 공유하거나, 스크린샷이나 클라우드 메모에 저장하지 마세요.
:::

### 2. 기존 지갑 복구

1. **Restore existing wallet**를 탭합니다.
2. 24개 단어를 순서대로 입력합니다.
3. QoreX가 동일한 주소를 다시 파생합니다 — 지갑은 어떤 기기에서도 동일하게 보입니다.

### 3. 다른 기기에서 연결

이미 다른 휴대폰이나 태블릿에 QoreX가 설치되어 있다면, **서버 없이 그리고 입력 없이** 지갑을 옮길 수 있습니다 — [기기 연결하기](/qorex/security-and-recovery#link-device)를 참조하세요. 새 기기에서 **Link from another device**를 선택하여 시작합니다.

## 선택 사항: @handle 등록

지갑이 생성되면 고유한 **@handle**(예: `@liviu`)을 등록하여 사람들이 `qor1…` 주소 대신 이름으로 여러분에게 보낼 수 있게 할 수 있습니다. 이는 선택 사항이며 건너뛸 수 있습니다 — 지갑은 절대 이에 의존하지 않습니다. [계정 및 Dashboard](/qorex/account-and-dashboard#handle)를 참조하세요.
