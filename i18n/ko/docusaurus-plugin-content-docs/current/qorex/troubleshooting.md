# 문제 해결

QoreX 앱과 확장 프로그램에 대한 일반적인 질문과 빠른 해결 방법입니다.

| 증상 | 원인 / 해결 방법 |
|---|---|
| 온보딩 중 **"먼저 기기를 보호하세요"** | 시스템 설정에서 Face ID / 지문 **또는 화면 잠금(PIN / 패턴)** 을 설정한 다음 돌아오세요. 지갑은 강력한 잠금 해제 요소가 있는 기기에서만 생성할 수 있습니다. Android에서 2D 얼굴 잠금 해제만으로는 *약한* 생체 인증입니다. 그 뒤에 있는 PIN이 자격을 충족하는 요소입니다. |
| **로그인 시트가 닫힘** / "해당 로그인 시도가 만료되었습니다" | 이전 시도가 중단되었습니다. 로그인을 다시 탭하기만 하면 됩니다. |
| Google / Dashboard 로그인 후 **"패스키 추가"가 없음** | 정상입니다. 패스키는 이메일 코드 계정에만 연결됩니다([계정 및 Dashboard](/qorex/account-and-dashboard#sign-in)의 참고 사항 참조). |
| **"핸들 곧 제공 예정"** | @handle 레지스트리에 일시적으로 연결할 수 없습니다. 지갑에는 영향이 없으며, 레지스트리가 복구되면 핸들이 자동으로 활성화됩니다. |
| 기기 연결 중 **"코드가 잘못되었거나 QR이 손상됨"** | 10자 코드를 다시 확인하고(알파벳에서 혼동되는 문자는 제외됩니다: 0/O/1/I/L 없음) 다시 스캔하세요. 두 항목 모두 일회용입니다. |
| **카메라 화면에 권한이 필요하다고 표시됨** | iOS: 설정 → QoreX → 카메라. Android: 앱 정보 → 권한 → 카메라. |
| **확장 프로그램: 처음 열었을 때 지갑이 없음** | 확장 프로그램은 **독립형** 지갑입니다. 팝업을 열고 **지갑 생성** 또는 **지갑 가져오기** 를 선택하세요. 모바일 앱이 필요하지 않습니다. |
| **읽기 전용 주소에서 보내기가 거부됨** | 해당 주소는 다른 지갑에 속합니다(레이블에 어느 지갑인지 표시됩니다). QoreX는 자체적으로 파생된 계정에 대해서만 서명할 수 있습니다. 해당 주소를 소유한 지갑에서 보내세요. |
| **테스트넷 배지가 표시됨** | 설정 → **"테스트넷 사용(개발자용)"** 이 켜져 있습니다. 이를 끄면 메인넷으로 돌아갑니다. |
| **스왑 버튼이 비활성화됨** | 현재는 정상입니다. 풀 유동성이 확보되면 스왑이 자동으로 켜지며, 앱 업데이트가 필요하지 않습니다. |

## 여전히 해결되지 않나요?

- 가디언 및 기기 연결에 대해서는 [보안 및 복구](/qorex/security-and-recovery) 페이지를 참조하세요.
- QoreChain 자체에 대한 질문은 [메인 문서](/introduction/what-is-qorechain) 또는 [qorechain.io](https://qorechain.io)에 링크된 커뮤니티 채널을 참조하세요.
