# 포트폴리오 및 스테이킹

## 포트폴리오

**포트폴리오** 화면(세션마다 처음 열 때 생체 인증으로 보호됨)은 **배분 도넛** 차트를 보여줍니다. 이는 세 가지 레인(Native, EVM, SVM)에 걸쳐 통합된 QOR을 나타내며, 링 아래에 캡션이 표시되고 각 자산마다 한 행씩 나열됩니다. 백분율은 가격 피드가 활성화되면 표시됩니다.

자산을 탭하면 **자산 상세** 화면이 열리며, 다음을 보여줍니다.

- **잔액 내역** — 온체인 전송 내역으로부터 만들어진 실제 추세.
- **최근 활동** — 역방향 **@handle** 조회가 적용된 거래 행으로, 가능한 경우 거래 상대방이 이름으로 표시됩니다.

## 스테이킹 및 적립(Earn)

QOR을 스테이킹하면 QoreChain을 보호하는 데 도움이 되고 보상을 받을 수 있습니다. 모든 스테이킹 작업은 포스트 퀀텀 서명이 포함된 실제 온체인 거래입니다.

### 밸리데이터에 스테이킹하기

1. **Stake**를 엽니다.
2. 목록에서 밸리데이터를 선택합니다(체인에서 실시간으로 로드됨).
3. 금액을 입력하고 생체 인증 확인으로 **위임(delegate)**합니다.
4. 보상이 적립될 때마다 같은 화면에서 청구합니다.

:::note 현재는 잠금 기간이 없으며, 대기 시간은 나갈 때만 발생합니다
지금은 선택할 고정된 기간이 없습니다. 실제로 그런 것이 존재하지 않기 때문입니다. 위임은 다음 블록부터 보상이 흘러들어오는 상태로 계속 활성 상태이며, 위임 해제(undelegate)를 요청할 때까지 계속됩니다. 갱신해야 할 만료 기한도, 최소 스테이킹 기간도 없습니다. 유일한 대기 기간은 나갈 때뿐입니다. 위임을 해제하면 해당 QOR은 21일간의 언본딩(unbonding) 기간 동안 보상 없이 이동도 불가능한 상태로 머물다가, 이후 사용 가능한 잔액으로 돌아옵니다. 대신 다른 밸리데이터로 위임을 옮기는 재위임(redelegate)을 사용하면 이 대기 시간을 완전히 건너뛸 수 있습니다. 이는 영구적인 보장이 아니라 현재 체인의 동작을 설명한 것입니다. 자세한 내용은 [잠금 기간이 있나요?](/user-guide/staking-and-delegation#lock-in-period)를 참고하세요.
:::

:::note 이 화면에는 아직 자체 위임 해제(Undelegate) 버튼이 없습니다
이 Stake 화면은 위임(delegate)과 청구(claim)만 다룹니다. QoreX 화면에서 직접 위임을 해제하려면 대신 [브라우저 확장 프로그램의 Stake 화면](/qorex/browser-extension#stake)을 사용하거나, [대시보드](/dashboard/staking-and-validators#delegate)를 통해 위임을 해제하세요. 이 경우 요청은 앱을 포함해 연결되어 있는 QoreX로 전달되어 사용자가 승인하게 됩니다.
:::
