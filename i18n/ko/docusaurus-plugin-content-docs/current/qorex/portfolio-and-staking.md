# 포트폴리오 및 스테이킹

## 포트폴리오

**포트폴리오** 화면(세션마다 처음 열 때 생체 인증으로 보호됨)은 **배분 도넛** 차트를 보여줍니다. 이는 세 가지 레인(Native, EVM, SVM)에 걸쳐 통합된 QOR을 나타내며, 링 아래에 캡션이 표시되고 각 자산마다 한 행씩 나열됩니다. 백분율은 가격 피드가 활성화되면 표시됩니다.

자산을 탭하면 **자산 상세** 화면이 열리며, 다음을 보여줍니다.

- **잔액 내역** — 온체인 전송 내역으로부터 만들어진 실제 추세.
- **최근 활동** — 역방향 **@handle** 조회가 적용된 거래 행으로, 가능한 경우 거래 상대방이 이름으로 표시됩니다.

## 스테이킹 및 적립(Earn)

QOR을 스테이킹하면 QoreChain을 보호하는 데 도움이 되고 보상을 받을 수 있습니다. 모든 스테이킹 작업은 포스트 퀀텀 서명이 포함된 실제 온체인 거래입니다.

### 밸리데이터에 스테이킹하기

1. **Stake**를 엽니다.
2. 목록에서 밸리데이터를 선택합니다(체인에서 실시간으로 로드됨).
3. 금액을 입력하고 생체 인증 확인으로 **위임(delegate)**합니다.
4. 보상이 적립될 때마다 같은 화면에서 청구합니다.

### 적립(Earn)

**Earn** 화면은 활성 포지션과 수익률을 한곳에 요약해서 보여줍니다.
