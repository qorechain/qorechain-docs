# 포트폴리오 및 스테이킹

## 포트폴리오

**포트폴리오** 화면(세션마다 처음 열 때 생체 인증으로 보호됨)은 **배분 도넛** 차트를 보여줍니다. 이는 세 가지 레인(Native, EVM, SVM)에 걸쳐 통합된 QOR을 나타내며, 링 아래에 캡션이 표시되고 각 자산마다 한 행씩 나열됩니다. 백분율은 가격 피드가 활성화되면 표시되며, 각 잔액에는 QOR 수량과 함께 예상 USD 가치가 표시됩니다.

**가격 정보의 출처.** QoreX는 이를 저희의 공개 엔드포인트인 `GET https://api.qore.network/v1/price/{symbol}`에서 읽어오며, 어떤 거래소에도 직접 호출하지 않습니다. 사용자의 기기는 QoreChain 자체 인프라 외의 어떤 가격 소스와도 통신하지 않으므로, IP 주소가 외부에 노출되는 일이 없습니다. 신뢰할 수 있는 가격을 정말로 구할 수 없는 경우, 해당 엔드포인트는 값을 추측하는 대신 오류로 응답합니다 — QoreX는 조작된 0 값이나 오래된 수치를 마치 현재 가격인 것처럼 표시하는 대신, 가격을 사용할 수 없음으로 표시합니다.

자산을 탭하면 **자산 상세** 화면이 열리며, 다음을 보여줍니다.

- **잔액 내역** — 온체인 전송 내역으로부터 만들어진 실제 추세.
- **최근 활동** — 역방향 **@handle** 조회가 적용된 거래 행으로, 가능한 경우 거래 상대방이 이름으로 표시됩니다. 행을 탭하면 금액, 거래 상대방, 블록, 트랜잭션 해시, 서명을 포함한 전체 상세 정보가 열립니다.

## 스테이킹 및 적립(Earn)

QOR을 스테이킹하면 QoreChain을 보호하는 데 도움이 되고 보상을 받을 수 있습니다. 모든 스테이킹 작업은 포스트 퀀텀 서명이 포함된 실제 온체인 거래입니다.

### 밸리데이터에 스테이킹하기

1. **Stake**를 엽니다.
2. 목록에서 밸리데이터를 선택합니다(체인에서 실시간으로 로드되며, 스테이크가 가장 적은 밸리데이터부터 표시되고, 현재 수감(jailed) 상태인 밸리데이터는 제외됩니다 — 그런 밸리데이터에 위임하는 것은 결코 원하는 일이 아니기 때문입니다).
3. 금액을 입력하고 생체 인증 확인으로 **위임(delegate)**합니다.
4. 보상이 적립될 때마다 같은 화면에서 청구합니다.

:::note 현재는 잠금 기간이 없으며, 대기 시간은 나갈 때만 발생합니다
지금은 선택할 고정된 기간이 없습니다. 실제로 그런 것이 존재하지 않기 때문입니다. 위임은 다음 블록부터 보상이 흘러들어오는 상태로 계속 활성 상태이며, 위임 해제(undelegate)를 요청할 때까지 계속됩니다. 갱신해야 할 만료 기한도, 최소 스테이킹 기간도 없습니다. 유일한 대기 기간은 나갈 때뿐입니다. 위임을 해제하면 해당 QOR은 21일간의 언본딩(unbonding) 기간 동안 보상 없이 이동도 불가능한 상태로 머물다가, 이후 사용 가능한 잔액으로 돌아옵니다. 대신 다른 밸리데이터로 위임을 옮기는 재위임(redelegate)을 사용하면 이 대기 시간을 완전히 건너뛸 수 있습니다. 이는 영구적인 보장이 아니라 현재 체인의 동작을 설명한 것입니다. 자세한 내용은 [잠금 기간이 있나요?](/user-guide/staking-and-delegation#lock-in-period)를 참고하세요.
:::

### 밸리데이터 간 스테이크 이동하기(재위임) {#move-stake}

이미 스테이킹한 QOR을 21일 언본딩 대기열을 전혀 거치지 않고 다른 밸리데이터로 옮기거나, 여러 밸리데이터에 나누어 옮길 수 있습니다. 스테이크는 이동하는 내내 계속 보상을 받습니다.

1. **Stake**를 열고, 현재 QOR이 위임되어 있는 밸리데이터를 탭합니다.
2. 이동할 곳을 선택합니다 — 단일 대상을 선택하거나 여러 대상을 한 번에 선택할 수 있습니다. 여러 대상에 나누면 금액이 균등하게 분배되며, 확인하기 전에 각 밸리데이터로 가는 정확한 수치가 표시됩니다.
3. 생체 인증 승인으로 확인합니다. 모든 대상으로의 이동은 **단일 트랜잭션**으로 처리됩니다 — 수수료는 한 번만 발생하며, 전체 이동이 성공하거나 전혀 성공하지 않거나 둘 중 하나입니다.

이는 위임 중인 밸리데이터가 수감(jailed)되거나 수수료율을 인상할 때 취해야 할 조치입니다 — 이 기능이 없었을 때는 유일한 대처법이 스테이킹을 해제하고 21일 동안 아무 보상 없이 기다리는 것뿐이었지만, 대신 이동하면 대기 시간도, 잃는 보상도 없습니다.

:::caution 쌍(pair)별 한도가 존재하며, 한도를 초과해도 수수료는 소비됩니다
체인은 동일한 (출발지, 목적지) 밸리데이터 쌍에 대해 진행 중인 재위임을 **최대 7건**까지 허용합니다 — 일반적인 사용에서는 이 한도에 근접하지 않지만, QoreX는 서명 전에 이 한도를 확인하고 한도에 도달한 경우 경고합니다. 한도를 초과하면 트랜잭션이 온체인에서 실패하지만 네트워크 수수료는 여전히 소비되므로, 이런 이유로 거부된 이동을 기존 이동이 정리될 때까지 기다리지 않고 재시도하지 마세요.
:::

### 위임 해제하기(Undelegate)

1. **Stake**를 열고 밸리데이터를 탭한 뒤, 스테이크를 이동하는 대신 위임 해제를 선택합니다.
2. 금액을 입력합니다 — 확인하기 전에 화면에 **21일 언본딩 기간**과 지불하게 될 **정확한 수수료**가 모두 표시됩니다.
3. 생체 인증 승인으로 확인합니다. QOR은 즉시 보상 적립을 멈추며, 언본딩 기간이 끝나면 다시 사용 가능한 잔액이 됩니다.

### 적립(Earn)

**Earn** 화면은 활성 포지션과 수익률을 한곳에 요약해서 보여줍니다.
