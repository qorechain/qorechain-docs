# 계정 및 대시보드

QoreX는 **계정 없이도 완전히 작동합니다** — 여러분의 키는 계정에 의존하지 않습니다. 로그인은 결제 요청, 대시보드 페어링과 같은 편의 기능을 추가할 뿐이며, @핸들을 등록할 때도 로그인을 요청할 수 있습니다.

## 로그인 {#sign-in}

홈 탭의 **로그인**에서, 또는 온보딩 중에 로그인할 수 있습니다. 방법:

- **이메일 코드** — 이메일을 입력하고 일회용 코드를 받습니다. 이 방식으로 로그인한 후, QoreX는 다음 로그인을 위해 즉시 사용할 수 있는 **패스키**(Face ID / Touch ID / PIN)를 추가하도록 제안합니다. 이는 *계정* 패스키이며, 지갑 키에는 전혀 영향을 주지 않습니다.
- **패스키** — 이전에 등록한 적이 있는 경우.
- **Apple로 로그인** *(iOS 전용)* — Apple은 이름과 이메일만 공유하며, 실제 주소 대신 비공개 릴레이 주소를 사용하도록 할 수 있습니다.
- **Google로 계속하기** — 시스템 인증 시트를 통한 단일 네이티브 전환입니다(앱이 브라우저로 이동하지 않습니다).
- **QORECHAIN 대시보드로 계속하기** — 기존 대시보드 계정(Google 로그인 포함)으로 로그인하고 프로필을 가져옵니다.

:::note
패스키 제안은 **이메일 코드** 로그인 후에만 나타납니다. 아이덴티티 제공자(Apple, Google 또는 대시보드)로 로그인하면 해당 제공자가 자체 인증을 관리하므로, 그 계정에는 패스키를 연결할 수 없습니다.
:::

## 하나의 문구로 여러 계정 {#accounts}

설정 → **내 계정**에서 지갑당 최대 **20개 계정**을 생성하고 전환할 수 있으며, 모두 동일한 24단어 복구 문구로부터 파생됩니다(별도로 백업할 것이 없습니다). 각 계정은 고유한 `qor1…` 주소와 자체 잔액, 자체 선택적 @핸들(핸들은 지갑이 아니라 **주소**에 연결됩니다)을 가지며, 첫 송금 이후에는 자체 포스트 퀀텀 키도 갖게 됩니다. 계정을 탭하면 해당 계정이 사용 중인 계정이 됩니다. 활성 계정이 송금, 수신, 스테이킹, dApp 브라우저에서 사용되는 계정이며 — 전환하면 모든 것이 함께 이동하고, 계정이 두 개 이상 존재할 때는 앱이 현재 어느 계정에 있는지 항상 표시합니다. 계정은 *계정 1, 2, …*로 번호가 매겨지며 이름을 변경할 수 없습니다. 브라우저 확장 프로그램에도 동일한 화면이 있습니다 — [하나의 문구로 여러 계정](/qorex/browser-extension#wallet)을 참고하세요.

- **계정 추가**는 동일한 문구에 다음 계정을 추가합니다. 새 계정은 처음 송금할 때 자체 양자 안전 키를 등록하며, 이때 소액의 일회성 네트워크 수수료가 듭니다.
- **Ethereum 계정 추가(coin 60)**는 MetaMask 또는 QoreChain 대시보드에서 처음 사용한 복구 문구를 위한 것입니다 — 자금이 그곳에 있기 때문입니다. Ethereum 경로 `m/44'/60'`를 사용하며 *Ethereum · coin 60*으로 표시됩니다. `0x…` 주소는 모든 EVM 네트워크에서 동일하며, 해당 QoreChain 계정과 같은 키입니다. [MetaMask 또는 대시보드에서 문구 복원하기](/qorex/getting-started#restore-dashboard)를 참고하세요.
- 새 기기에서 문구를 **복원**하면 **계정 1**만 돌아옵니다. 나머지는 **계정 추가**(및 **Ethereum 계정 추가(coin 60)**)로 복원하세요. 주소 화면(**설정 → 내 주소**)은 별개입니다: 이 지갑의 모든 계정과 다른 지갑에서 연결한 읽기 전용 주소를 나열합니다.

## @핸들 {#handle}

**이중 서명**(레지스트리 ed25519 서명 + 본인의 secp256k1 서명)으로 여러분의 주소에 연결된 고유한 이름(예: `@liviu`)을 등록하세요. 이후 누구나 여러분의 @핸들로 송금할 수 있습니다. 확인 방식은 **최초 확인 후 고정**(trust-on-first-use)이므로, 핸들의 키가 은밀하게 변경되면 QoreX가 이를 표시합니다.

핸들은 지갑이 아니라 주소에 연결되기 때문에, 등록은 **주소별**로 이루어집니다 — [여러 계정](#accounts)이 있다면 각 계정이 자체 @핸들을 가질 수 있으며, 한 계정에 핸들을 등록해도 다른 계정에 자동으로 이름이 부여되지는 않습니다. 브라우저 확장 프로그램에서는 핸들로 송금할 수 있습니다. 팝업에서의 등록은 일부 버전에서는 일반 QoreChain 계정에 제공되고 다른 버전에서는 제공되지 않습니다 — 팝업에서 제공되지 않으면 모바일 앱에서 등록하세요. Ethereum 방식(coin 60) 계정에는 핸들이 없습니다.

핸들 레지스트리에 일시적으로 접속할 수 없는 경우, 화면은 **"핸들 기능 준비 중"**으로 전환되며 나머지 기능은 계속 정상 작동합니다. 레지스트리가 복구되면 핸들 기능도 자동으로 다시 활성화됩니다.

:::note 핸들 등록과 대시보드 연결의 차이
이 둘은 서로 별개의, 관련 없는 동작입니다. @핸들을 등록하면 **다른 사람이 이름으로 여러분에게 송금**할 수 있게 될 뿐, 그 외에는 아무런 영향이 없습니다. 대시보드 연결(아래 참조)은 여러분의 지갑을 대시보드 계정에 연결하여 두 곳에서 동일한 데이터를 표시하도록 합니다. 둘 중 하나만 해도 되고, 둘 다 하지 않아도 됩니다.
:::

## 연결된 계정 {#linked-account}

**설정 → 연결된 계정**은 QoreX 지갑과 대시보드 계정을 양방향으로 연결합니다:

1. 대시보드에 표시된 8자리 코드를 입력하거나, **또는** QoreX에서 코드를 생성(10분간 유효)하여 대시보드에 입력합니다.
2. [여러 계정](#accounts)이 있다면, QoreX 자체 승인 창에서 **어느 계정**을 연결할지 선택할 수 있습니다 — 현재 활성화된 계정을 자동으로 가정하지 않습니다.
3. 연결되면 @핸들과 연결된 주소가 양쪽에 모두 표시됩니다.
4. 언제든지 연결을 해제할 수 있습니다.

**대시보드로 계속하기**를 *통해* 로그인하면 자동으로 두 계정이 연결됩니다 — 별도로 할 일이 없습니다.

## 대시보드 연동 {#dashboard}

대시보드가 연결되면:

- 대시보드의 **QoreX로 연결**은 `qorex://connect` 딥링크와 서명된 소유권 증명을 통해 여러분의 지갑과 페어링됩니다.
- **대시보드에서 시작된 송금**은 QoreX에 `qorex://tx` 요청으로 도착합니다. 이 요청은 해독되어 전체 내용이 여러분에게 표시되며, 생체 인증 승인을 거쳐 **앱 내에서만** 서명되고 — 오직 앱 자체가 파생한 주소에서만 서명됩니다. `qor1…` 주소는 메인넷과 테스트넷 모두에서 동일하게 유효하므로, 대시보드에서 시작된 모든 요청은 대상 네트워크를 명시하며, 그것이 현재 연결된 네트워크와 일치하지 않으면 QoreX는 해당 요청 처리를 거부합니다 — 요청에 따라 네트워크를 임의로 전환하는 일은 결코 없습니다.
- 연결 또는 송금 요청이 도착했을 때 **로그인되어 있지 않다면**, QoreX는 막다른 상황을 피할 수 있도록 인라인 **"대시보드에 로그인"** 단계를 제공합니다.
- **내 주소(설정)** — 이 지갑에서 파생된 모든 계정과, 다른 지갑(Keplr / MetaMask / Phantom)에서 연결한 **읽기 전용** 주소를 나열합니다. 읽기 전용 항목에는 이를 생성한 지갑이 표시되며, 그중 하나에서 송금을 시도하면 해당 항목을 생성한 지갑에서 송금해야 한다는 안내가 표시됩니다.

## 계정 삭제 {#delete-account}

설정 → **계정 삭제**(맨 아래의 빨간색 항목). 확인 절차와 한 번의 생체 인증 잠금 해제를 거치면, QoreX는 다음을 영구적으로 삭제합니다: 이 기기의 지갑과 개인 키, QoreX 레지스트리의 @핸들(있는 경우), QoreChain 대시보드 계정(로그인한 경우), 소셜 복구 설정(구성한 경우). 이 작업은 되돌릴 수 없습니다. QoreX는 비수탁형이므로 **복구 문구를 백업하지 않았다면 모든 자금에 대한 접근 권한을 잃게 됩니다** — 먼저 백업하세요. 서버 측 삭제는 최선의 노력(best-effort)으로 수행되며, 기기 내 삭제는 항상 완료되어 앱을 첫 실행 화면으로 되돌립니다.
