# 보내기 및 받기

홈(지갑) 탭이 여러분의 시작점입니다. 여기에는 **네트워크 배지**(기본값은 MAINNET, 개발자 토글을 활성화한 경우 TESTNET), **총 잔액**(탭하여 숨기기/표시), 그리고 주요 작업인 **보내기 · 받기 · 스왑 · 스테이킹**이 표시됩니다. 자산 목록에는 **QOR**(Native + 포스트 퀀텀 🛡, Native/EVM/SVM 레인 전체에 걸친 하나의 통합 잔액)와 **All networks**(ETH · BNB · POL · ARB 통합 뷰)가 표시됩니다.

## 양자 내성 QOR 보내기

1. **보내기**를 탭합니다.
2. 받는 사람을 `qor1…` 주소 **또는** **@handle**로 입력합니다. 핸들은 확인되고 암호학적으로 검증됩니다(레지스트리 서명 + 소유자 서명 + 최초 사용 시 신뢰(trust-on-first-use) 고정). 핸들의 키가 조용히 변경되면 QoreX가 명시적인 경고를 표시합니다.
3. 금액을 입력합니다. 미리보기에는 받는 사람, 금액, 수수료, 그리고 **Shield** 상태(서명의 포스트 퀀텀 보호 수준)가 표시됩니다.
4. **생체 인증** 승인으로 확인합니다. QoreX는 필수 하이브리드 포스트 퀀텀 서명(ML-DSA-87 + secp256k1)으로 전송에 서명하고 Native 레인에서 이를 브로드캐스트합니다.

**첫** 전송 시 여러분의 포스트 퀀텀 키가 온체인에 자동으로 등록되기도 합니다. 이는 [보안 및 복구](/qorex/security-and-recovery#pqc-key)에서 확인할 수 있습니다. 별도의 단계는 필요하지 않습니다.

## QOR 받기

**받기**를 탭하면 여러분의 `qor1…` 주소가 QR 코드(QoreChain 아이콘이 삽입됨)와 복사 버튼으로 표시됩니다. 둘 중 하나를 보내는 사람과 공유하세요.

## 결제 요청

**요청**을 탭하면([로그인](/qorex/account-and-dashboard#sign-in) 필요) 금액과 선택적 메모로 구성된 결제 요청을 QR 코드나 링크로 생성할 수 있습니다. 이를 스캔하는 사람은 미리 채워진 전송 내용을 보게 됩니다.

## 외부 네트워크 및 토큰

**All networks**(또는 외부 보내기)에서 **ETH, BNB, POL, ARB, SOL**을 네이티브로 보낼 수 있으며, **ERC-20**과 **SPL** 토큰도 보낼 수 있습니다. 이 모든 것은 동일한 복구 문구에서 파생됩니다(ETH는 `m/44'/60'`를 사용하고, SOL은 표준 경로를 사용하며, SPL은 연결된 토큰 계정을 사용합니다).

:::caution 외부 체인은 클래식 전용입니다
다른 블록체인은 포스트 퀀텀 서명을 담을 수 없습니다. 외부 네트워크에서 보낼 때 QoreX는 이를 명시적으로 알립니다(전송은 클래식 서명을 사용하고 **Shield**에 다운그레이드가 표시됩니다). 여러분의 **QOR**는 항상 보호된 Native 레인에 남아 있습니다. Cosmos 기반 외부 전송은 선택적 메모를 지원합니다.
:::

## 스왑

**스왑** 탭은 QoreChain의 온체인 AMM에 연결되어 있지만 비활성화된 상태로 유지됩니다. 버튼에는 **"Swap — coming with pool liquidity"**라고 표시되며, 유동성과 원격 기능 플래그가 이를 켤 때까지 그렇습니다. 그렇게 되면 자동으로 활성화되며, **앱 업데이트는 필요하지 않습니다**.
