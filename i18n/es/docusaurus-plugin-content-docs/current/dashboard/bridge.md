# Puente

Actualmente, el Panel no incluye una pantalla de Puente. Una vista previa anterior se ha retirado y hoy no es posible iniciar transferencias entre cadenas desde el Panel.

:::caution Estado cualificado
El puente entre cadenas se encuentra aún en testnet y se está desplegando de forma progresiva: todavía no es un sistema de mainnet en producción, y sus rutas de cadena siguen pendientes en ambas redes. No des por hecho que ninguna ruta esté activa.
:::

Para entender cómo se validan las transferencias entre cadenas, consulta [Arquitectura del Puente](/architecture/bridge-architecture) y [Transferencia de activos por el puente](/user-guide/bridging-assets). Esta página describirá el flujo del Panel cuando se publique una pantalla de Puente.
