# Puente

Actualmente, el Dashboard no incluye una pantalla de Bridge. Esta página existe para que puedas saber qué está y qué no está disponible: hoy no es posible iniciar transferencias entre cadenas desde el Dashboard, y no existe una página `/bridge` (abrir `dashboard.qorechain.io/bridge` devuelve "not found").

:::caution Estado cualificado
El puente entre cadenas se encuentra aún en testnet y se está desplegando de forma progresiva. Todavía no es un sistema de mainnet en producción, y sus rutas de cadena siguen pendientes en ambas redes. No des por hecho que ninguna ruta esté activa.
:::

## Innovaciones {#innovations}

Todavía no hay nada que usar en el Dashboard, así que no hay innovaciones del Dashboard que enumerar. Cómo valida la cadena las transferencias entre cadenas se describe en [Arquitectura del Puente](/architecture/bridge-architecture).

## Cómo usarlo {#how-to-use}

No puedes iniciar una transferencia por el puente desde el Dashboard. Para saber cómo está previsto que funcionen las transferencias entre cadenas, lee [Transferencia de activos por el puente](/user-guide/bridging-assets) y [Arquitectura del Puente](/architecture/bridge-architecture). Esta página describirá el flujo del Dashboard cuando se publique una pantalla de Bridge.

## Cómo acceder {#how-to-access}

No disponible. No hay ruta, ni entrada en la barra lateral, ni ajuste de inicio de sesión o de red que lo active.

## Dónde está publicado {#where-published}

En ninguna parte del Dashboard. En la página Badges existe una serie de insignias "Bridge" para una función que no está activa; ignórala por ahora.

## Límites y problemas conocidos {#limits}

- No existe ninguna pantalla de Bridge en el Dashboard, ni en mainnet ni en testnet.
- Una vista previa anterior se retiró.
- El puente es un sistema de testnet y en desarrollo; sus rutas están pendientes en ambas redes.
