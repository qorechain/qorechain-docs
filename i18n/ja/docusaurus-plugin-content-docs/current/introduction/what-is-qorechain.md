# QoreChainとは？

QoreChainは、ジェネシスの時点から耐量子暗号を組み込み、AIネイティブなトランザクション処理を備え、EVM、QoreChain Native(CosmWasmランタイム)、SVMのプログラムを単一チェーン上で実行するトリプルVMランタイムを持つ、世界初のレイヤー1ブロックチェーンです。既存のプロトコルに量子耐性を後付けするのではなく、QoreChainは古典的な攻撃者と量子コンピュータによる攻撃者の両方に対して安全であることを前提に、ゼロから設計されており、同時に現代の汎用ブロックチェーンに求められる開発者体験と相互運用性を提供します。

メインネット（`qorechain-vladi`、EVMチェーンID **9801**）は2026年6月7日から稼働しており、チェーンリリース**v3.2.4**（2026年10月23日に高さ3,742,566でガバナンス提案13によって適用）で動作しています。パブリックテストネット（`qorechain-diana`、EVMチェーンID **9800**、2026年10月27日からv3.2.6で稼働）はステージングおよび統合テスト用に並行して稼働しています。ネイティブトークンは**QOR**（表示単位）／**uqor**（基本単位、10^6）で、Bech32プレフィックスはアカウントが`qor`、バリデータが`qorvaloper`です。チェーンはCosmos SDK v0.53上に構築されています。

## コアイノベーション

### 1. 耐量子暗号

QoreChainは、デジタル署名にNIST標準化されたML-DSA-87（Dilithium-5）、鍵カプセル化にML-KEM-1024、デフォルトのアプリケーションハッシュにSHAKE-256を使用しています。ハイブリッド署名は現在、cosmosトランザクション経路において**デフォルトで必須**となっています。cosmos経路のすべてのトランザクションは、古典的なsecp256k1（ECDSA）署名に*加えて*、トランザクション拡張としてDilithium-5（ML-DSA-87）署名を含めなければなりません。古典署名のみのcosmosトランザクションは拒否され、ダウングレード経路は閉じられています（ジェネシスのgentx、PQC鍵の登録／移行トランザクション、および登録済みの鍵を持たないオペレーターアカウントからのunjailのみが例外です）。EVMレーンは標準の`eth_secp256k1`署名を維持するため、Ethereumのツール類はそのまま署名できますが、v3.2.0以降、EVMトランザクションは、登録済みのML-DSA-87鍵を持ち、かつ開いている**EVM認可ウィンドウ**があるアカウントからのみ受理されます。これは耐量子署名されたCosmosレーンのメッセージによって開かれる、期間限定の権限です（[EVM認可ウィンドウ](/getting-started/first-transaction#evm-window)を参照）。古典的な鍵だけでは、EVMレーンで資金を動かすことはできなくなりました。ガバナンスが制御する3つの強制モード（disabled、optional、required）は引き続き利用可能ですが、現在のネットワークのデフォルトは**required**です。アルゴリズム俊敏性（agility）フレームワークにより、暗号標準の進化に応じてガバナンス提案を通じて署名方式をアップグレードできます。

### 2. AIネイティブ処理

**PRISM**（Policy-driven Reinforcement-learning for Intelligent State Machines）は、ブロックのライフサイクルに組み込まれたオンチェーンの強化学習レイヤーで、73,733パラメータの固定小数点PPOポリシーネットワークとサーキットブレーカー式の安全制限で構成されています。現在は観測モードで動作しており、稼働中のネットワークは10ブロックごとに観測値と報酬を記録するだけで、学習済みポリシーはロードされていないため、現時点ではPRISMによって調整されているコンセンサスパラメータはありません。統計的アイソレーションフォレストによる異常検知と多次元リスクスコアリングが、アンテハンドラのチェーン内ですべてのトランザクションを評価し、実行前に不正なパターンを検出します。動的な手数料最適化は、リアルタイムのネットワーク状況に基づいてベース手数料を調整します。すべてのオンチェーンAI推論はバリデータ間で完全に決定論的になるよう設計されており、同一の入力は同一の出力を生成し、外部オラクルへの依存はありません。

### 3. トリプルVMランタイム

QoreChainは、単一のコンセンサス内で3つの仮想マシンをネイティブに実行する唯一のレイヤー1です。

* **EVM** — EIP-1559のガス価格設定とポート8545でのJSON-RPCによる完全なEthereum互換性。Hardhat、Foundry、Remixといった標準ツールを使ってSolidityコントラクトをデプロイできます。
* **QoreChain Native** — Rustで記述されたWebAssemblyスマートコントラクトで、完全なライフサイクル（instantiate、execute、query、migrate）をサポートします。
* **SVM** — ポート8899でのSolana互換JSON-RPCサーバーによるBPFプログラムのデプロイと実行。既存のSolanaクライアントおよびツール類がそのまま動作します。

クロスVMメッセージングにより、3つのランタイムすべてが相互に通信できます。EVMコントラクトはプリコンパイル経由でQoreChain Nativeを呼び出し（そのプリコンパイルが有効化された後）、QoreChain Nativeコントラクトはカスタムメッセージ経由でEVMを呼び出し、SVMプログラムは非同期のイベントベースのブリッジングを通じて参加します。現在、稼働中のネットワークでトランザクションを受け付けるのはEVMランタイムのみです。QoreChain Nativeのコードアップロードとインスタンス化は無効、SVMのトランザクションレーンは無効、メインネットで有効なEVMプリコンパイルはなく（テストネットでは3つが有効）、クロスVM呼び出しメッセージはメインネットでオフになっています。

### 4. 上限付き発行のトークノミクス

バーンエンジンは**12のバーンソース**（ガス手数料、コントラクト作成、AIサービス手数料、ブリッジ手数料、トレジャリーによるバイバック、失敗したトランザクション、xQOREペナルティ、自動バイバック、TGEバーン、ロールアップ作成、トランザクション数のマイルストーン、AMM）を定義しており、これらが中央のバーン会計モジュールに集約されます。メインネットでこれまでにバーンが記録されているのはガス手数料と失敗したトランザクションのチャネルのみです。フィーコレクターに入るすべての資金は、**バリデータに37%、恒久的にバーンされる分が30%、トレジャリーに20%、ステーカーに10%、ライトノードに3%**の配分で分割されます。この配分は、トランザクション手数料にもエポック発行にも同様に適用されます。xQOREガバナンスステーキングの設計により、ユーザーはQORをロックしてガバナンスウェイトを2倍にでき、早期離脱のペナルティは残存する保有者へ再分配されます。ロックおよびアンロックのトランザクションは、まだ稼働中のネットワークには組み込まれていません。

QORは**有限の供給経路**を持ちます。ジェネシス時点で**4,420,000,000 QOR**（計画上は4,500,000,000 QORで、そのうち80,000,000 QORはジェネシス前のトークン生成イベントでバーンされました）、**累積上限590,000,000 QORという厳格なハードキャップ**の下で発行されるステーキング報酬、そしてトークンを恒久的に消滅させるバーンエンジンです。`x/inflation`モジュールは、上限に達するまで43,200ブロックのエポックごとに固定量（2026年10月のガバナンス提案10以降は86,000 QOR）を発行し、その後の報酬はトランザクション手数料のみから支払われます。最新の数値とスケジュールについては[トークノミクス](/architecture/tokenomics#supply-and-emission)を参照してください。

### 5. クロスチェーン接続性

QoreChainは、ネイティブIBCとQoreChain Bridge（QCB）という2つの補完的なプロトコルを通じて、幅広いブロックチェーンエコシステムに接続できるよう設計されています。ブリッジレイヤーは、**37のチェーン設定（36の外部チェーンに、IBC経由で到達するInjectiveを加えたもの）**と最大**8つのIBCカウンターパーティ**を定義しています。クロスチェーンレイヤーは**どちらのネットワークでも稼働していません**。37のチェーン設定はすべて`pending`ステータスで、メインネットにはIBCチャネルがなく、テストネットにはテストチェーンへの単一のテストチャネルがあります。以下の数値は目標としているカバレッジを示すものです。

* **最大8つのIBCカウンターパーティ** — Cosmos Hub、Osmosis、Noble、Celestia、Stride、Akash、Babylon、Injective。クライアント更新、不正動作検知、自動パケットクリアリングを備えた事前設定済みのリレーヤーテンプレートを利用します。
* **37のQCBチェーン設定（36の外部チェーン + IBC経由のInjective）** — 各エンドポイントは、種別ごとのアドレス検証、設定可能な確認深度、サーキットブレーカーによる出来高上限、PQC署名によるバリデータ証明を備えるよう設計されています。対象としている外部チェーンは以下の通りです。
  * **ベースライン（10）:** Ethereum, Solana, TON, BSC, Avalanche, Polygon, Arbitrum, Optimism, Base, Sui
  * **EVM系（14）:** zkSync Era, Linea, Scroll, Blast, Mantle, Hyperliquid, Berachain, Sonic, Sei, Monad, Plasma, Filecoin FVM, Cronos, Kaia
  * **非EVM（5）:** Starknet, XRP Ledger, Stellar, Hedera, Algorand
  * **保留中（7）:** NEAR, Bitcoin, Cardano, Polkadot, Tezos, Tron, Aptos

このアーキテクチャは、EVM、Solana（SVM）、Moveベース（Sui、Aptos）、Cosmos/IBC、UTXO、その他の非EVM系統といった、主要なチェーンタイプすべてをカバーし、エコシステム全体にわたる幅広い相互運用性を提供します。

### 6. ロールアップ開発キット

`x/rdk`モジュールは、アプリケーション固有のロールアップをQoreChainのホストチェーン上に直接デプロイするための、プロトコルネイティブなフレームワークです。ロールアップサポートはホストチェーンのフレームワークとして提供されており、具体的なデプロイに関する記述は目標とする能力として扱ってください。4つの決済パラダイムがサポートされています。

* **Optimistic** — 7日間のチャレンジウィンドウを持つ不正証明方式で、EndBlockerによって自動的に確定されます。
* **ZK（ゼロ知識証明）** — SNARKまたはSTARK証明を用い、検証と同時に即時ファイナリティを実現します。
* **Based** — L1でシーケンスされるトランザクションで、約2ホストブロックでファイナリティに達します。
* **Sovereign** — QoreChainをデータ可用性専用として利用する独立したチェーンです。

5つのプリセットプロファイル（**defi、gaming、nft、enterprise、custom**）により、決済モード、ブロック時間、VMの選択、DAバックエンド、ガスモデルが事前設定された状態でのワンクリックデプロイが可能です。ネイティブのDAルーターは、SHAKE-256でコミットされたBlobストレージを、設定可能な保持期間と自動プルーニングとともに提供します。PRISMコンセンサスモジュールは、AI支援によるロールアップ設定のためのアドバイザリメソッドを提供します。稼働中のネットワークでは、まだロールアップは作成されていません。

### 7. アカウントおよびガスアブストラクション

3つのプログラマブルなタイプ（マルチシグ、ソーシャルリカバリー、セッションベース）を持つスマートアカウントは、きめ細かな権限と有効期限を持つセッションキー、アカウントごとの支出ルール、denomアローリストをサポートします。これにより、標準的なアカウントでは不可能だったウォレットUXパターン、すなわちモバイル向けのdAppセッションキー、ファーストクラスのアカウントタイプとしてのソーシャルリカバリー、プログラマブルな支出上限が実現します。スマートアカウントとリンク済みウォレットの機能は実装済みですが、**メインネットではオフ**になっており（`abstractaccount.enabled = false`）、テストネットでは有効です（`GET /qorechain/abstractaccount/v1/config`で確認できます）。ガスアブストラクションは、ユーザーが対応する非ネイティブトークンで手数料を支払えるように設計されています（設定には`ibc/USDC`と`ibc/ATOM`が記載されています）。ただしIBCチャネルはまだ開通していないため、現在、手数料はQORで支払われます。

## エコシステム

QoreChainには**48のジェネシスモジュール（うち20がQoreChain固有）**が搭載されており、セキュリティ（pqc）、AI（ai、reputation、rlconsensus）、コンセンサス（qca）、仮想マシン（vm、svm、crossvm）、トークノミクス（burn、xqore、inflation）、流動性（amm）、ライセンス（license）、ブリッジ（bridge、babylon、multilayer）、ガバナンス拡張（abstractaccount、fairblock、gasabstraction）、ロールアップ（rdk）をカバーしています。最近の追加としては、AMM／オンチェーン流動性のための`x/amm`と、チェーンライセンスのための`x/license`があります。このチェーンはオープンコアアーキテクチャを採用しており、プロトコルレイヤーは完全にオープンソースで、エンタープライズ向けデプロイのためのオプションのプロプライエタリ拡張機能があります。
