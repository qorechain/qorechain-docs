# QoreChainとは？

QoreChainは、ジェネシスの時点から耐量子暗号を組み込み、AIネイティブなトランザクション処理を備え、EVM、CosmWasm、SVMのプログラムを単一チェーン上で実行するトリプルVMランタイムを持つ、世界初のレイヤー1ブロックチェーンです。既存のプロトコルに量子耐性を後付けするのではなく、QoreChainは古典的な攻撃者と量子コンピュータによる攻撃者の両方に対して安全であることを前提に、ゼロから設計されており、同時に現代の汎用ブロックチェーンに求められる開発者体験と相互運用性を提供します。

メインネット（`qorechain-vladi`、EVMチェーンID **9801**）は2026年6月7日から稼働しており、チェーンバージョン**v3.1.92**で動作しています。パブリックテストネット（`qorechain-diana`、EVMチェーンID **9800**）はステージングおよび統合テスト用に並行して稼働しています。ネイティブトークンは**QOR**（表示単位）／**uqor**（基本単位、10^6）で、Bech32プレフィックスはアカウントが`qor`、バリデータが`qorvaloper`です。チェーンはCosmos SDK v0.53上に構築されています。

## コアイノベーション

### 1. 耐量子暗号

QoreChainは、デジタル署名にNIST標準化されたML-DSA-87（Dilithium-5）、鍵カプセル化にML-KEM-1024、デフォルトのアプリケーションハッシュにSHAKE-256を使用しており、古典的な攻撃者と量子コンピュータによる攻撃者の両方に対する安全性を提供します。ハイブリッド署名は現在、cosmosトランザクション経路において**デフォルトで必須**となっています。cosmos経路のすべてのトランザクションは、古典的なsecp256k1（ECDSA）署名に*加えて*、トランザクション拡張としてDilithium-5（ML-DSA-87）署名を含めなければなりません。古典署名のみのcosmosトランザクションは拒否され、ダウングレード経路は閉じられています（ジェネシスのgentxと、PQC鍵の登録／移行トランザクションのみが例外です）。EVMトランザクションは影響を受けません。EVMは別系統の`eth_secp256k1`アンテ処理経路（QoreChain EVM Engine経路）を使用しており、ハイブリッド署名は必須ではありません。ガバナンスが制御する3つの強制モード（disabled、optional、required）は引き続き利用可能ですが、現在のネットワークのデフォルトは**required**です。アルゴリズム俊敏性（agility）フレームワークにより、暗号標準の進化に応じてガバナンス提案を通じて署名方式をアップグレードできます。

### 2. AIネイティブ処理

オンチェーンの強化学習エージェント（73,733パラメータのPPO MLP）がブロックのライフサイクル内で直接、決定論的な固定小数点推論を実行し、ブロック時間・ガスリミット・バリデータプールの重みといったコンセンサスパラメータを動的に調整します。この最適化レイヤーは**PRISM**（Policy-driven Reinforcement-learning for Intelligent State Machines）というブランド名で呼ばれています。統計的アイソレーションフォレストによる異常検知と多次元リスクスコアリングが、アンテハンドラのチェーン内ですべてのトランザクションを評価し、実行前に不正なパターンを検出します。動的な手数料最適化は、リアルタイムのネットワーク状況に基づいてベース手数料を調整します。すべてのAI推論はバリデータ間で完全に決定論的であり、同一の入力は同一の出力を生成し、外部オラクルへの依存はありません。

### 3. トリプルVMランタイム

QoreChainは、単一のコンセンサス内で3つの仮想マシンをネイティブに実行する唯一のレイヤー1です。

* **EVM** — EIP-1559のガス価格設定とポート8545でのJSON-RPCによる完全なEthereum互換性。Hardhat、Foundry、Remixといった標準ツールを使ってSolidityコントラクトをデプロイできます。
* **CosmWasm** — Rustで記述されたWebAssemblyスマートコントラクトで、完全なライフサイクル（instantiate、execute、query、migrate）をサポートします。
* **SVM** — ポート8899でのSolana互換JSON-RPCサーバーによるBPFプログラムのデプロイと実行。既存のSolanaクライアントおよびツール類がそのまま動作します。

クロスVMメッセージングにより、3つのランタイムすべてが相互に通信できます。EVMコントラクトはプリコンパイル経由でCosmWasmを呼び出し、CosmWasmコントラクトはカスタムメッセージ経由でEVMを呼び出し、SVMプログラムは非同期のイベントベースのブリッジングを通じて参加します。

### 4. 固定供給トークノミクス

10種類の異なるバーン（焼却）チャネル（トランザクション手数料、ガバナンス違反のペナルティ、スラッシング、ブリッジ手数料、スパム抑止、エポック超過分、手動バーン、コントラクトコールバック、クロスVM手数料、ロールアップ作成バーン）が、中央のバーン会計モジュールに集約されます。徴収された手数料は**バリデータに37%、恒久的にバーンされる分が30%、トレジャリーに20%、ステーカーに10%、ライトノードに3%**の配分で分割されます。xQOREガバナンスステーキングの仕組みにより、ユーザーはQORをロックしてガバナンスウェイトを2倍にでき、PvPリベース再分配も適用されます。早期離脱のペナルティは残存する保有者へ再分配され、長期保有を貫いた者が報われる仕組みです。

QoreChainは、永続的なパーセンテージ型インフレではなく、有限の発行予算を持つ**固定供給**モデルを採用しています。総供給量は**4,500,000,000 QOR**に固定されており、そのうち**80,000,000（1.78%）**がTGE時にバーンされました。ステーキング報酬は、専用の**590,000,000 QOR**プールから複数年にわたるスケジュールで支払われます。

| 期間 | 目標APY | 発行予算 |
| --- | --- | --- |
| 1年目 | 8–12% | 127,500,000 QOR |
| 2年目 | 6–10% | 106,250,000 QOR |
| 3〜4年目 | 5–8% | 年あたり85,000,000 QOR |
| 5年目以降 | ガバナンスが決定 | 残り約186,000,000 QOR |

10種類のバーンチャネルと組み合わさることで、この固定供給設計はトランザクション量の増加に伴い、純デフレ的な挙動へと収束していきます。

### 5. クロスチェーン接続性

QoreChainは、ネイティブIBCとQoreChain Bridge（QCB）という2つの補完的なプロトコルを通じて、幅広いブロックチェーンエコシステムに接続できるよう設計されています。ブリッジレイヤーは、**37のQCBチェーン設定（QoreChain自身をネイティブなループバックとして含む）**と**8つのIBCチャネル**を定義しており、合計で**36の外部チェーン**をカバーしています。クロスチェーンレイヤーは現時点では**テストネット／保留ステータスであり、まだ本番運用ではありません**。以下の数値は目標としているカバレッジを示すものです。

* **8つのIBCチャネル** — Cosmos Hub、Osmosis、Noble、Celestia、Stride、Akash、Babylon、Injective。クライアント更新、不正動作検知、自動パケットクリアリングを備えた事前設定済みのリレーヤーテンプレートを利用します。
* **37のQCB設定（36の外部チェーン + QoreChainループバック）** — 各エンドポイントは、種別ごとのアドレス検証、設定可能な確認深度、サーキットブレーカーによる出来高上限、PQC署名によるバリデータ証明を備えるよう設計されています。対象としている外部チェーンは以下の通りです。
  * **ベースライン（10）:** Ethereum, Solana, TON, BSC, Avalanche, Polygon, Arbitrum, Optimism, Base, Sui
  * **EVM系（14）:** zkSync Era, Linea, Scroll, Blast, Mantle, Hyperliquid, Berachain, Sonic, Sei, Monad, Plasma, Filecoin FVM, Cronos, Kaia
  * **非EVM（5）:** Starknet, XRP Ledger, Stellar, Hedera, Algorand
  * **保留中（7）:** NEAR, Bitcoin, Cardano, Polkadot, Tezos, Tron, Aptos

このアーキテクチャは、EVM、Solana（SVM）、Moveベース（Sui、Aptos）、Cosmos/IBC、UTXO、その他の非EVM系統といった、主要なチェーンタイプすべてをカバーし、エコシステム全体にわたる幅広い相互運用性を提供します。

### 6. ロールアップ開発キット

`x/rdk`モジュールは、アプリケーション固有のロールアップをQoreChainのホストチェーン上に直接デプロイするための、プロトコルネイティブなフレームワークです。ロールアップサポートはホストチェーンのフレームワークとして提供されており、具体的なデプロイに関する記述は目標とする能力として扱ってください。4つの決済パラダイムがサポートされています。

* **Optimistic** — 7日間のチャレンジウィンドウを持つ不正証明方式で、EndBlockerによって自動的に確定されます。
* **ZK（ゼロ知識証明）** — SNARKまたはSTARK証明を用い、検証と同時に即時ファイナリティを実現します。
* **Based** — L1でシーケンスされるトランザクションで、約2ホストブロックでファイナリティに達します。
* **Sovereign** — QoreChainをデータ可用性専用として利用する独立したチェーンです。

5つのプリセットプロファイル（**defi、gaming、nft、enterprise、custom**）により、決済モード、ブロック時間、VMの選択、DAバックエンド、ガスモデルが事前設定された状態でのワンクリックデプロイが可能です。ネイティブのDAルーターは、SHA-256でコミットされたBlobストレージを、設定可能な保持期間と自動プルーニングとともに提供します。PRISMコンセンサスモジュールは、AI支援によるロールアップ設定のためのアドバイザリメソッドを提供します。

### 7. アカウントおよびガスアブストラクション

3つのプログラマブルなタイプ（マルチシグ、ソーシャルリカバリー、セッションベース）を持つスマートアカウントは、きめ細かな権限と有効期限を持つセッションキー、アカウントごとの支出ルール、denomアローリストをサポートします。これにより、標準的なアカウントでは不可能だったウォレットUXパターン、すなわちモバイル向けのdAppセッションキー、ファーストクラスのアカウントタイプとしてのソーシャルリカバリー、コンセンサスレベルで強制されるプログラマブルな支出上限が実現します。ガスアブストラクションにより、手数料支払いのためにネイティブQORを保有する必要がなくなり、ユーザーはUSDCやATOMなど、対応するIBC転送トークンで支払うことができます。

## エコシステム

QoreChainには**45以上のジェネシスモジュール（うち20以上がカスタムモジュール）**が搭載されており、セキュリティ（pqc）、AI（ai、reputation、rlconsensus）、コンセンサス（qca）、仮想マシン（vm、svm、crossvm）、トークノミクス（burn、xqore、inflation）、流動性（amm）、ライセンス（license）、ブリッジ（bridge、babylon、multilayer）、ガバナンス拡張（abstractaccount、fairblock、gasabstraction）、ロールアップ（rdk）をカバーしています。最近の追加としては、AMM／オンチェーン流動性のための`x/amm`と、チェーンライセンスのための`x/license`があります。このチェーンはオープンコアアーキテクチャを採用しており、プロトコルレイヤーは完全にオープンソースで、エンタープライズ向けデプロイのためのオプションのプロプライエタリ拡張機能があります。
