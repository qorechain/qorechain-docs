# Build Before Q-Day

**Build Before Q-Day** は、[build.qorechain.io](https://build.qorechain.io) でオンライン開催される QoreChain の開発者フェストで、ハッシュタグは #BuildBeforeQDay です。参加者はレベルを選び、オープンソースのキットを使って QoreChain テストネット上で開発し、公開の場で成果を発信して、審査員とコミュニティの前でプロジェクトを発表します。フェストと並行して、毎週1回、技術ワークショップが開かれます。各ワークショップには、最初のコマンドから最後のコマンドまで通した完全なステップバイステップガイドがこのセクションにあるので、自分のペースで、自分のコンピューターですべてを進められます。各ワークショップのサンプルアプリは、公開リポジトリ [github.com/qorechain/build-before-qday](https://github.com/qorechain/build-before-qday) にまとめられています。

## 革新的な点 {#innovations}

このセクションのどのワークショップも、QoreChain を特徴づける機能を軸に組み立てられています。

- **ハイブリッド署名。** トランザクションは2回署名されます。1回は従来型の secp256k1 鍵、もう1回はポスト量子の ML-DSA-87 鍵です。従来型の鍵だけを盗んだ人は、2つ目の署名を作れません。
- **オンチェーンで検証。** バリデーターが両方の署名を確認します。トランザクションには `PQCHybridSignature` 拡張が含まれ、チェーンはステータス `verified` の `pqc_hybrid_verify` イベントを発行します。どちらも公開 REST エンドポイントから読み取れ、結果はエクスプローラーでも確認できます。
- **使い慣れたツール。** Hardhat、Foundry、あるいは好みの言語をそのまま使えます。ポスト量子鍵と認可ウィンドウの扱いは、キットが引き受けます。

## 仕組み {#how-it-works}

1. **登録。** [build.qorechain.io](https://build.qorechain.io) で GitHub にサインインし、レベルを選び、X と QoreX を接続します。
2. **開発。** キット、毎週のワークショップ、ハッカソン中盤のチャレンジを使って、テストネット上で開発します。コミットと更新は公開フィードに表示されます。
3. **提出。** 締め切りまでに、公開リポジトリ、3分以内の動画、プロジェクトが使うテストネットアドレスを提出します。

参加は無料です。開発はテストネットで行い、テスト用の QOR は[フォーセット](/dashboard/faucet)から入手できます。参加資格、提出、審査の詳しいルールは、フェストサイトのルールのページにあります。賞金総額は合計20,000ドルで、2027年1月からは QOR によるフォローアップグラントもあります。内訳はフェストサイトに掲載されています。

## レベル {#levels}

レベルは登録時に選びます。あとから変更もできます。

| レベル | 対象 |
| --- | --- |
| Quantum Pass | QoreChain や web3 が初めての方。ハイブリッドなポスト量子トランザクションを送り、チェーンから読み戻す小さなアプリを作ります。 |
| Intermediate | dApp を公開した経験がある方。QoreChain SDK と QoreX で完全なアプリケーションを作ります。 |
| Advanced | 3つのトラック。A はエージェント、B は QoreSeal による暗号化アプリケーション、C は EVM と Native の両レーンにまたがるクロス VM アプリです。 |
| Expert | プロトコルインフラ。RDK によるロールアップ、QORel による IBC、カストディ、開発者向けツールです。 |

ワークショップ1は、Quantum Pass レベルが求める内容、つまりオンチェーンで検証されたハイブリッド署名トランザクションを、そのまま扱います。

## スケジュール {#timeline}

時刻はすべて UTC です。

| 日程 | 内容 |
| --- | --- |
| 2026年11月4日 | 登録と開発の開始 |
| 毎週 | ワークショップを1回（全4回）。ステップバイステップガイドはここに掲載 |
| 2026年11月18日 | ハッカソン中盤のチャレンジ開始 |
| 2026年12月2日 23:59 | 提出締め切り |
| 12月3日から5日 | 提出内容の確認 |
| 12月6日から15日 | 審査とピープルズチョイス投票 |
| 12月16日 | 受賞者発表とライブデモショー |
| 12月17日から22日 | 賞金の支払い |
| 2027年1月 | フォローアップグラント |

スケジュールはフェストサイトに掲載されています。

## ワークショップ {#workshops}

| ワークショップ | テーマ | ガイド |
| --- | --- | --- |
| ワークショップ1 | 最初のハイブリッド署名トランザクション | [ワークショップ1](/build-before-qday/workshop-1) |

どのガイドも、何もインストールされていない状態から始まります。まずインストールするものを挙げ、そのあとコマンドを1つずつ進めます。コードを取得し、インストールし、テストネット専用の鍵を作成し、フォーセットでテスト用 QOR を受け取り、実行して、エクスプローラーで結果を確認します。最後に、使用したパッケージとサンプルアプリを紹介します。サンプルアプリはすべて、公開リポジトリ [github.com/qorechain/build-before-qday](https://github.com/qorechain/build-before-qday) にあります。

## どこから始めるか {#where-to-start}

- テストネットで[ワークショップ1](/build-before-qday/workshop-1)を進めます。
- [サンプルアプリ](/build-before-qday/workshop-1/kits)と、その土台になっているキットを見てみましょう。
- QoreChain へのデプロイが初めてなら、先に[5分でデプロイ](/getting-started/deploy-in-5-minutes)をお読みください。
