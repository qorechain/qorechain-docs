# トークン操作

このガイドでは、QOR トークン、トークンの送受信方法、残高の照会、そして QoreChain における手数料分配モデルについて説明します。

:::note
以下のコマンドは **`qorechain-diana`** テストネット（EVM チェーン ID **9800**）を使用しています。メインネット（**`qorechain-vladi`**、EVM チェーン ID **9801**）は 2026年6月7日から稼働しており、高さ 3,742,566 まではリリース **v3.2.3**、そのブロックからは **v3.2.4** を実行します。テストネットは 2026年10月19日から **v3.2.4** を実行しています — メインネットで取引する場合は、**Connecting to Mainnet** ページに記載されたメインネットのチェーン ID とエンドポイントに置き換えてください。
:::

:::caution `tx pqc cosign` で署名する
メインネットとテストネットでは、Cosmos レーンのすべてのトランザクションにハイブリッドのポスト量子署名が必要です。そのため、このページのコマンドは記載のままではブロードキャストされません。コマンドに `--generate-only > tx.json` を追加し、続けて `qorechaind tx pqc cosign tx.json --from mykey --pqc-key mypqc --chain-id <chain-id>` を実行してください。[ハイブリッド署名](/cli-reference/transaction-commands#hybrid-signing) を参照してください。[QoreX](/qorex/overview) と [ダッシュボード](/dashboard/overview) は、この署名を自動的に行います。
:::

## トークン情報

| プロパティ            | 値                             |
| --------------------- | ------------------------------ |
| **表示単位**           | QOR                            |
| **基本単位**           | uqor                           |
| **換算**               | 1 QOR = 1,000,000 uqor (10^6)  |
| **チェーンID**         | `qorechain-vladi`（メインネット）/ `qorechain-diana`（テストネット） |
| **Bech32プレフィックス** | `qor`（例: `qor1abc...xyz`）  |

すべてのオンチェーン金額は **uqor** 単位で表記されます。トランザクションを送信する際は、必ず金額を uqor 単位で指定してください。

## トークンの送信

あるアカウントから別のアカウントへ QOR トークンを送金するには、以下のようにします。

```bash
qorechaind tx bank send <from_address> <to_address> <amount>uqor \
  --chain-id qorechain-diana \
  --gas 400000 --fees 40000uqor
```

**例:** 別のアドレスへ 5 QOR（5,000,000 uqor）を送金する場合:

```bash
qorechaind tx bank send qor1sender... qor1recipient... 5000000uqor \
  --chain-id qorechain-diana \
  --gas 400000 --fees 40000uqor
```

送信者の指定には、生のアドレスの代わりにキー名を使用することもできます。

```bash
qorechaind tx bank send mykey qor1recipient... 5000000uqor \
  --chain-id qorechain-diana \
  --gas 400000 --fees 40000uqor
```

## 残高の照会

任意のアカウントの残高を確認します。

```bash
qorechaind query bank balances <address>
```

**例:**

```bash
qorechaind query bank balances qor1abc...xyz
```

**出力例:**

```yaml
balances:
- amount: "15000000"
  denom: uqor
pagination:
  next_key: null
  total: "0"
```

これは、このアカウントが 15 QOR（15,000,000 uqor）を保有していることを示します。

## 手数料構造

QoreChain のトランザクション手数料は、ネットワークのインセンティブを整合させるため、5つの分配先に配分されます。

| 分配先              | 割合  | 目的                                                       |
| ------------------- | ----- | ---------------------------------------------------------- |
| **バリデーター**     | 37%   | ブロック生成者への報酬とネットワークのセキュリティ確保     |
| **バーン（焼却）**   | 30%   | 供給から永久に除去される                                   |
| **トレジャリー**     | 20%   | プロトコル開発とエコシステム助成金の資金源となる           |
| **ステーカー**       | 10%   | すべてのデリゲーターに比例配分される                       |
| **ライトノード**     | 3%    | ライトノード報酬（下記の注記を参照）                       |

この分配は、手数料コレクターに入るすべて（トランザクション手数料と、各エポックで発行されるステーキング発行分）に適用されます。ライトノードの取り分はライトノード報酬プールに積み立てられます。登録は開放されており、ライセンスによる制限がありますが、まだライトノードが登録されていないため、現時点ではこのプールから支払われているノードはありません（[ライトノード](/light-node/overview#reward-program-status) を参照）。v3.2.0 アップグレード以降、ステーカーの取り分は通常のステーキング報酬として支払われます（[トークノミクス](/architecture/tokenomics#stranded-and-reserve) を参照）。

## バーンチャネル

QoreChain のバーンモジュールは 12 のバーンソースを定義しています。いずれかを通じてバーンされた QOR は、流通から永久に除去されます。メインネットでは、これまでにバーンが記録されたのはガス手数料チャネルと失敗トランザクションチャネルのみで、その他は定義されているものの何も記録されていません。v3.2.4 以降（テストネットでは 2026年10月19日から、メインネットでは高さ 3,742,566 から）は、オプションのタイムロック型ステーキングモジュール用に 13 番目のソース `staking_tier_penalty` があります。

| チャネル              | 説明                                                                 |
| --------------------- | --------------------------------------------------------------------- |
| `gas_fee`             | すべてのガス手数料の 30% がバーンされる                               |
| `contract_create`     | コントラクト作成ごとに一律 100 QOR の手数料がバーンされる（無効: QoreChain Native のアップロードは閉じられています） |
| `ai_service`          | AI サービス手数料の 50% がバーンされる（無効: AI サービス手数料は稼働していません） |
| `bridge_fee`          | ブリッジ手数料の 100% がバーンされる（無効: ブリッジは稼働していません） |
| `treasury_buyback`    | トレジャリーからの定期的なバイバック＆バーン                           |
| `failed_tx`           | 失敗したトランザクションのガスの 10%。v3.2.2 からチェーンが適用        |
| `xqore_penalty`       | バーンに回される xQORE の早期引き出しペナルティ（xQORE は稼働していません） |
| `auto_buyback`        | プロトコルレベルの自動バーン（無効）                                   |
| `tge`                 | 予約済み。TGE のバーンはジェネシス前に行われたため、このチャネルには何も記録されません |
| `rollup_create`       | ロールアップ作成ステークの 1% がバーンされる                           |
| `milestone`           | 累積トランザクション数が一定の値に達した時点で実行される予定のバーン（まだ発動していません） |
| `amm`                 | AMM プロトコル手数料のために予約（記録なし）                           |

バーンモジュールには CLI のクエリがありません。ソースごとの累積バーン量は REST から読み取ってください。

```bash
curl -s https://api.qore.host/qorechain/burn/v1/stats
```

レスポンスには `total_burned` と `burns_by_source`（uqor 単位）が含まれます。現在の総供給量は `qorechaind query bank total-supply-of uqor` で確認できます。

## ヒント

:::caution
トークンを送信する前は、必ず受信者アドレスを再確認してください。QoreChain 上のトランザクションは取り消すことができません。
:::

:::tip

* `--dry-run` フラグを使用すると、トランザクションをブロードキャストせずにシミュレーションできます。
* `--gas` は明示的に設定してください（ハイブリッド署名の送金には 400,000 で十分です）。
* 手数料の下限は **ガス 1 単位あたり 0.1 uqor** です。したがって、ガスリミット 400,000 には少なくとも **40,000 uqor** が必要です。

:::
