# トークン操作

このガイドでは、QOR トークン、トークンの送受信方法、残高の照会、そして QoreChain における手数料分配モデルについて説明します。

:::note
以下のコマンドは **`qorechain-diana`** テストネット（EVM チェーン ID **9800**）を使用しています。メインネット（**`qorechain-vladi`**、EVM チェーン ID **9801**）は 2026年6月7日からチェーンバージョン **v3.1.92** で稼働しています — メインネットで取引する場合は、**Connecting to Mainnet** ページに記載されたメインネットのチェーン ID とエンドポイントに置き換えてください。
:::

## トークン情報

| プロパティ            | 値                             |
| --------------------- | ------------------------------ |
| **表示単位**           | QOR                            |
| **基本単位**           | uqor                           |
| **換算**               | 1 QOR = 1,000,000 uqor (10^6)  |
| **チェーンID**         | `qorechain-vladi`（メインネット）/ `qorechain-diana`（テストネット） |
| **Bech32プレフィックス** | `qor`（例: `qor1abc...xyz`）  |

すべてのオンチェーン金額は **uqor** 単位で表記されます。トランザクションを送信する際は、必ず金額を uqor 単位で指定してください。

## トークンの送信

あるアカウントから別のアカウントへ QOR トークンを送金するには、以下のようにします。

```bash
qorechaind tx bank send <from_address> <to_address> <amount>uqor \
  --chain-id qorechain-diana \
  --fees 500uqor
```

**例:** 別のアドレスへ 5 QOR（5,000,000 uqor）を送金する場合:

```bash
qorechaind tx bank send qor1sender... qor1recipient... 5000000uqor \
  --chain-id qorechain-diana \
  --fees 500uqor
```

送信者の指定には、生のアドレスの代わりにキー名を使用することもできます。

```bash
qorechaind tx bank send mykey qor1recipient... 5000000uqor \
  --chain-id qorechain-diana \
  --fees 500uqor
```

## 残高の照会

任意のアカウントの残高を確認します。

```bash
qorechaind query bank balances <address>
```

**例:**

```bash
qorechaind query bank balances qor1abc...xyz
```

**出力例:**

```yaml
balances:
- amount: "15000000"
  denom: uqor
pagination:
  next_key: null
  total: "0"
```

これは、このアカウントが 15 QOR（15,000,000 uqor）を保有していることを示します。

## 手数料構造

QoreChain のトランザクション手数料は、ネットワークのインセンティブを整合させるため、5つの分配先に配分されます。

| 分配先              | 割合  | 目的                                                       |
| ------------------- | ----- | ---------------------------------------------------------- |
| **バリデーター**     | 37%   | ブロック生成者への報酬とネットワークのセキュリティ確保     |
| **バーン（焼却）**   | 30%   | 供給から永久に除去され、デフレ圧力を生み出す               |
| **トレジャリー**     | 20%   | プロトコル開発とエコシステム助成金の資金源となる           |
| **ステーカー**       | 10%   | すべてのデリゲーターに比例配分される                       |
| **ライトノード**     | 3%    | ネットワークデータを提供するライトノード運用者への報酬     |

## バーンチャネル

QoreChain はマルチチャネルのバーン（焼却）機構を実装しています。QOR トークンは、10 個の異なるチャネルを通じて流通から永久に除去されます。

| チャネル              | 説明                                                                 |
| --------------------- | --------------------------------------------------------------------- |
| `tx_fee`              | すべてのトランザクション手数料に含まれる30%のバーン部分               |
| `governance_penalty`  | ガバナンス提案が定足数に達しなかった場合、または拒否された場合にバーンされる |
| `slashing_burn`       | スラッシュされたバリデーターのステークのうちバーンされる部分           |
| `bridge_fee`          | クロスチェーンブリッジ転送時にバーンされる手数料                       |
| `spam_deterrent`      | スパムと判定されたトランザクションに追加で適用されるバーン             |
| `epoch_excess`        | エポック境界で目標値を超えた超過発行分がバーンされる                   |
| `manual_burn`         | ガバナンス提案によるコミュニティ主導のトークンバーン                   |
| `contract_callback`   | スマートコントラクトのコールバック実行時にバーンされる手数料           |
| `cross_vm_fee`        | クロスVM（例: EVM から CosmWasm へ）呼び出しの実行時にバーンされる     |
| `rollup_create`       | 新しいロールアップをデプロイする際にバーンされる最小ステークの1%       |

すべてのチャネルにおけるバーンされた総量は、以下のコマンドで照会できます。

```bash
qorechaind query bank total --denom uqor
```

## ヒント

:::caution
トークンを送信する前は、必ず受信者アドレスを再確認してください。QoreChain 上のトランザクションは取り消すことができません。
:::

:::tip

* `--dry-run` フラグを使用すると、トランザクションをブロードキャストせずにシミュレーションできます。
* `--gas auto` を使用すると、ノードがトランザクションに必要なガス量を自動的に見積もります。
* 標準的な送金の最小手数料は **500 uqor** です。

:::
