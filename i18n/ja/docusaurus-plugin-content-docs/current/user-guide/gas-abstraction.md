# ガス抽象化

このページでは、QoreChainのガス抽象化機能について説明します。この機能は、ユーザーがQORではなく、承認されたネイティブ以外のトークンで取引手数料を支払えるように設計されています。**現在、どちらのネットワークでも使用できません**。このページでは、その設計と、代わりに行うべきことを説明します。

:::caution まだ利用できません
ネイティブ以外のトークンでの手数料支払いは、現在、メインネット（**`qorechain-vladi`**、ノードリリース **v3.2.1**）でもテストネット（**`qorechain-diana`**）でも**動作しません**。

* ガス抽象化のクエリはメインネットでは提供されていません。`qorechaind query gasabstraction accepted-tokens` はヘルプテキストを表示し、REST ルート `/qorechain/gasabstraction/v1/config` は `Not Implemented` を返します。
* どちらのネットワークでもIBCチャネルは開通していないため、支払いに使える `ibc/USDC` や `ibc/ATOM` の残高は存在し得ません。
* ネットワークの手数料下限は `uqor` で確認されるため、それ以外のデノミネーションでの手数料は拒否されます。

すべての手数料を `uqor` で支払ってください。稼働中のネットワークでトークンが受け入れられるようになった時点で、このページは更新されます。
:::

---

## 現在動作するもの：uqorで手数料を支払う

すべてのトランザクションは、ガス1単位あたり最低 **0.1 uqor** を支払います。ガスリミットと手数料を一緒に設定します。

```bash
qorechaind tx bank send mykey qor1recipient... 5000000uqor \
  --gas 400000 --fees 40000uqor \
  --chain-id qorechain-vladi --generate-only > tx.json
```

その後、[トランザクションコマンド](/cli-reference/transaction-commands#hybrid-signing)の説明に従って、`qorechaind tx pqc cosign` でハイブリッド署名してブロードキャストします。トランザクションタイプごとの推奨上限については、[手数料とガス](/cli-reference/transaction-commands#fees-and-gas)をご覧ください。

---

## 概要

ガス抽象化は、取引手数料を支払うためにQORを保有する必要をなくすよう設計されています。承認された代替トークン（たとえばIBC転送されたステーブルコイン）を保有するユーザーは、そのトークンで手数料を支払い、プロトコルは処理前に手数料額をネイティブ相当額に変換します。

---

## 想定される設計

### 承認済みトークン

モジュールのジェネシス設定には、以下のトークンとプロトコルで定義された変換レートが記載されています。これらは手数料算定上の交換比率であり、市場価格ではありません。現在、ネットワーク上に存在し得るのは `uqor` のみです（上記の注意を参照）。

| トークン              | デノミネーション | 変換レート |
| ------------------ | ------------ | --------------- |
| **QOR**            | `uqor`       | 1.0(ネイティブ)    |
| **USDC**(IBC経由) | `ibc/USDC`   | 1.0             |
| **ATOM**(IBC経由) | `ibc/ATOM`   | 10.0            |

### 想定される動作

QoreChainの `GasAbstractionDecorator` は取引処理パイプラインに組み込まれています。手数料がネイティブでないデノミネーションの取引では、次のようになります。

1. **手数料の検査** — デコレーターが手数料のデノミネーションを読み取ります。
2. **レートの参照** — そのデノミネーションが承認済みトークン一覧に含まれている場合、対応する変換レートが参照されます。
3. **変換** — 手数料はネイティブな `uqor` 相当額に変換されます。
4. **標準処理** — 変換後の手数料は標準の手数料控除ハンドラーを通過するため、下流の手数料処理（バリデーターへの分配、バーン、トレジャリー、ステーカーおよびライトノードの取り分）は、ネイティブ相当額に対して行われます。

---

## 設定の照会

メインネットはまだガス抽象化のクエリを提供しておらず、JSON-RPCメソッド `qor_getGasAbstractionConfig` もどの公開エンドポイントでも提供されていません（[`qor_` 名前空間](/api-reference/json-rpc-qor_-namespace)を参照）。現在、稼働中の承認済みトークン一覧を読み取る公開手段はありません。
