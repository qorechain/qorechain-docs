# ロールアップのデプロイ

このガイドは、Rollup Development Kit（RDK）を使って、QoreChain 上で決済されるアプリケーション特化型ロールアップを立ち上げるための簡単な概要です。ステップごとのコマンドは **[ロールアップのデプロイ](/rollups/deploying-a-rollup)** にあります。このページでは、開始前に必要なものを説明します。

:::caution 初期段階の機能
どちらのネットワークでも、まだロールアップは作成されていません。メインネット（**`qorechain-vladi`**、EVM チェーン ID **9801**）はチェーンバージョン **v3.2.1** で稼働しており、テストネット（**`qorechain-diana`**、EVM チェーン ID **9800**）はより新しいリリース（**v3.2.2**）で稼働しています。まずテストネットで検証してください。
:::

---

## ここでのロールアップとは {#what-a-rollup-is-here}

QoreChain のロールアップは、**オフチェーンで実行**し、**決済**に QoreChain を使うアプリケーション特化型チェーンです。ロールアップをオンチェーンに登録し、ステートルートのバッチを投稿し、（任意で）データ blob と出金コミットメントを投稿します。オンチェーンの記録には、プロファイル、決済モード、シーケンサーモード、データ可用性バックエンド、ガスモデル、VM ラベルが含まれます。ホストチェーンがロールアップのトランザクションを実行することはありません。

---

## プリセットプロファイル {#preset-profiles}

RDKには、一般的なアプリケーションカテゴリごとに調整された5種類のプリセットプロファイルが用意されています。

| プロファイル        | 決済(証明)  | シーケンサー | DA              | ガスモデル    | VM       | 想定ユースケース |
| -------------- | ------------------- | --------- | --------------- | ------------ | -------- | ----------------- |
| **defi**       | zk(SNARK)          | dedicated | native          | EIP-1559     | EVM      | DeFi/AMMアプリケーション(レンディング、DEX、デリバティブ) |
| **gaming**     | based               | based     | native          | flat         | custom   | 高スループットなゲーム状態管理とリアルタイム体験 |
| **nft**        | optimistic(fraud)  | dedicated | native(Celestia DA計画中) | standard | CosmWasm | NFTミンティングおよびマーケットプレイス用途 |
| **enterprise** | based               | based     | native          | subsidized   | EVM      | 手数料をスポンサーする許可制・コンソーシアム型デプロイメント |
| **custom**     | デフォルト: optimistic(fraud) | dedicated | native | standard | EVM | 開始時のデフォルト。メッセージが許す範囲で調整してください |

詳細と成熟度に関する注記（例えば、CLI で作成した `defi` ロールアップはまだ ZK バッチをファイナライズできないことや、`based` シーケンシングは現時点では作成者が提出することを意味することなど）については、[プリセットプロファイル](/rollups/preset-profiles)を参照してください。

## 要件 {#requirements}

| 要件 | 詳細 |
| ----------- | ------- |
| **ロールアップのステーク** | 最低 10,000 QOR（`min_stake_for_rollup`、10,000,000,000 uqor）。現在の値は `qorechaind query rdk config` で確認してください |
| **作成時のバーン** | 提供したステーク額の 1 % が作成時にバーンされます。残りはエスクローされ、ロールアップを停止すると返還されます |
| **レイヤー登録ステーク** | ロールアップを作成すると、multilayer モジュールにレイヤーも登録され、作成者からさらに 1,000 QOR がロックされます（ロールアップの停止時に返還されます）。その残高がないとレイヤーは作成されず、ロールアップをアンカーできません |
| **アカウント** | ポスト量子鍵が登録された、資金のあるアカウント（ネイティブレーンのすべてのトランザクションはハイブリッド署名されます） |

---

## ヒント {#tips}

* プリセットプロファイルから始めましょう。プリセットは決済モード、シーケンサー、データ可用性バックエンド、VM を設定します。`create-rollup` が受け取るのは、ID、プロファイル、ステーク、および任意の `--vm` だけです。
* 1 % の作成時バーンは、提供したステーク額に適用されます。
* 現時点では、ロールアップの作成者がバッチの提出者です（どのプリセットもシーケンサーアドレスを設定しません）。そのため作成者の鍵を安全に保管してください。ロールアップの一時停止、再開、停止ができるのは作成者だけです。
* `suggest-profile` ヘルパーは、現在、公開エンドポイントでは固定の `defi` フォールバックを返します。そのため、プロファイル表から選んでください。
