# ガーディアンズ・プログラム

ガーディアンズ・プログラムは、QoreChain のコミュニティ・リーダーシップ・プログラムです。コミュニティ、開発者、バリデーター運用、リサーチの活動を担う人が応募し、短いトライアルを通過すると、検証された貢献に対して QOR を獲得できます。QoreChain にまつわる明確な役割と実績を求めるコミュニティメンバー、ビルダー、ノード運営者、ライターのためのプログラムです。

:::note このページで扱う内容
このプログラムはチェーン上ではなく、QoreChain のウェブサイトから運営されています。このページは [qorechain.io/guardians](https://qorechain.io/guardians) が公開している内容を 2026年10月27日時点で確認してまとめたもので、このマニュアルでは確認できないことも明記しています。ルール、上限、日付、報酬についてはウェブサイトが正式な情報源であり、両者が異なる場合はウェブサイトに従ってください。これは、[QoreX のソーシャルリカバリー](/qorex/security-and-recovery#social-recovery)のガーディアン（自分のウォレットの復元を手伝ってもらうために自分で選ぶ人たち）とは無関係です。
:::

## 革新的な仕組み {#innovations}

以下は、ウェブサイトが説明している仕組みです。これらはチェーンの機能ではなくプログラムのルールであるため、このマニュアルには、そのいずれかを証明するチェーンクエリは掲載していません。

* **公開された上限を持つ 5 つのランク。** Initiate（上限 1,000）、Guardian（250）、Captain（25）、Sentinel（7）、Architect（最初の 24 か月は 3）。ウェブサイトによると、昇格には在籍期間、公開された実績、上位者の推薦、評議会（Council）による承認が必要で、現在の人数はリーダーボードで公開されます。
* **4 つのトラック。** コミュニティ、ビルダー、ブリッジおよびバリデーター運用、リサーチおよび DevRel。Initiate は応募時に 1 つのトラックを選びます。Guardian 以上は、メイントラックとサブトラックを持つことができます。
* **6 つのリージョン。** 西ヨーロッパ、東ヨーロッパおよび CIS、北米、中南米、APAC、MENA およびアフリカ。各リージョンに Captain を置き、月次のリージョン運営予算を設ける方針です。
* **ポイントシェア方式の報酬。** 各ランクには、供給量の 1.5%（6,750 万 QOR）のベスティング済み割当から引き出される月次の QOR プールがあります。Guardian の月間 QOR は、その月に同じランクで獲得されたポイントに占める自分のシェアです。ポイントは、週次のクエスト、月次のトラック業務、四半期ごとのキャンペーンから得られます。
* **ソウルバウンド資格情報。** ウェブサイトによると、完了したクエストは譲渡不可のオンチェーン資格情報として記録され、不正な活動があった場合は QOR の回収と資格情報の失効が行われます。
* **ランクごとの本人確認。** Initiate は本人確認なしの公開応募です。ウェブサイトによると、Guardian ランクではプライバシーを保護する人間性証明が、Captain ランク以上では標準的な KYC が必要です。
* **アクティビティのルール。** ウェブサイトによると、2 週間活動がないと Guardian は一時停止され（再開に新たな応募は不要）、2 か月間沈黙が続くと枠が空きます。

## 使い方 {#how-to-use}

ウェブサイトが説明している参加の流れは次のとおりです。

1. **応募する。** [qorechain.io/guardians](https://qorechain.io/guardians) からリンクされている応募フォームに、名前、トラック、リージョン、志望動機、推薦者を入力します。
2. **審査。** ウェブサイトには、審査の目標時間として 48 時間と記載されています。
3. **トライアル。** 選んだトラックでの実際のタスクに取り組む 1 週間のトライアルです。
4. **有効化。** トライアルに合格すると Initiate になり、クエストポイントの獲得が始まります。

有効化の後は、ウェブサイトにトラックごとの月次業務の例が掲載されています（たとえば、コミュニティではイベントの主催とコンテンツ、ビルダーではテストネットでのコントラクトのデプロイ、ブリッジおよびバリデーター運用ではバリデーターの稼働率、リサーチおよび DevRel では長文の技術記事）。正確な業務内容とクエスト一覧は、ウェブサイトが定義し、変更します。

## アクセス方法 {#how-to-access}

* **応募:** [qorechain.io/guardians](https://qorechain.io/guardians)（「Apply Now」ボタンからフォームが開きます）。
* **順位:** [qorechain.io/guardians/leaderboard](https://qorechain.io/guardians/leaderboard)。ウェブサイトによると、上限と現在の人数はここで公開されています。また、すでに終了した 2026年4月から5月の紹介キャンペーンの最終順位も掲載されています。
* **コミュニティチャンネル:** ウェブサイト上の Discord と Telegram のリンク。
* **費用:** 応募は無料です。QOR を受け取るにはウォレットアドレスが必要です。[ウォレットのセットアップ](/getting-started/wallet-setup)を参照してください。

## 制限事項と既知の問題 {#limits}

* **未決定、またはここでは確認できていない事項。** ウェブサイトのタイムラインには、2026年後半に予定されている項目（メインネットでのクエストエンジン、Captain の KYC 連携、最初の Architect の任命、第 2 期のコホート）が挙げられています。このマニュアルでは、そのいずれかが実現したかどうかを確認できず、第 2 期コホートの日付も示しません。
* **報酬は保証されません。** 金額は、ポイントシェア、ランクごとのプールの規模、検証されたアクティビティによって決まります。このページでは、個人ごとの金額や、ウェブサイトに記載されている以外のスケジュールは示していません。
* **オンチェーン資格情報はここでは文書化されていません。** このマニュアルには、資格情報に関するコントラクトアドレス、クエリ、エクスプローラーの表示はありません。ウェブサイトまたはこのマニュアルが方法を示すまでは、ブロックエクスプローラーで検証できると考えないでください。
* **このページはウェブサイトより遅れることがあります。** ウェブサイトの一部の表現には、トークン生成イベントやメインネットのローンチ前後の日付がまだ残っています。最新のチェーン情報には[ネットワーク](/appendix/networks)ページを使用してください。
* **秘密情報は応募に含めないでください。** リカバリーフレーズや秘密鍵は、プログラムの運営者を名乗る相手であっても、誰にも送らないでください。応募に必要なのは、せいぜい公開アドレスだけです。
