# ポートフォリオとステーキング

## ポートフォリオ

**Portfolio**（ポートフォリオ）ビュー（各セッションで最初に開くときに生体認証で保護されます）は、**アロケーションドーナツ**（3つのレーン（Native、EVM、SVM）にまたがって統合されたあなたの QOR）をリングの下のキャプションとともに表示し、さらに各資産ごとの行を表示します。パーセンテージは価格フィードが有効になると表示されます。

任意の資産をタップすると **Asset detail**（資産詳細）が開き、以下が表示されます。

- **Balance history**（残高履歴） — オンチェーンの送金から構築された実際のトレンド。
- **Recent activity**（最近のアクティビティ） — **@handle** の逆引きが付いた取引行。可能な場合は取引相手が名前で表示されます。

## ステーキングと Earn

QOR をステーキングすると QoreChain のセキュリティ確保に役立ち、報酬を獲得できます。すべてのステーキング操作は、あなたのポスト量子署名を伴う実際のオンチェーントランザクションです。

### バリデーターにステーキングする

1. **Stake**（ステーク）を開きます。
2. リスト（チェーンからライブで読み込まれます）からバリデーターを選択します。
3. 金額を入力し、生体認証で確認して **delegate**（委任）します。
4. 報酬が発生したら、同じ画面からいつでも請求できます。

:::note ロック期間は現状ありません — 待機が発生するのは出口だけです
現時点では選択すべき固定期間はありません。なぜなら、そもそも存在しないからです。委任は、あなたが委任解除を求めるまで、次のブロックから報酬を受け取り続けたまま有効な状態を保ちます。更新が必要な有効期限も、最低ステーキング期間もありません。唯一の待機期間は出口側にあります。委任解除すると、その QOR は21日間のアンボンディング期間に入り、その間は報酬が発生せず移動もできません。その後、使用可能な残高に戻ります。委任を別のバリデーターに移す（再委任）場合は、この待機を完全にスキップできます。これは現在のチェーンの挙動を説明するものであり、恒久的な保証ではありません。詳細は[ロック期間はありますか？](/user-guide/staking-and-delegation#lock-in-period)を参照してください。
:::

:::note この画面にはまだ専用の Undelegate ボタンがありません
この Stake 画面がカバーするのは delegate（委任）と claim（請求）のみです。QoreX の画面から直接委任解除するには、代わりに[ブラウザ拡張機能の Stake 画面](/qorex/browser-extension#stake)を使用するか、または[ダッシュボード](/dashboard/staking-and-validators#delegate)経由で委任解除してください。ダッシュボードからのリクエストは、接続している QoreX（アプリを含む）に送られ、あなたが承認する形になります。
:::

### Earn

**Earn** ビューは、あなたのアクティブなポジションと利回りを1か所にまとめて表示します。
