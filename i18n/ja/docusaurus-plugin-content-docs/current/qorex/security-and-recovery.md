# セキュリティとリカバリー

ウォレットの保護とリカバリーに関するすべては、**設定 → セキュリティダッシュボード**にまとまっています。ホームタブにも**バックアップの健全性**カードが表示され、ソーシャルリカバリーを設定するまで警告が続きます。

## 今すぐバックアップを — 失われたウォレットは誰にも復元できません {#back-up-now}

:::danger ウォレットに資金を入れる前に必ずお読みください
QoreXは**非カストディアル**です。あなたの鍵はご自身の端末上にのみ存在し、QoreChain協会はその鍵のコピーも、マスターキーも、ウォレットをリセット・復元する手段も一切持っていません。**「パスワードをお忘れですか」フローも、サポートチケットも、カスタマーサービスによる特例対応もありません** — バックアップがない状態で鍵へのアクセスを失った場合、資金は永久に、かつ取り消し不能な形で失われます。これはQoreX特有の制限ではなく、すべての非カストディアルウォレットに共通する事実ですが、あえて明確に述べておきます。

**次のうち少なくとも1つを — ウォレットを作成した直後に、後回しにせず行ってください:**

1. **24単語のリカバリーフレーズを書き留め**、オフラインで耐久性のある場所に保管してください(スクリーンショットではなく、クラウドに同期されるメモでもなく、自分宛てのメッセージでもない方法で)。これは、どの端末からでも、いつでもウォレットを復元できる唯一の手段です。
2. 信頼できるガーディアンとともに**[ソーシャルリカバリー](#social-recovery)**を設定してください。これにより、フレーズを紛失した場合でもウォレットを復元でき、しかも単独のガーディアンだけであなたの資金にアクセスすることは決してできません。

両方行うのが最も安全な選択です — フレーズは端末を切り替えた場合やアプリが利用できない場合に備え、ガーディアンはフレーズそのものを紛失した場合に備えます。

**アプリをアンインストールすると、その端末上の鍵は削除されます。** モバイルアプリのボールトとブラウザ拡張機能のボールトは、それぞれを作成した端末上にのみ存在します。アプリのアンインストール、端末のリセット、拡張機能の削除・クリアを行うと、そのコピーは削除されます — バックアップも連携済み端末もない場合、QoreChainを含む誰にもあなたのウォレットを復元することはできません。
:::

## ポスト量子鍵 {#pqc-key}

セキュリティダッシュボードには、ポスト量子鍵のオンチェーン上のライブ状態が表示されます: **「最初の送金で登録されます」** → **「オンチェーンに登録済み ✓」**。アルゴリズムは**ML-DSA-87**(決定論的、secp256k1とのハイブリッド)です。

**鍵のローテーション** — ポスト量子鍵をローテーションする(オンチェーンの`MsgRotatePQCKey`操作)には、その都度の生体認証セレモニーが必要であり、**自動化されることは決してありません**。基盤となる仕組みについては[鍵のローテーション](/developer-guide/post-quantum-signing#key-rotation)を参照してください。

## ソーシャルリカバリー {#social-recovery}

ソーシャルリカバリーでは、信頼できる**ガーディアン**があなたのリカバリーフレーズを一切見ることなく、ウォレットの復元を手伝うことができます。

- あなたのシード情報は**ML-KEMで封印されたシェア**に分割され、**しきい値**方式(t-of-n)でガーディアンに配布されます: *n*人のガーディアンのうち*t*人が揃えば復元を助けられますが、それ未満では不可能です。
- 各ガーディアンは認証情報を受け取ります。設定時にリレーへ書き込まれるのは、読み取り不能な、封印された不透明なエンベロープのみです。
- リカバリーには、しきい値数のガーディアンの承認が必要で、その後**48時間のタイムロック**が実行され、あなた宛てに**キャンセルアラート**が送られます。これにより、悪意あるリカバリー試行を止めることができます。

**設定方法:** セキュリティダッシュボード → ソーシャルリカバリー → ガーディアンとしきい値を選択します。これが完了すると、バックアップの健全性に関する警告は解消されます。

**他人のリカバリーを承認する:** 誰かのガーディアンになっている場合、ホームタブの**リカバリーを手伝う**からその人のリクエストを承認できます。

## レガシープロトコル {#legacy}

**レガシープロトコル**は量子安全な資産継承機能です。ガーディアンの仕組みの上にデッドマンスイッチを重ねたもので、あなたと連絡が取れなくなった場合に、資産を指定した受益者へ引き継ぐことができます。任意機能であり、セキュリティダッシュボードから設定します。

## 新しい端末を連携する {#link-device}

**サーバーを介さず、24単語を入力することもなく**、ウォレットを2台目のスマートフォンやタブレットに移動できます:

1. **新しい端末**でオンボーディング → **他の端末から連携**を選択します。ワンタイムの**10文字のコード**が表示され、カメラが起動します。
2. **元の端末**で設定 → セキュリティ → **新しい端末を連携**へ進み、そのコードを入力して生体認証で確認します。**QRコード**が表示されます(コードから導出した鍵でシードを封印したもの: scrypt N=2¹⁷ → AES-256-GCM)。
3. **新しい端末**でそのQRコードをスキャンすると、端末上でローカルに復号され、同じウォレット・同じアドレスが復元されます。

**安全な理由:** コードとQRコードが同じ画面に同時に表示されることは決してありません。QRコードだけを撮影しても、それはメモリハードな鍵導出関数の背後にある暗号文にすぎず、両方の要素はワンタイムであり画面が閉じれば消えます。誤ったコードを入力した場合は分かりやすいエラーが表示されるので、再試行するだけです。

:::note
端末連携は**利便性のための機能**であり、リカバリー手段ではありません。24単語のフレーズとソーシャルリカバリーこそが、あなたの本当の安全網です。
:::

## 接続中のdApp {#connected-dapps}

dAppとの接続は**オリジンごと**かつ**セッション単位**です: アプリ内dAppブラウザを閉じると、すべての接続が失効します。セキュリティダッシュボードで、アクティブな接続の確認・切断を行えます。

## リンク済みサイナーと送金限度額 {#linked-signers}

[ダッシュボード](/qorex/account-and-dashboard#dashboard)を通じて外部の鍵(Phantom / MetaMask)を連携すると、それぞれに**範囲を限定した権限**と、インターフェース上だけでなく**オンチェーンで強制される****SpendingRule(送金ルール)**が付与されます。鍵の管理をリンク済みの鍵に委任することは決してできません。オンチェーンでの仕組みについては[リンク済みウォレット・オーセンティケーター](/developer-guide/account-abstraction#authenticators)を参照してください。ダッシュボードは常に、オンチェーン上の現在の実態を表示します。

## Q-Dayスキャナー {#q-day-scanner}

**Q-Dayスキャナー**では、任意のアドレス — 自分のものでも他人のものでも — を入力して、量子耐性の状態レポートを取得できます。どの資金が古典暗号のみの鍵に置かれており、どの資金がすでにポスト量子で保護されているかが分かります。ホームタブのクイックボタンから利用できます。

## セキュリティモデルの概要

1. **非カストディアル** — 鍵は端末上で生成され、ハードウェアに裏付けられたボールト(モバイル)または暗号化されたボールト(拡張機能)内に保管され、外部に出ることはありません。
2. **同意なしには何も行われません** — すべての接続はオリジンごとに管理され、すべての署名は個別に承認され(モバイルでは生体認証)、ペイロードは署名前に必ず復号・表示されます。
3. **デフォルトで量子安全** — NativeレーンでのすべてのQOR送金には常にML-DSA-87 + secp256k1が付与され、古典暗号のみの場合は必ずラベル表示され、暗黙のまま扱われることはありません。
4. **データ収集なし** — アナリティクス、トラッキング、広告は一切ありません。任意のアカウントサインインは[QoreChainプライバシーポリシー](https://qorechain.io/privacy)の対象です。
5. **リカバリー手段** — 24単語のフレーズ(常時利用可能)、ガーディアンによるソーシャルリカバリー+48時間のタイムロック(任意)、レガシー資産継承(任意)、端末連携(利便性のための機能)。
