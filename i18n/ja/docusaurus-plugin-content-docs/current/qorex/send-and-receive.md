# 送金と受取

ホーム（ウォレット）タブが出発点です。ここには**ネットワークバッジ**（デフォルトは MAINNET、開発者トグルを有効にした場合は TESTNET）、**合計残高**（タップで表示／非表示を切り替え）、そして主要な操作である**送金 · 受取 · スワップ · ステーク**が表示されます。資産リストには **QOR**（Native + ポスト量子 🛡、Native/EVM/SVM レーンにまたがる統一された単一残高）と**すべてのネットワーク**（ETH · BNB · POL · ARB を統合したビュー）が表示されます。

## 量子安全な QOR を送金する

1. **Send** をタップします。
2. 受取人を `qor1…` アドレス**または** **@handle** として入力します。ハンドルは解決され、暗号学的に検証されます（レジストリ署名 + 所有者署名 + 初回使用時の信頼によるピン留め）。ハンドルの鍵が知らないうちに変更された場合、QoreX は明示的な警告を表示します。
3. 金額を入力します。プレビューには受取人、金額、手数料、そして**Shield** の状態（署名のポスト量子保護レベル）が表示されます。
4. **生体認証**による承認で確定します。QoreX は必須のハイブリッド・ポスト量子署名（ML-DSA-87 + secp256k1）で送金に署名し、Native レーンでブロードキャストします。

**最初の**送金では、あなたのポスト量子鍵がオンチェーンに自動的に登録されます。これは [セキュリティと復旧](/qorex/security-and-recovery#pqc-key) で確認できます。別途の手順は不要です。

## QOR を受け取る

**Receive** をタップすると、あなたの `qor1…` アドレスが QR コード（QoreChain アイコンが埋め込まれています）とコピーボタンとして表示されます。どちらかを送金者と共有してください。

## 支払いをリクエストする

**Request**（[サインイン](/qorex/account-and-dashboard#sign-in)が必要）をタップすると、支払いリクエスト（金額と任意のメモ）を QR コードまたはリンクとして作成できます。それをスキャンした人には、あらかじめ入力された送金が表示されます。

## 外部ネットワークとトークン

**すべてのネットワーク**（または外部送金）から、**ETH、BNB、POL、ARB、SOL** をネイティブに送金できるほか、**ERC-20** および **SPL** トークンも送金できます。これらはすべて同じ復旧フレーズから導出されます（ETH は `m/44'/60'` を使用し、SOL は標準パスを使用し、SPL は関連トークンアカウントを使用します）。

:::caution 外部チェーンはクラシックのみ
他のブロックチェーンはポスト量子署名を運ぶことができません。外部ネットワークで送金する場合、QoreX はこれを明示的に示します（送金にはクラシック署名が使用され、**Shield** はダウングレードを表示します）。あなたの **QOR** は常に保護された Native レーンにとどまります。Cosmos ベースの外部送金は任意のメモに対応しています。
:::

## スワップ

**Swap** タブは QoreChain のオンチェーン AMM に接続されていますが、無効のままです。ボタンには **"Swap — coming with pool liquidity"** と表示され、流動性とリモート機能フラグが有効になるまでこの状態が続きます。有効になると自動的に点灯します。**アプリの更新は不要です**。
