# テストネット機能

:::caution テストネット専用
このページの内容はすべて **QoreChain テストネット**（`qorechain-diana`）で**のみ**動作します。**いずれもメインネットにはありません。** テストネットのトークンに価値はありません。以下の画面は、メインネットを使っている間は QoreX に表示されません。
:::

QoreX には、先にテストネットで検証している機能がいくつかあります。これらはテストネットがアクティブな間のみ表示され、すべての画面に **TESTNET：テスト用トークンのみ。本物の QOR ではありません** というバナーが表示されます。

## イノベーション {#innovations}

- **署名前にネットワークが確認（テストネット専用）。** 別のチェーンへの送金では、QoreX はまずネットワークにチャネルと相手側の確認を求めます。確認できない場合は何も送信しません。
- **ルートの実際の状態（テストネット専用）。** ブリッジ画面は、各ルートについてネットワーク自体が示す内容を表示し、示していないものは提供しません。
- **QoreChain 上の Solana 形式のトランザクション（テストネット専用）。** ML-DSA-87 署名で開く SVM ウィンドウにより、自分の Solana 鍵が厳しい制限の範囲内で動作できます。

## QoreX でテストネットに切り替える方法 {#reach-testnet}

- **モバイルアプリ:** **設定**を開き、<strong>テストネットを使う（開発者向け）</strong>をオンにします。アプリは再起動せず、すぐに `qorechain-diana` に切り替わります。デフォルトは常にメインネットです。戻るにはオフにします。
- **ブラウザ拡張機能:** ポップアップ下部のバージョン番号を 7 回タップして**開発者モード**のセクションを表示し、**テストネット（diana）に切り替え**をタップします。同じセクションの**メインネットに戻る**で戻ります。

テストネットがアクティブな間は、以下のテストネット専用の画面がアプリの**設定**と拡張機能のポップアップ（**別のチェーンへ送る**と**ブリッジ**）に表示され、**QoreChain 上の Solana** ツールが開発者タブまたは開発者ツールのページに表示されます。テストネットの残高にはドル建ての価値は表示されません。dApp はネットワークを変更できず、変更できるのはあなただけです。

## テスト用 QOR を入手する {#get-test-qor}

テストネットの QOR は無料で、価値はありません。[Dashboard のフォーセット](/dashboard/faucet)で入手します。そこでサインインし、QoreX からテストネットのアドレスをコピーして（**テストネット作業スペース**開発者ツールに **アドレスをコピー** ボタンと**テストネットのフォーセットを開く**ボタンがあります）、トークンをリクエストします。公開テストネットのエンドポイントは[テストネットへの接続](/getting-started/connecting-to-testnet)も参照してください。

## 別のチェーンへ送る（IBC） {#ibc}

**テストネット専用。** QoreChain テストネットから **Cosmos Hub**、**Osmosis**、**Injective**、**Akash**、**Celestia** の各テストネットへ QOR を送り、戻すことができます。

QoreX が行うこと:

- **まずルートを確認します。** 署名できるようになる前に、QoreX はチャネルが開いていて、選んだチェーンに引き続きつながっていることをネットワークに確認します。チャネルが閉じている、変更されている、確認できない場合は、その旨を表示して何も送信しません。
- **完全な確認画面を表示します。** 署名前に、送信者、相手チェーンの受取人、ネットワーク手数料、所要時間を確認できます。
- **所要時間。** Cosmos Hub テストネットへのテスト送金は約 20 秒で到着しました。QoreX は 1 分程度を見込むよう案内します。10 分以内に配達されない場合は、自分に戻ります。
- **使われる署名。** QoreChain からの送金は、ハイブリッド鍵（ML-DSA-87 と secp256k1）で署名されます。戻すときは、相手チェーンの要件に従い、そのチェーンで従来型の鍵で署名されます。確認画面にはその旨が表示されます。そのチェーン上では、これらのコインは従来型の鍵のみで保護されます。

### QoreChain から送る {#ibc-send}

1. テストネットをオンにし（[上記](#reach-testnet)を参照）、**設定**（拡張機能ではポップアップ）を開いて**別のチェーンへ送る**をタップします。
2. **送り先のチェーン**と**資産**（QOR、または IBC で届いたコイン）を選びます。
3. **金額**を入力します。**受取先**には、そのチェーン上の自分のアドレスが自動入力されます。変更もできます。QoreX はそのチェーンの有効なアドレスかを確認します。
4. **確認する**をタップし、**署名の前に確認**の内容を確認して、**署名して送信**を選びます。

### コインを戻す {#ibc-back}

1. **別のチェーンへ送る**で **QoreChain へ戻す**を開き、使ったチェーンで**残高を表示**をタップします。
2. **戻すもの**を選びます。手数料の支払いには、そのチェーンの固有コインが少し必要です。足りない場合は QoreX が知らせます。
3. 内容を確認して、**署名して戻す**を選びます。自分の QoreChain アドレスに届きます。

### 送金を追跡する {#ibc-track}

**あなたの送金**には各送金が一覧表示され、追跡されます。ネットワーク待ち、転送中、配達済み、自分に返金（理由、またはタイムアウトのため）です。**更新**をタップすると再読み込みします。状態がまだ分からない場合、QoreX は推測せず、配達はまだ確認されていないと表示します。

## ブリッジ画面 {#bridge}

**テストネット専用。** **ブリッジ**画面は、QoreChain Bridge のルートをネットワークから読み取り、各ルートの実際の状態を表示します。未開放、一時停止、現在は閉鎖、開放、引き出しのみ可能、入金のみ可能です。ネットワーク自体が開いていると示すルートのみが提供されます。

**現在テストネットではすべてのルートが閉じているため、何も提供されません。** この画面はルートが開くときに備えたものです。ここにあるものは、今利用できるルート、資産、金額ではなく、メインネットには何もありません。

## QoreChain 上の Solana {#solana-on-qorechain}

**テストネット専用。** SVM レーンは、QoreChain 上で Solana 形式のトランザクションを実行します。これは開発者モードのツールで、テストネットがアクティブな間のみ表示されます。メインネットの SVM レーンは開いておらず、ここのものは何も使えません。

このツールでできること:

- **レーンを表示します。** ネットワークで SVM レーンが稼働しているかと、そのクラスターです。
- **SVM ウィンドウを表示します。** ウィンドウにより、Solana 鍵で署名したトランザクションが、ML-DSA-87 署名なしで、上限の範囲内でアカウントから支払えます。QoreX は、ウィンドウが開いているか、残りのブロック数、取引数、QOR、紐付けられた Solana 鍵、許可するプログラムを表示します。
- **ウィンドウを開閉します。** 許可するプログラム（列挙を推奨。**すべてのプログラム**には警告があります）、開いておくブロック数（最大 17,280）、取引数（最大 1,000）、使える QOR の上限を選んでウィンドウを開きます。紐付けられるのは、リカバリーフレーズのインデックス 0 の Solana 鍵です。ウィンドウを開くと、既存のウィンドウは置き換えられます。画面の警告のとおり、小さく短く保ち、終わったら**ウィンドウを閉じる**で閉じてください。
- **署名済み Solana トランザクションをリレーします。** 開発者ツールのワイヤーバイト（base64 または base58）を貼り付けて**読み取る**をタップします。QoreX はプログラムと、署名済みの署名者を表示し、完全に署名されたトランザクションのみをリレーします。QoreChain アカウントはエンベロープに ML-DSA-87 で署名して手数料を支払います。Solana トランザクションに対する権限は一切得ません。

使い方: テストネットと開発者モードをオンにし、開発者タブ（または拡張機能の開発者ツールのページ）から **QoreChain 上の Solana** を開いて、上記の各セクションを使います。[開発者モード](/qorex/developer-mode#contracts)からの SVM プログラムへのコントラクト呼び出しも、テストネットでのみ動作します。

SVM レーンのチェーン側については、[テストネットの SVM](/developer-guide/svm-testnet-v329) と [SVM レーン](/developer-guide/svm-lane-v328)を参照してください。

## メインネットにないもの {#not-on-mainnet}

- QoreX から IBC で他のチェーンへ送る機能。
- QoreChain Bridge 画面とそのルート。
- SVM ウィンドウとリレーを含む、QoreChain 上の Solana。

QoreX はこれらの画面をテストネットでのみ表示し、各画面にその旨を示します。
