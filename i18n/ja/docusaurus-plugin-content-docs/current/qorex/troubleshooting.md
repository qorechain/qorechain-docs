# トラブルシューティング

QoreX アプリと拡張機能に関するよくある質問と簡単な対処法です。

| 症状 | 原因 / 対処法 |
|---|---|
| オンボーディング時に **「まずデバイスを保護してください」** と表示される | システム設定で Face ID / 指紋認証 **または画面ロック（PIN / パターン）** を設定してから戻ってください。ウォレットは、強力なロック解除要素を備えたデバイスでのみ作成できます。Android では、2D の顔認証だけでは *弱い* 生体認証です。その背後にある PIN が条件を満たすものです。 |
| **サインインシートが閉じた** / 「そのサインイン試行は期限切れです」 | 前回の試行が中断されました。もう一度サインインをタップしてください。 |
| Google / ダッシュボードでのサインイン後に **「パスキーを追加」が表示されない** | 想定どおりです。パスキーはメールコードアカウントにのみ紐付きます（[アカウントとダッシュボード](/qorex/account-and-dashboard#sign-in) の注記を参照）。 |
| **「ハンドルは近日公開」** | @handle レジストリに一時的に接続できません。ウォレットには影響しません。復旧すると自動的にハンドルが有効になります。 |
| **QoreX がハンドルのアドレスが変わったと警告する** | これはバグではなく想定どおりのセキュリティ動作です。QoreX は、あるハンドルに初めて送金した際に解決されたアドレスを記憶しており、後で変わった場合はそれを黙って信用せずに警告します。続行する前に、受取人と別の手段で新しいアドレスを確認してください。 |
| ベスティングアカウントで **「利用可能残高を超えています」として送金が拒否される** | 残高の一部がベスティングスケジュールによってまだロックされています。送金できるのは **利用可能** 部分（ホーム、送金、資産詳細に表示）のみで、残りは段階的にアンロックされます。 |
| **ウォレットリクエストに「テストネット/メインネット向けですが、あなたのウォレットは…」と表示される** | そのリクエスト（例：ダッシュボードからのもの）は、現在接続しているネットワークとは異なるネットワークを対象としています。意図したものであれば、まず自分でネットワークを切り替えてください。QoreX が自動で切り替えることはありません。 |
| デバイスのリンク中に **「コードが間違っているか QR が破損しています」** | 10 文字のコードを再確認し（アルファベットは紛らわしい文字を除いています。0/O/1/I/L はありません）、再スキャンしてください。どちらの成果物も 1 回限りです。 |
| **カメラ画面に権限が必要と表示される** | iOS: 設定 → QoreX → カメラ。Android: アプリ情報 → 権限 → カメラ。 |
| **拡張機能: 初回起動時にウォレットがない** | 拡張機能は **スタンドアロン** のウォレットです。ポップアップを開いて **ウォレットを作成** または **ウォレットをインポート** を選択してください。モバイルアプリは不要です。 |
| **読み取り専用アドレスからの送金が拒否される** | そのアドレスは別のウォレットに属しています（ラベルにどのウォレットかが表示されます）。QoreX は自身の派生アカウントについてのみ署名できます。それを所有するウォレットから送金してください。 |
| **テストネットバッジが表示される** | 設定 → **「テストネットを使用（開発者向け）」** がオンになっています。オフにするとメインネットに戻ります。 |
| **スワップボタンが無効になっている** | 現時点では想定どおりです。プールの流動性が利用可能になると、スワップは自動的に有効になります。アプリの更新は不要です。 |
| **アプリをアンインストールした / 拡張機能を削除したらウォレットが見当たらない** | ボールトはそのデバイスまたはそのブラウザにのみ存在していました。24 単語のフレーズをバックアップしていた場合は、それを使って復元してください。[ソーシャルリカバリー](/qorex/security-and-recovery#social-recovery) を設定していた場合は、ガーディアンとともに復旧を開始してください。どちらも行っていなかった場合、そのウォレットは復旧できません。新しいウォレットを作成したらすぐに保護するために、[今すぐバックアップ](/qorex/security-and-recovery#back-up-now) を参照してください。 |

## それでも解決しない場合

- ガーディアンとデバイスのリンクについては、[セキュリティと復旧](/qorex/security-and-recovery) のページを確認してください。
- QoreChain 自体に関する質問は、[メインドキュメント](/introduction/what-is-qorechain) または [qorechain.io](https://qorechain.io) にリンクされているコミュニティチャンネルを参照してください。
