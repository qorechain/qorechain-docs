# トラブルシューティング

QoreX アプリと拡張機能に関するよくある質問と簡単な対処法です。

| 症状 | 原因 / 対処法 |
|---|---|
| オンボーディング時に **「まずデバイスを保護してください」** と表示される | システム設定で Face ID / 指紋認証 **または画面ロック（PIN / パターン）** を設定してから戻ってください。ウォレットは、強力なロック解除要素を備えたデバイスでのみ作成できます。Android では、2D の顔認証だけでは *弱い* 生体認証です。その背後にある PIN が条件を満たすものです。 |
| **サインインシートが閉じた** / 「そのサインイン試行は期限切れです」 | 前回の試行が中断されました。もう一度サインインをタップしてください。 |
| Google / ダッシュボードでのサインイン後に **「パスキーを追加」が表示されない** | 想定どおりです。パスキーはメールコードアカウントにのみ紐付きます（[アカウントとダッシュボード](/qorex/account-and-dashboard#sign-in) の注記を参照）。 |
| **「ハンドルは近日公開」** | @handle レジストリに一時的に接続できません。ウォレットには影響しません。復旧すると自動的にハンドルが有効になります。 |
| **QoreX がハンドルのアドレスが変わったと警告する** | これはバグではなく想定どおりのセキュリティ動作です。QoreX は、あるハンドルに初めて送金した際に解決されたアドレスを記憶しており、後で変わった場合はそれを黙って信用せずに警告します。続行する前に、受取人と別の手段で新しいアドレスを確認してください。 |
| ベスティングアカウントで **「利用可能残高を超えています」として送金が拒否される** | 残高の一部がベスティングスケジュールによってまだロックされています。送金できるのは **利用可能** 部分（ホーム、送金、資産詳細に表示）のみで、残りは段階的にアンロックされます。 |
| **ウォレットリクエストに「テストネット/メインネット向けですが、あなたのウォレットは…」と表示される** | そのリクエスト（例：ダッシュボードからのもの）は、現在接続しているネットワークとは異なるネットワークを対象としています。意図したものであれば、まず自分でネットワークを切り替えてください。QoreX が自動で切り替えることはありません。 |
| デバイスのリンク中に **「コードが間違っているか QR が破損しています」** | 10 文字のコードを再確認し（アルファベットは紛らわしい文字を除いています。0/O/1/I/L はありません）、再スキャンしてください。どちらの成果物も 1 回限りです。 |
| **カメラ画面に権限が必要と表示される** | iOS: 設定 → QoreX → カメラ。Android: アプリ情報 → 権限 → カメラ。 |
| **拡張機能: 初回起動時にウォレットがない** | 拡張機能は **スタンドアロン** のウォレットです。ポップアップを開いて **ウォレットを作成** または **ウォレットをインポート** を選択してください。モバイルアプリは不要です。 |
| **読み取り専用アドレスからの送金が拒否される** | そのアドレスは別のウォレットに属しています（ラベルにどのウォレットかが表示されます）。QoreX は自身の派生アカウントについてのみ署名できます。それを所有するウォレットから送金してください。 |
| **テストネットバッジが表示される** | 設定 → **「テストネットを使用（開発者向け）」** がオンになっています。オフにするとメインネットに戻ります。 |
| **スワップボタンが無効になっている** | 現時点では想定どおりです（Android）。プールの流動性が利用可能になると、スワップは自動的に有効になります。アプリの更新は不要です。iOS ではスワップタブは表示されず、拡張機能にはスワップ画面がありません。 |
| **アプリをアンインストールした / 拡張機能を削除したらウォレットが見当たらない** | ボールトはそのデバイスまたはそのブラウザにのみ存在していました。24 単語のフレーズをバックアップしていた場合は、それを使って復元してください。[ソーシャルリカバリー](/qorex/security-and-recovery#social-recovery) を設定していた場合は、ガーディアンとともに復旧を開始してください。どちらも行っていなかった場合、そのウォレットは復旧できません。新しいウォレットを作成したらすぐに保護するために、[今すぐバックアップ](/qorex/security-and-recovery#back-up-now) を参照してください。 |
| **24 単語が見つからない / アプリが一度も表示しなかった** | モバイルアプリは、ウォレットの作成中にフレーズを表示しません。**設定 → セキュリティ → リカバリーフレーズを表示** を開き、生体認証またはデバイスの PIN で確認してから、単語を書き留めてください。拡張機能では、ポップアップの **リカバリーフレーズを表示** を使用します（パスワードが必要です）。ウォレットがすでに紛失した端末にしかない場合、QoreChain は復旧できません。[今すぐバックアップ](/qorex/security-and-recovery#back-up-now) を参照してください。 |
| **入金済みのアカウントが「あなたのアカウント」から消えた** | 何も失われていません。すべてのアカウントはリカバリーフレーズから再導出されるため、これはデータ損失ではなく表示上の問題です。これは **1.0.9** 以前のモバイルビルドに存在した実際の不具合で、現在は修正済みです。デバイスのセキュアストレージからの読み取りが（おそらくアンロック直後に）瞬間的に失敗し、アカウント一覧が短く表示されることがありました。QoreX を更新してください（修正は 1.0.9 以降のすべてのバージョンに含まれています）。すでに最新版でこの現象が発生した場合は、アプリを閉じて再度開くと表示が戻るはずです。「アカウントを追加」をタップすると、欠けているアカウントが復元されるのではなく **新しい** アカウントが作成されるため、既存のアカウントが再び表示されるまではタップしないでください。 |
| **「The EVM lane needs an open authorisation window for this account. Open one here first — MetaMask cannot.」**（または「Your EVM authorisation window has run out」、あるいは「That authorisation window was refused」） | アカウントに開いているウィンドウがない（またはブロック数、トランザクション数、金額を使い切った）ため、MetaMask / EVM レーンのトランザクションが拒否されました。[EVM アクセスウィンドウ](/qorex/security-and-recovery#evm-window) でウィンドウを開いてから、再試行してください。送信する *前* に開いてください。ウィンドウを開くとアカウントのナンスが進むため、それ以前に準備したトランザクションは「nonce too low」で失敗します。アカウントにまだポスト量子鍵がない場合、QoreX は先に登録するよう案内します。 |
| **「This network needs an updated QoreX. Update the app and try again — nothing was sent.」** | ネットワークは、お使いのビルドが生成するものより新しい署名形式を検証します。ストアから QoreX を更新して再試行してください。何も送信されておらず、手数料も取られていません。 |
| **「Too many transactions from this account in a short time. Wait a minute and try again.」** | ネットワークは、1 つのアカウントが短時間に送信できるトランザクション数を制限しています。1 分待ってください。 |
| **「That address can't receive ordinary transfers.」** | ネットワークは、そのアドレス（一部のシステムまたはモジュールアドレス）への通常の送金を拒否します。受取人を確認してください。 |
| **「Not enough unlocked QOR to pay the network fee. Vesting QOR cannot pay fees…」** または **「Claiming needs about … QOR unlocked」** | 請求とアンステークの手数料は、（報酬が届く前の）*アンロック済み* 残高から支払われます。そのアドレスに少量の QOR を送ってから、再試行してください。 |
| **「The network ran out of gas before finishing. The fee was taken and nothing moved — your rewards are still there.」** | トランザクションはブロックに到達し、そこで失敗しました。再試行してください。失敗した試行の手数料は消費されています。 |
| **「Unstaking this much would drop your validator's self-bond below the required 100,000 QOR.」** | バリデーター運営者のみが該当します。セルフボンドの下限は、バリデーターが稼働している間は適用されます。アンステークする量を減らしてください。 |
| ダッシュボードまたは MetaMask から復元したアカウントから送金すると **「Account 'qor1…' does not exist on chain」** と表示される | QoreX を最新バージョンに更新してください。このアカウントは Ethereum 形式（coin 60）のアカウントです — [MetaMask またはダッシュボードからフレーズを復元する](/qorex/getting-started#restore-dashboard) を参照してください。最初の送金では、そのアカウントのポスト量子鍵も登録されます（少額の追加手数料がかかります）。 |
| **フレーズを復元したら 2 つ目のアカウント / 資金が見当たらない** | 復元で戻るのは **アカウント 1** のみです。設定 → あなたのアカウントで **アカウントを追加**（MetaMask やダッシュボードで使っていたフレーズの場合は **Ethereum アカウントを追加（coin 60）**）をタップしてください。アカウントは同じアドレスで再導出されます。 |
| **拡張機能: 「ウォレット」にパスキーがオフになったと表示される** | ウォレットを追加または削除すると、ボールトが再封印され、パスキーによるロック解除が解除されます（新しいウォレットをカバーできないためです）。ポップアップのホーム画面から再度オンにしてください。Firefox ではパスキーによるロック解除は提供されません。 |
| **プッシュ通知が届かなかった** | プッシュはメインネット専用で、端末の設定で QoreX の通知が許可されていることと、**プッシュ通知** のスイッチがオン（ホーム → ベルのアイコン）になっていることが必要です。通知は QOR が届いたことだけを知らせ、金額は表示しません。詳細はアプリの **通知** 一覧で確認できます。 |
| **Android: 戻るボタン** | 戻るボタンは前の画面に戻ります。ホームでは、アプリが終了します。 |

## それでも解決しない場合

- ガーディアンとデバイスのリンクについては、[セキュリティと復旧](/qorex/security-and-recovery) のページを確認してください。
- QoreChain 自体に関する質問は、[メインドキュメント](/introduction/what-is-qorechain) または [qorechain.io](https://qorechain.io) にリンクされているコミュニティチャンネルを参照してください。
