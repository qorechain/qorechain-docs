# トラブルシューティング

QoreX アプリと拡張機能に関するよくある質問とすばやい解決策です。

| 症状 | 原因 / 解決策 |
|---|---|
| オンボーディング時に **"Secure your device first"** と表示される | システム設定で Face ID または指紋を登録してから、アプリに戻ってください。ウォレットは生体認証で保護されたデバイスでのみ作成できます。 |
| **サインインシートが閉じた** / "That sign-in attempt expired" | 前回の試行が中断されました。もう一度サインインをタップするだけで大丈夫です。 |
| Google / Dashboard でのサインイン後に **"Add a passkey" が表示されない** | 想定どおりの動作です。パスキーはメールコードのアカウントにのみ紐づきます（[アカウント & Dashboard](/qorex/account-and-dashboard#sign-in) の注記を参照）。 |
| **"Handles coming soon"** | @handle レジストリに一時的にアクセスできません。ウォレットには影響ありません。レジストリが復旧すると、ハンドルは自動的に有効になります。 |
| デバイスのリンク中に **"Wrong code or damaged QR"** | 10 文字のコードを再確認し（アルファベットは紛らわしい文字を除いています：0/O/1/I/L はありません）、再スキャンしてください。どちらの成果物も一度きりの使用です。 |
| **カメラ画面に権限が必要と表示される** | iOS: 設定 → QoreX → カメラ。Android: アプリ情報 → 権限 → カメラ。 |
| **拡張機能: "No wallet yet"** | 拡張機能は QoreX モバイルアプリで作成したウォレットとペアリングします。まずそちらで作成してください。 |
| **読み取り専用アドレスからの送金が拒否される** | そのアドレスは別のウォレットに属しています（ラベルにどのウォレットかが表示されます）。QoreX は自身の派生アカウントに対してのみ署名できます。所有しているウォレットから送金してください。 |
| **テストネットバッジが表示される** | 設定 → **"Use testnet (developers)"** がオンになっています。オフにするとメインネットに戻ります。 |
| **Swap ボタンが無効になっている** | 現時点では想定どおりです。プールの流動性が利用可能になると Swap は自動的に有効になります。アプリの更新は不要です。 |

## それでも解決しない場合

- ガーディアンとデバイスのリンクについては、[セキュリティ & リカバリー](/qorex/security-and-recovery) のページをご覧ください。
- QoreChain 自体に関する質問は、[メインドキュメント](/introduction/what-is-qorechain) または [qorechain.io](https://qorechain.io) にリンクされているコミュニティチャンネルをご覧ください。
