# 開発者モード

開発者モードは QoreX の**設定**にあるスイッチです。**デフォルトはオフ**です。オンの間、QoreX は **QORE**CHAIN 上で開発する人向けのツール一式を表示します。ネットワークを読み取るインスペクター、トランザクションのシミュレーションとデコードの場、コントラクトとロールアップのツール、オフライン署名、そして AI エージェントが提案したトランザクションを確認する手段です。

開発者モードは署名のルールを一切変えません。署名するものは、これまでどおり署名内容を表示し、承認を待ちます。

## イノベーション {#innovations}

- **どのツールもまず読み取りか確認。** インスペクターは読み取るだけです。署名できるツールは、デコードした確認画面を表示して承認を待ちます。
- **ネットワークからの正確な数値。** インスペクターは、チェーン自体が報告する内容を表示します。バージョン、機能、アカウントの登録済みの鍵、EVM ウィンドウです。
- **わかりやすい言葉のエラー。** エラーデコーダーは、生のネットワークエラーを文章に変え、次にすべきことを示します。
- **提案するのは AI エージェント、決めるのはあなた。** エージェントは許可された内容を読み取り、トランザクションを提案できます。QoreX は確認してシミュレーションし、あなたは通常の承認ウィンドウで承認または拒否します。どのエージェントも署名できません。

## オンにする方法 {#how-to-use}

- **モバイルアプリ（iPhone と Android）:** **設定**を開き、**開発者モード**をオンにします。下部バーにコードのアイコン（`</>`）の**開発者**タブが表示されます。開くとツールが表示されます。設定をオフにすると、タブは再び非表示になります。
- **ブラウザ拡張機能:** ポップアップで、下部のバージョン番号を 7 回タップします。ポップアップに**開発者モード**のセクションが表示され、**開発者ツール**ボタンがあります。このボタンは、アプリのタブと同じグループを持つページを開きます。同じセクションに**開発者モードをオフにする**があります。

同じセクションにネットワークの切り替えがあります。アプリでは設定の**テストネットを使う（開発者向け）**、拡張機能では**テストネット（diana）に切り替え**です。テストネットにしかないものについては、[テストネット機能](/qorex/testnet-features)を参照してください。

ツールに別の記載がない限り、アプリと拡張機能のツールは同じです。次のグループに分かれています。

## 確認 {#inspect}

読み取り専用で、メインネットとテストネットで使えます。これらの画面では何も署名も送信もしません。

### ネットワークと機能のインスペクター

接続しているネットワークと、その対応内容を表示します。チェーン ID、ノードのバージョン、最新ブロック、適用済みの最新アップグレードと予定されているもの、チェーンが報告するプロトコル機能（有効、段階的、無効）、EVM レーンのチェーン ID、SVM レーンが実行されるか閉じているか、クロス VM とポスト量子のパラメータ、ネットワークが掲載する IBC チャネルとブリッジルートの数です。2 つ目の**このウォレット**には、QoreX のバージョン、ビルド（アプリか拡張機能）、このビルドが使う署名方法とシミュレーションモードが表示されます。

使い方: **ネットワークと機能のインスペクター**を開きます。**更新**をタップすると再読み込みします。値の横の**コピー**でコピーできます。

### アカウントインスペクター

アクティブなアカウントを表示します。Cosmos アカウント（coin 118）か統合アカウント（coin 60）か、スロットと導出インデックス、各レーンのアドレス（ネイティブ `qor1...`、EVM `0x...`、SVM 鍵）、公開鍵です。表示されるのは公開情報のみで、秘密情報がボルトから出ることはありません。

使い方: **アカウントインスペクター**を開き、**アドレスと公開鍵を表示**をタップします（ロック解除を求められる場合があります）。

### PQC インスペクター

あなたのアカウントについてチェーンに登録された ML-DSA-87 鍵を表示します。アルゴリズム、登録された高さ、公開鍵の SHA-256、サイズ、チェーンのルールが引き続き受け付けるか、所持証明です。さらに、その鍵をこの端末の鍵と比較し、一致するかを示せます（正規の鍵、古い導出方式、番号付きのローテーション）。**操作を守っているもの**の表もあり、ネイティブ送金、EVM トランザクション、SVM トランザクション、IBC 送金、外部チェーンでの送金について、どの署名がポスト量子でどれが従来型かを示します。

使い方: **PQC インスペクター**を開いてチェーン上の鍵を読み取り、**この端末の鍵と比較**をタップして比較します。チェーンが登録済みの鍵を拒否する場合、画面は登録し直しが必要だと表示します。

### EVM ウィンドウインスペクター

アカウントに有効な EVM ウィンドウがあるか、開いた高さと期限の高さおよびおおよその時刻、使用済みと残りの取引数と金額、許可内容（QOR の送金のみ、または呼び出しと送金。許可された受取人とコントラクト）を表示します。ウィンドウの開閉はここではなく、EVM ウィンドウ画面で行います。[セキュリティとリカバリー](/qorex/security-and-recovery#evm-window)を参照してください。

使い方: **EVM ウィンドウインスペクター**を開きます。ウィンドウが「読み取れませんでした」と表示される場合、それはウィンドウがないという意味ではありません。

## トランザクション {#transactions}

ツールに別の記載がない限り、メインネットとテストネットで使えます。

### トランザクションインスペクター

トランザクションハッシュ（QoreChain、または `0x` 付きの EVM）か生のリクエスト（SignDoc JSON、base64 の TxRaw、EVM トランザクション JSON、dApp リクエスト）を貼り付けます。QoreX はすべてのメッセージをデコードし、署名者、受取人、移動する資金、手数料、メモ、要求された権限を表示し、ポスト量子署名が付いているかを示します。ネットワーク上にすでにあるトランザクションは、結果、使用ガス、イベントも表示します。QoreX が読み取れないメッセージタイプは、生のバイト列とともに不明と表示され、推測はしません。リクエストは端末上で読み取られ、送信されることはありません。

使い方: **トランザクションインスペクター**を開き、貼り付けて**検査**をタップします。

### シミュレーションワークベンチ

QoreChain のメッセージを JSON で、または EVM トランザクションを貼り付けると、QoreX はネットワークがどう処理するかを問い合わせます。何も署名も送信もしません。成功するかどうか、使用ガスと手数料、該当する場合は 1 回限りのポスト量子鍵登録手数料、アカウントの資産の変化、そしてシミュレーションで示せないものの一覧（コントラクト自体の状態や、後のブロックで実行されるクロス VM のステップなど）が表示されます。ネットワークエラーは、組み込みの**エラーデコーダー**がわかりやすい言葉にデコードし、次の対処を提案します。生のログ、結果の JSON、エラーメッセージを貼り付けて**デコード**をタップします。

使い方: **シミュレーションワークベンチ**を開き、**QoreChain メッセージ**か **EVM トランザクション**を選び、貼り付けて**シミュレート**をタップします。

### 手数料とスポンサー

チェーンの最低ガス価格、QoreX がガスあたりに支払う額、一般的な操作（送金、ステーキング、EVM ウィンドウを開く、IBC 送金）のコスト、次のトランザクションで 1 回限りの鍵登録も支払うか、そして受け取った手数料の肩代わり枠と付与した枠を、それぞれの判定（支払われるか、拒否される理由: 期限切れ、使い切り、メッセージタイプが違う）とともに表示します。QoreX は自分の手数料を自分で支払い、fee granter を自ら指定することはありません。

使い方: **手数料とスポンサー**を開きます。開くと読み込みます。

### テストネット作業スペース

テストネットで開発するためのツールで、メインネットには一切触れません。

- **テストネット専用アカウント。** リカバリーフレーズから作るアカウントで、QoreX はメインネットでの署名を決して許さず、メインネットがアクティブな間は非表示にします。**テストネット専用アカウントを作成**をタップします。
- **フォーセット。** テストネットのアドレスをコピーして、**テストネットのフォーセットを開く**をタップします。フォーセットは Dashboard にあり、利用にはそこでのサインインが必要です。[テストネット機能](/qorex/testnet-features#get-test-qor)を参照してください。
- **接続のリセット。** **すべての接続をリセット**は、すべてのサイトを切断し、待機中のすべてのリクエストを拒否し、サイトが最近署名させたコントラクトを忘れます。確認のため 2 回タップします。

利用可否: 画面はどちらのネットワークでも開きます。テストネット専用アカウントとフォーセットはテストネット向けです。

### リクエストログ

サイトが何を求め、あなたがどう判断し、ネットワークがどう応答したかを一覧表示します。端末上にのみ、開発者モードがオンの間だけ、最大 500 件、7 日間保存されます。リカバリーフレーズ、鍵、パスワードは記録せず、署名した内容も記録しません（タイプとハッシュのみ）。ブラウザを閉じた後も保持する、消去する、または不具合報告に添付する**デバッグファイルを書き出す**ことができます。ファイルは書き出し前にフレーズや鍵が含まれていないか確認されます。

使い方: **リクエストログ**を開きます。先に開発者モードをオンにしないと、何も記録されません。

## コントラクトとロールアップ {#contracts}

### コントラクト操作

自分のアカウントで EVM、CosmWasm（QoreChain Native）、SVM のコントラクトを呼び出します。読み取りは無料で、状態を変えるものは dApp のリクエストと同じ承認を通り、シミュレーションとポスト量子署名の追加が行われます。

使い方:

1. **コントラクト操作**を開き、**コントラクトの種類**を選びます。
2. EVM: コントラクトアドレスを入力し、**ABI (JSON)** を読み込みます。各関数は、read、write、payable のタグが付いた型付きフォームになります。QoreX は QOR を受け取れない関数に金額を指定することを拒否します。
3. CosmWasm: コントラクトアドレスを入力し、必要に応じて `cosmwasm-schema` のスキーマを読み込み、**メッセージ (JSON)** と、必要なら資金（`1000uqor` のように記述）を入力します。読み取りには**クエリ**、署名される内容を正確に確認するには**実行内容を確認**を使います。
4. SVM（テストネットのみ）: プログラム ID を入力し、**Anchor IDL (JSON)** を読み込みます。QoreX は自分の Solana 鍵で Solana トランザクションに署名し、QoreChain アカウントでリレーします。
5. **シミュレート**をタップしてネットワークが示す呼び出しの結果を確認してから、**確認して署名**（または**承認へ進む**）を選び、承認ウィンドウで承認します。

コントラクトはネットワークごとに保存でき、ファイルに書き出して再び読み込めます。**コントラクト情報**パネルには、CosmWasm コントラクトの code id、作成者、ラベル、管理者が表示されます。

### デプロイ承認

コマンドラインツール、IDE、エージェントが用意したデプロイを承認します。QoreX はコードハッシュを自分で計算し、コンストラクタ引数をデコードし、署名前に誰がコントラクトをアップグレードできるかを確認します。ツールが示すハッシュがバイト列と一致しない場合は拒否します。アップグレード可能なプロキシのパターン、自分のアカウントではない管理者やアップグレード権限、移行が永久にできない管理者なしのコントラクトについて警告します。EVM コントラクトのデプロイと、保存済みコードからの CosmWasm コントラクトのインスタンス化に対応します。QoreX は CosmWasm コードをアップロードせず、このバージョンでは SVM プログラムのデプロイに対応していません。コードのアップロードをガバナンス経由で行うネットワークでは、ウォレットから署名できません。

使い方: **デプロイ承認**を開き、ツールのデプロイリクエスト JSON を貼り付け（**形式を表示**をタップすると形式が分かります）、**確認**をタップして内容を読み、**承認して署名**を選びます。

### ロールアップとアプリチェーンのプロファイル

QoreChain RDK で構築したロールアップやアプリチェーンを追加します。QoreX はプロファイルを保存する前にそのノードに実際に問い合わせ、各チェックを表示します。REST と RPC のチェーン ID、アドレスの接頭辞、EVM チェーン ID、QoreChain 上のロールアップです。プロファイルはメインネットにもテストネットにも決済できます。プロファイルが有効な間は、すべての確認画面でどのネットワークが署名するかを尋ね、チェーン ID を確認できないノード向けの署名は拒否されます。

使い方: **ロールアップとアプリチェーンのプロファイル**を開き、**プロファイルを追加**をタップして、名前、チェーン ID、エンドポイントを入力し、**確認して追加**を選びます。切り替えには**有効にする**または**使用をやめる**、いつでも**再確認**できます。

## その他の仮想マシン {#other-vms}

### QoreChain 上の Solana（テストネットのみ）

QoreChain **テストネット**の SVM レーンです。SVM ウィンドウと、署名済み Solana トランザクションのリレーを扱います。このツールはテストネットがアクティブな間のみ表示されます。メインネットの SVM レーンは開いておらず、ここのものは何も使えません。詳細と手順は[テストネット機能](/qorex/testnet-features#solana-on-qorechain)にあります。

### クロス VM 呼び出し

自分のアカウントから、QoreChain 自体の別の実行レーン（EVM、CosmWasm、SVM）にあるコントラクトへの呼び出しを組み立てます。何も QoreChain の外に出ません。他のチェーンへのブリッジではありません。フォームでは、対象レーン、コントラクトまたはプログラム、ペイロード、そして CosmWasm の場合のみ添付する QOR を指定します。

**実行のタイミング**を選ぶと、QoreX はその内容をはっきり示します。

- **今すぐ、このトランザクション内で (アトミック):** すべてが実行されるか、何も実行されないかです。
- **後のブロック用にキューへ (非アトミック):** 後のブロックで実行されます。失敗やタイムアウトになっても、このトランザクションが行ったことはそのまま残ります。

使い方: **クロス VM 呼び出し**を開き、フォームを入力して**シミュレート**をタップしてステップと手数料を確認し、**署名して送信**を選びます。QoreX はシミュレーションした呼び出しのみに署名します。ネットワークでクロス VM 呼び出しがオフの場合、画面はその旨を表示し、署名するものは何も提示しません。現在のメインネットではクロス VM 呼び出しは閉じているため、そのメッセージが表示されます。

### クロス VM 呼び出しを追跡

トランザクションのハッシュ（QoreChain、または EVM の `0x`）を貼り付けると、QoreX はクロス VM の各レッグを読み取ります。キューに入ったレッグは保留、実行済み、失敗、タイムアウトのいずれかで表示されます。EVM トランザクションのレッグはトランザクション内で実行されるため、その結果から読み取ります。完了したキューのレコードはしばらくするとネットワークで削除され、レコードがない場合はトラッカーがその旨を表示します。

使い方: **クロス VM 呼び出しを追跡**を開き、ハッシュを貼り付けて**追跡**をタップします。

## 署名とエージェント {#signing-and-agents}

### 権限とセッション

あなたのアカウントが他のアドレスに許可したすべての内容を、チェーン自体が強制する上限とともに一覧表示し、それぞれ取り消せます。**権限付与**、**手数料の肩代わり**、**リンクされた鍵**、**アクセスウィンドウ**です。それぞれに、できること、上限、期限（または期限なし）が表示されます。**取り消す**は取り消しトランザクションを送信し、**ウィンドウを閉じる**は EVM ウィンドウを閉じます。

**新しいセッション**で、アプリや別のアドレスに制限付きのセッションを与えることもできます。一覧のコントラクトのみの呼び出し、設定額までの送金、選んだバリデーターへのステーキング、投票と報酬の請求を、指定した日数の間許可し、必要に応じて上限まで手数料を肩代わりします。**プレビュー**は、付与される側ができることを正確に示し、チェーンが強制しないもの（QoreX が毎回あなたに確認します）を別に一覧表示します。

### オフラインおよびマルチシグ作業スペース {#multisig}

任意のトランザクションをチェーンのコマンドライン形式のファイルとして準備する、マルチシグファイル内のすべての署名を確認する、ある端末で署名して別の端末からブロードキャストする、といった作業ができます。

- **オフライン署名:** オンラインの端末でトランザクションを準備し（送金、デリゲート、コントラクト呼び出しなどのテンプレートから始めるか、メッセージを貼り付けます）、ファイルまたは QR コードを鍵を持つ QoreX に渡し、内容を確認して**署名**し、どちらの端末からでも**ネットワークに送信**します。
- **署名を確認:** トランザクションと署名ファイルを開きます。QoreX は、各マルチシグメンバーについて、ポスト量子鍵が登録されているか、ラウンド 1（ポスト量子）とラウンド 2（従来型）が有効、古い、無効、不足のいずれか、そしてどのラウンドがまだ足りないかを表示します。

確認画面には必ずメモとすべての手数料コインが表示され、QoreX は確認したバイト列にのみ署名します。QOR 以外のコインの手数料、ネットワークの高いガス価格を大きく上回る手数料、別のアカウントが支払う、または肩代わりする手数料は拒否します。確認後にファイルが変わった場合は、開き直して再確認する必要があります。QoreX は ML-DSA-87 署名のないトランザクションをブロードキャストしません。

## AI エージェント {#ai-agents}

AI エージェント（あなた自身の AI アシスタント、またはあなたが実行するツール）は、あなたが選んだアカウントを読み取り、トランザクションを**提案**できます。署名はできません。モデルは次のとおりです。

1. エージェントがどのアカウントを閲覧し、提案できるかはあなたが決めます。いつでも一時停止や取り消しができ、**アクティビティ**一覧にはエージェントが行ったことが表示されます。
2. QoreX はすべての提案を確認し、ネットワークでシミュレーションします。QoreX が読み取れない提案や、ネットワークが失敗すると示す提案は、あなたに表示されません。
3. 提案は通常の承認ウィンドウに、Web サイトではなく AI エージェントの提案として表示され、あなたが承認または拒否します。承認するまで何も署名されません。

QoreX は、誰が提案しても、外部の者が要求できない種類のリクエストには決して署名しません。1 時間あたりの提案数の上限で大量送信を防ぎ、待機できる提案は一度に 1 件だけです。

使い方:

- **モバイルアプリ:** 開発者モードをオンにして **AIエージェント**を開き、エージェントの提案 JSON を貼り付けて**提案を確認**をタップするか、`qorex://propose` リンクを開きます。QoreX は貼り付けられた提案やリンクの作成者を確認できないため、その旨を表示します。確認して承認または拒否します。
- **ブラウザ拡張機能（Chrome、Edge、Brave、Firefox）:** エージェントは、Model Context Protocol を使うコンピューター上のコンパニオンプログラムを通じて接続します。このプログラムはまだ公開されていないため、拡張機能側はまだ一般には利用できません。公開されたら、**このコンピューターでAIエージェントの接続を許可する**をオンにし、5 分で期限切れになる 1 回限りのコードでエージェントとペアリングして、アカウントを選びます。
- **Safari:** 利用できません。Safari は QoreX をコンピューター上のプログラムに接続できません。

## 制限事項 {#limits}

- 開発者モードは開発する人向けです。送金、受け取り、ステーキングだけなら必要ありません。
- ネットワークに依存するツール（インスペクター、シミュレーター、トラッカー）は、ネットワークに接続できない場合「読み取れませんでした」と表示します。何もないという意味ではありません。
- SVM のツールとクロス VM の作成ツールは、ネットワークが許可する内容に依存します。現在のメインネットでは、SVM とクロス VM の呼び出しは閉じています。
- ブラウザ拡張機能では、スイッチを表示するためにバージョン番号のタップが必要です。アプリでは設定にあります。
