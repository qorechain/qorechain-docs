# ブラウザ拡張機能

QoreX の**ブラウザ拡張機能**（Chrome と Firefox。同一機能を備えた Safari 版も準備中です）は、デスクトップ向けの **dApp コネクタ**です。ウェブサイトがあなたのウォレットを検出できるようにし、すべてのリクエストを明示的な承認へと変えます。これはモバイルアプリと概念的に対をなすものであり、ステーキング、ポートフォリオ、アカウント機能は**含みません**。それらの機能はアプリ側にあります。

## セットアップ

拡張機能は、**QoreX モバイルアプリ**で作成したウォレットとペアリングします。ペアリング前にポップアップを開くと、**「No wallet yet — create one in the QoreX app.」**と表示されます。

## ロック解除

ポップアップは、あなたの**ボールトパスワード**（ブラウザがパスキー由来の鍵をサポートしている場合はパスキー）を要求します。ボールトは拡張機能のストレージ内で AES-256-GCM 暗号化されており、自動的にロックされ、ロック解除は毎回明示的に行われます。

## dApp への接続

ウェブサイトは、**EIP-6963**（マルチウォレット標準）と QoreChain の connect コントラクトを通じて QoreX を検出します。QoreX は `window.ethereum` や `window.keplr` を**決して上書きしません**。他のウォレットと**並んで**表示され、サイトごとにどのウォレットを使うかを選べます。

1. サイトが接続を要求すると、承認ポップアップに**オリジン**が表示されます。
2. 承認すると、そのオリジンにはあなたの**公開アドレス**のみが開示されます。
3. 承認は**オリジンごと**であり、ブラウザの再起動をまたいで保持されます。あるサイトの承認が別のサイトに何かを付与することはありません。

## 署名

すべての署名リクエストは、**デコードされたペイロード**（受取人、金額、ネットワーク）を表示する承認ウィンドウを開きます。素のハッシュが表示されることは決してありません。

- Native レーンの QoreChain トランザクションについては、**dApp がポスト量子レイヤーを提供する**ことを拡張機能が注記します（ウォレットは古典的な半分に署名します。これは既存のウォレットが用いるのと同じパターンです）。
- リクエストが**古典署名のみ**の場合、ポップアップには明示的な警告が表示されます。**「⚠ This request is a classical signature — the app did not add a quantum-safe layer.」**
- **Reject** は常にワンクリックであり、リクエストは自動的に期限切れになります。

## 外部ネットワークでの送信

ポップアップから、**ETH / BNB / POL / ARB / SOL** と **ERC-20 / SPL** トークンを送信できます（アプリと同じシード導出を使用します）。送信前に古典署名に関する注記を承認する必要があります。結果リンクを開くとブロックエクスプローラーが表示されます。

## ネットワークとセキュリティの姿勢

- **アクティブなネットワーク** — デフォルトは QoreChain **メインネット**です（EVM レーンではチェーン `0x2649`）。テストネットは、それを要求する dApp のためにサポートされ続け、ネットワークをまたぐ署名リクエストは拒否されます。
- **パーミッション** — 拡張機能は **`storage` のみ**を要求します。コンテンツスクリプトはプロバイダ API のみを注入します。ウォレットリクエスト以外のページコンテンツを読み取ることはなく、アナリティクスもリモートコードもありません。
