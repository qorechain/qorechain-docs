# QoreX をはじめる

このページでは、**モバイルアプリ**のインストールと、ウォレットの作成・復元・連携の手順を説明します。デスクトップウォレットについては、Chrome、Firefox、Safari で提供中の [ブラウザ拡張機能](/qorex/browser-extension) を参照してください。

:::note モバイルの提供状況
- **Android** — Google Play で提供中です: https://play.google.com/store/apps/details?id=network.qore.qorex
- **iOS** — お試しになりたい場合は **TestFlight** 経由でテストに参加できます。App Store 版は現在審査中です。最新の招待リンクは [qorechain.io](https://qorechain.io) でご確認ください。
:::

## はじめる前に: デバイスを保護する

QoreX ウォレットは、デバイスに**強力なロック要素**が設定されている場合にのみ作成・インポートできます。これがハードウェアの保管庫内で鍵を保護します。次のいずれかが該当します。

- **iOS** — Face ID または Touch ID。
- **Android** — Class-3 の生体認証（指紋、虹彩、または 3D 顔認証）**または**デバイスの画面ロック（PIN、パターン、またはパスワード）。

:::note Android の 2D 顔認証
カメラベースの 2D 顔認証（一部のデバイス、たとえば特定の Samsung モデルに搭載）は*弱い*生体認証として扱われます。それしか設定していない場合、QoreX はその背後にある **PIN / パターン**に頼ります。システムのシートが自動的にそれを提示するため、引き続き保護されます。
:::

強力な要素が登録されていない場合、作成／インポートのボタンは無効のままとなり、画面には何を有効にすればよいかが説明されます。システム設定で Face ID、指紋、または画面ロックを設定してから、QoreX に戻ってください。

## 初回起動

アプリは、**デバイスにウォレットが存在しない場合にのみ**オンボーディング画面で開きます。ウォレットを一度作成すると、以降の起動はすべて直接ホーム（ウォレット）タブに移動します。残高の表示に生体認証は不要ですが、**取引の署名には必ず必要です**。

セットアップの方法は 3 通りあります。

### 1. 新しいウォレットを作成する

1. **新しいウォレットを作成**をタップします。
2. QoreX はデバイス上で **24 語のリカバリーフレーズ**（256 ビットのエントロピー）を生成し、QoreChain のアイデンティティを導出します — コインタイプ 118、`qor1…` アドレス（ETH と SOL のアカウントも同じシードから生成されます）。
3. **24 語を書き留め**、オフラインで保管してください。このフレーズは、デバイスを紛失した場合にウォレットを復元する**唯一**の方法です。
4. フレーズを確認します。QoreX はそれをハードウェアで保護され、生体認証でゲートされた保管庫に封印します。

:::caution リカバリーフレーズがすべてです
24 語を知る者は誰でもあなたの資金を管理でき、QoreChain Association を含め、誰もあなたに代わってそれを復元することはできません。フレーズを絶対にウェブサイトに入力したり、共有したり、スクリーンショットやクラウドのメモに保存したりしないでください。
:::

### 2. 既存のウォレットを復元する

1. **既存のウォレットを復元**をタップします。
2. 24 語を順番どおりに入力します。
3. QoreX は同じアドレスを再導出します — あなたのウォレットはどのデバイスでも同一に表示されます。

### 3. 別のデバイスから連携する

すでに別のスマートフォンやタブレットに QoreX がある場合は、**サーバーも入力も不要**でウォレットを移行できます — [新しいデバイスを連携する](/qorex/security-and-recovery#link-device) を参照してください。新しいデバイスで**別のデバイスから連携**を選んで開始します。

## 任意: @handle を取得する

ウォレットを作成した後、一意の **@handle**（たとえば `@liviu`）を取得できます。これにより、`qor1…` アドレスの代わりに名前で送金してもらえます。これは任意でスキップ可能です — ウォレットがこれに依存することはありません。[アカウントとダッシュボード](/qorex/account-and-dashboard#handle) を参照してください。
