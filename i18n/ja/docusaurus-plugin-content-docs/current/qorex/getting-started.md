# QoreX をはじめる

このページでは、**モバイルアプリ**のインストールと、ウォレットの作成・復元・連携の手順を説明します。デスクトップ用ウォレットについては [ブラウザ拡張機能](/qorex/browser-extension) をご覧ください。Chrome、Firefox、Safari で公開中です。

:::note モバイルの提供状況
- **Android** — Google Play で入手できます: https://play.google.com/store/apps/details?id=network.qore.qorex
- **iOS** — **TestFlight** 経由でテスト版を入手できます: https://testflight.apple.com/join/Xa9D7vgR — App Store 版は現在審査中です。
:::

## はじめる前に: デバイスを保護する

QoreX ウォレットは、デバイスに**強力なロック解除要素**が設定されている場合にのみ作成・インポートできます。これが、ハードウェア保管領域内の鍵を守る仕組みです。次のいずれかを満たしていれば有効です。

- **iOS** — Face ID または Touch ID。
- **Android** — クラス 3 の生体認証 (指紋、虹彩、または 3D 顔認証)、**あるいは**デバイスの画面ロック (PIN、パターン、パスワード)。

:::note Android の 2D 顔認証について
カメラによる 2D 顔認証 (一部のデバイス、たとえば特定の Samsung 機種に搭載) は*弱い*生体認証として扱われます。これしか設定されていない場合、QoreX はその背後にある **PIN / パターン**を利用します。システムのシートが自動的にそれを提示するため、引き続き保護されます。
:::

強力な要素が登録されていない場合、作成／インポートのボタンは無効のままとなり、画面に有効化すべき項目が表示されます。システム設定で Face ID、指紋、または画面ロックを設定してから QoreX に戻ってください。

## 初回起動

アプリがオンボーディング画面で開くのは、**デバイスにウォレットが存在しない場合のみ**です。ウォレットを作成した後は、以降の起動ではホーム (ウォレット) タブに直接移動します。残高の表示に生体認証は不要ですが、**取引への署名には必ず必要**です。

セットアップの方法は 3 通りあります。

### 1. 新しいウォレットを作成する

1. **新しいウォレットを作成**をタップします。
2. QoreX はデバイス上で **24 語のリカバリーフレーズ**を生成し (256 ビットのエントロピー)、QoreChain のアイデンティティを導出します。コインタイプは 118 で、`qor1…` 形式のアドレスになります (ETH と SOL のアカウントも同じシードから生成されます)。
3. **24 語を書き留めて**オフラインで保管してください。このフレーズは、デバイスを紛失した際にウォレットを復元できる**唯一の**手段です。
4. フレーズを確認すると、QoreX はそれをハードウェアで保護された生体認証付きの保管領域に封入します。

:::caution リカバリーフレーズがすべてです
24 語を知っている人は誰でもあなたの資産を操作できます。QoreChain Association を含め、誰もそれを代わりに復元することはできません。フレーズを web サイトに入力したり、他人と共有したり、スクリーンショットやクラウドのメモに保存したりしないでください。
:::

### 2. 既存のウォレットを復元する

1. **既存のウォレットを復元**をタップします。
2. 24 語を順番どおりに入力します。
3. QoreX が同じアドレスを再導出します。どのデバイスでもウォレットは同一に見えます。

### 3. 別のデバイスから連携する

すでに別のスマートフォンやタブレットで QoreX を使っている場合、**サーバーも入力も不要**でウォレットを移行できます。[新しいデバイスを連携する](/qorex/security-and-recovery#link-device) をご覧ください。新しいデバイスで**別のデバイスから連携**を選んで開始します。

## 任意: @handle を取得する

ウォレットの作成後、固有の **@handle** (たとえば `@liviu`) を取得できます。これにより、`qor1…` アドレスの代わりに名前で送金してもらえます。取得は任意であり、スキップできます。ウォレットがこれに依存することはありません。[アカウントと Dashboard](/qorex/account-and-dashboard#handle) をご覧ください。
