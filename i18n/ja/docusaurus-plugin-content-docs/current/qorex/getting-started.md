# QoreX をはじめる

このページでは、**モバイルアプリ**のインストールと、ウォレットの作成・復元・連携の手順を説明します。デスクトップ用ウォレットについては [ブラウザ拡張機能](/qorex/browser-extension) をご覧ください。Chrome、Firefox、Safari で公開中です。

:::note モバイルの提供状況
- **Android** — Google Play で提供中です (Android 7.0 以降): https://play.google.com/store/apps/details?id=network.qore.qorex
- **iOS** — App Store で提供中です (iOS 15.1 以降): https://apps.apple.com/us/app/qorex-wallet/id6791256626
:::

## はじめる前に: デバイスを保護する

QoreX ウォレットは、デバイスに**強力なロック解除要素**が設定されている場合にのみ作成・インポートできます。これが、ハードウェア保管領域内の鍵を守る仕組みです。次のいずれかを満たしていれば有効です。

- **iOS** — Face ID または Touch ID。
- **Android** — クラス 3 の生体認証 (指紋、虹彩、または 3D 顔認証)、**あるいは**デバイスの画面ロック (PIN、パターン、パスワード)。

:::note Android の 2D 顔認証について
カメラによる 2D 顔認証 (一部のデバイス、たとえば特定の Samsung 機種に搭載) は*弱い*生体認証として扱われます。これしか設定されていない場合、QoreX はその背後にある **PIN / パターン**を利用します。システムのシートが自動的にそれを提示するため、引き続き保護されます。
:::

強力な要素が登録されていない場合、作成／インポートのボタンは無効のままとなり、画面に有効化すべき項目が表示されます。システム設定で Face ID、指紋、または画面ロックを設定してから QoreX に戻ってください。

## 初回起動

アプリがオンボーディング画面で開くのは、**デバイスにウォレットが存在しない場合のみ**です。ウォレットを作成した後は、以降の起動ではホーム (ウォレット) タブに直接移動します。残高の表示に生体認証は不要ですが、**取引への署名には必ず必要**です。

セットアップの方法は 3 通りあります。

### 1. 新しいウォレットを作成する

1. **新しいウォレットを作成**をタップします。
2. QoreX はデバイス上で **24 語のリカバリーフレーズ**を生成し (256 ビットのエントロピー)、それをそのままハードウェアで保護された生体認証付きの保管領域に封入して、QoreChain のアイデンティティを導出します。コインタイプは 118 で、`qor1…` 形式のアドレスになります (ETH と SOL のアカウントも同じシードから生成されます)。**ウォレットの作成中、アプリはフレーズを表示しません。**
3. **フレーズを表示して、すぐに書き留めてください。** **設定 → セキュリティ → リカバリーフレーズを表示**を開き、生体認証またはデバイスの PIN で確認したうえで、24 語を順番どおりに紙へ書き写します。オフラインで保管してください。このフレーズは、デバイスを紛失した際にウォレットを復元できる**唯一の**手段です。
4. 必要に応じて[ソーシャルリカバリー](/qorex/security-and-recovery#social-recovery)を設定します。ホームの**バックアップの状態**カードが追跡するのはソーシャルリカバリーのみです。フレーズを書き留めたかどうかは判別できないため、リマインドされることはありません。

:::danger 手順 3 を今すぐ行ってください — アプリは何も知らせてくれません
ウォレットの作成後、アプリはそのままホームへ移動するため、フレーズを一度も書き留めないまま使い続けてしまいがちです。**何かを受け取ったり送ったりする前に、必ず行ってください。**書き留めたフレーズも、設定済みの[ソーシャルリカバリー](/qorex/security-and-recovery#social-recovery)もない状態で、アプリを紛失・アンインストールした場合、またはスマートフォンを紛失した場合、QoreChain Association を含め、誰もあなたの資産を取り戻すことはできません。
:::

:::caution リカバリーフレーズがすべてです
24 語を知っている人は誰でもあなたの資産を操作できます。QoreChain Association を含め、誰もそれを代わりに復元することはできません。フレーズを Web サイトに入力したり、他人と共有したり、スクリーンショットやクラウドのメモに保存したりしないでください。**QoreX をアンインストールすると、そのデバイスに保存されている鍵は削除されます** — 書き留めたフレーズ (または事前に設定した[ソーシャルリカバリー](/qorex/security-and-recovery#social-recovery)) がなければ、アンインストールはアクセスを永久に失うことを意味します。ウォレットに資金を入れる前に、後回しにせず必ずバックアップを取ってください。
:::

### 2. 既存のウォレットを復元する {#2-restore-an-existing-wallet}

1. **既存のウォレットを復元**をタップします。
2. **リカバリーフレーズ** (24 語を書き留めている場合) または**ソーシャルリカバリー** (ガーディアンを設定済みでフレーズをもう持っていない場合 — [ソーシャルリカバリー](/qorex/security-and-recovery#social-recovery) を参照) のいずれかを選びます。
3. リカバリーフレーズの場合: 24 語を順番どおりに入力します。QoreX は大文字・小文字や余分な空白を正規化してフレーズを検証し、単語が正しく確認できない場合は、汎用的なエラーではなく明確にその旨を伝えます。
4. QoreX が同じアドレスを再導出します。どのデバイスでもウォレットは同一に見えます。

:::note 追加のアカウントは 1 つずつ戻ります
フレーズから復元すると、**アカウント 1** が戻ります。以前のウォレットで複数のアカウントを使っていた場合は、**アカウントを追加** (設定 → アカウント) をタップして次のアカウントを復元してください。これらは同じフレーズから導出されるため、同じアドレスで再び表示されます。Ethereum 形式のアカウントは **Ethereum アカウントを追加 (coin 60)** で追加します。[MetaMask またはダッシュボードのフレーズを復元する](#restore-dashboard) を参照してください。以前のウォレットで作成したのと同じ順序で追加してください。アカウントはスロットごとに番号が付けられるため、新しいデバイスで順序が異なると、同じスロットに別のアカウントが割り当てられる場合があります。
:::

### 3. 別のデバイスから連携する

すでに別のスマートフォンやタブレットで QoreX を使っている場合、**サーバーも入力も不要**でウォレットを移行できます。[新しいデバイスを連携する](/qorex/security-and-recovery#link-device) をご覧ください。新しいデバイスで**別のデバイスから連携**を選んで開始します。

## 1 台のデバイスで複数のウォレットを使う {#several-wallets}

各ウォレットにはそれぞれ**固有のリカバリーフレーズ**があります。たとえばメインのウォレットと、別のサービスから復元したウォレットなど、1 台のスマートフォンに複数を保持でき、ワンタップで切り替えられます。

- **モバイル:** 設定 → **ウォレット**に、このスマートフォン上のウォレットが一覧表示されます。1 つをタップするとそれがアクティブなウォレットになり、アプリ全体がそのウォレットに切り替わります (チェーン上では何も動きません)。**ウォレットを追加**では、新規作成、リカバリーフレーズからの復元、別のデバイスからの連携が行えます。すでにあるウォレットはそのまま残ります。スマートフォンにすでにあるフレーズを復元した場合は、そのウォレットに切り替わるだけです。
- **拡張機能:** ポップアップの**ウォレット**画面でも同じ操作ができ、すべてのウォレットに**共通のパスワード 1 つ**を使用します。ウォレットの追加または削除では、保管領域を再封入するためにパスワードを 1 回求められ、パスキーによるロック解除はオフになります (ホーム画面から再度オンにしてください)。
- **ウォレットを削除**する (*このスマートフォンから削除* / *このブラウザから削除*) と、そのウォレットの鍵がデバイスから削除されます。資産はチェーン上に残りますが、元に戻せるのはそのリカバリーフレーズだけです。先に書き留めておいてください。

## MetaMask またはダッシュボードのフレーズを復元する {#restore-dashboard}

デフォルトでは、QoreX はコインタイプ **118** のリカバリーフレーズから `qor1…` アドレスを導出します。最初に MetaMask で使われたフレーズ、または QoreChain ダッシュボードで作成されたウォレットのフレーズでは、QOR は代わりに **Ethereum 形式**のアドレス (コインタイプ **60**) にあるため、復元しても**アカウント 1** は空に見えます。何も失われていません。Ethereum 形式のアカウントを追加してください。

1. ストアから QoreX を最新バージョンに更新します。
2. **ウォレットを追加** (設定 → ウォレット → *ウォレットを追加* → *既存のウォレットを復元*) してフレーズを入力します。既存のウォレットはそのまま残ります。拡張機能の場合: **ウォレット** → 復元。
3. 設定 → **アカウント**を開き、**Ethereum アカウントを追加 (coin 60)** をタップします。最初のタップでインデックス 0 のアカウントが追加されます。これは MetaMask がそれらの単語に対して表示するものと同じ `0x…` アドレスであり、そのアカウントの QoreChain `qor1…` アドレスと同じ鍵です。QOR はここにあります。
4. そのアカウント (*Ethereum · coin 60* と表示されます) に切り替えます。そこから送金、ステーキング、報酬の請求ができます。最初の送金では、そのアカウントのポスト量子鍵も登録され、少額の 1 回限りの手数料がかかります。

Ethereum 形式のアカウントには @handle がなく (@handle はコインタイプ 118 の QoreChain `qor1…` アカウントで取得します)、Web サイトはこのアカウントでは `signDirect` ではなく `signAndBroadcast` で署名します。**Ethereum アカウントを追加 (coin 60)** をタップするたびに、次のインデックスが追加されます。

## 使い方の案内 {#find-your-way}

- **検索** — ホーム上部の虫眼鏡では、画面 (「stake」)、コイン (「USDC」)、人 (@handle またはアドレス)、メモ、トランザクションハッシュの先頭部分を検索できます。@handle または `qor1…` アドレスを入力すると、**QOR を … に送る**が直接表示されます。
- **ツアー** — ウォレットが初めてホームで開いたときに、QoreX でできることと各機能の場所を説明する短いカードが 5 枚表示されます。表示は 1 回のみで、設定 → **ツアーをもう一度見る**から再生できます。

## 任意: @handle を取得する

ウォレットの作成後、固有の **@handle** (たとえば `@liviu`) を取得できます。これにより、`qor1…` アドレスの代わりに名前で送金してもらえるようになります。取得は任意でありスキップ可能です — ウォレットがこれに依存することは一切ありません。(ブラウザ拡張機能では、バージョンによっては取得に対応していません。ポップアップに表示されない場合は、モバイルアプリから取得してください。) @handle はウォレット全体ではなく特定のアドレスに紐づくため、複数のアカウントを持つようになると重要になります。詳しくは [1 つのフレーズから複数のアカウント](/qorex/account-and-dashboard#accounts) と [@handle](/qorex/account-and-dashboard#handle) をご覧ください。

## 言語

QoreX は英語、ルーマニア語、ドイツ語、スペイン語、フランス語、イタリア語、トルコ語、アラビア語、日本語、韓国語の 10 言語に対応しており、スマートフォンの言語設定に自動的に従います。それ以外の言語の場合は英語にフォールバックします。検出された言語はいつでも**設定 → 言語**から変更できます。アラビア語を選択すると、インターフェースが右から左のレイアウトに切り替わります。
