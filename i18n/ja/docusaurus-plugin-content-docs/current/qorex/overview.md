# QoreX Wallet

**QoreX** は、量子耐性を備えたレイヤー1である **QoreChain**（メインネット `qorechain-vladi`）の公式**非カストディアル**ウォレットです。秘密鍵は**お客様のデバイス上でのみ**生成・保管され、QoreChain Association が資金にアクセスすることは一切ありません。また、アプリは**データを一切収集しません**。Native レーンにおけるすべての QOR 送金には**ハイブリッド耐量子署名**（ML-DSA-87、NIST FIPS-204、secp256k1 との組み合わせ）が付与されるため、従来型の攻撃者と量子攻撃者の双方から資金が保護されます。

QoreX は、連携して動作する 2 つの部分で構成されています。

- **ブラウザ拡張機能** — デスクトップ向けウォレットで、**Chrome、Firefox、Safari（macOS）で公開・提供中**です。単体で使えるウォレット（作成／インポート、QOR の保有と送金）であると同時に、あらゆるウェブサイトが QoreX を検出し、すべてのリクエストを明示的な承認に変えるためのコネクタでもあります。[ブラウザ拡張機能](/qorex/browser-extension)を参照してください。
- **モバイルアプリ**（Android・iOS） — フル機能のウォレットです。作成／復元、量子耐性のある QOR の送受信、外部ネットワーク、ステーキング、ポートフォリオ、リカバリー、アプリ内 dApp ブラウザを備えています。現在は公開テスト中です（提供状況は下記を参照）。

## 対応プラットフォーム

| 機能 | モバイルアプリ（Android・iOS） | ブラウザ拡張機能 |
|---|---|---|
| ウォレットの作成／インポート | ✅ | ✅（単体で利用可） |
| QOR の送受信（耐量子） | ✅ | ✅（ポップアップから） |
| 外部ネットワーク（Ethereum、BNB Chain、Polygon、Arbitrum、Solana、Cosmos Hub、Osmosis、Celestia＋トークン） | ✅ | ✅（ポップアップから送金） |
| ステーキング、ポートフォリオ、Q-Day Scanner、リカバリー、Legacy | ✅ | — |
| dApp との接続 | ✅（アプリ内ブラウザ） | ✅（あらゆるウェブサイト） |
| アカウント（@handle、支払いリクエスト） | ✅ | — |
| 複数デバイスのリンク | ✅ | — |
| ダッシュボードとのペアリング | ✅ | ✅（接続＋提案された送金、v0.1.5） |

## QoreX が他と違う理由

- **標準で量子耐性** — Native レーンの QOR 送金には常に ML-DSA-87 + secp256k1 のハイブリッド署名が付与されます。従来型の暗号にとどまるもの（外部チェーン）は明確に表示され、黙って処理されることはありません。
- **真の非カストディアル** — 鍵はデバイス上で生成され、ハードウェアに裏付けられたボールト（iOS では Secure Enclave、Android では StrongBox）または暗号化ボールト（拡張機能）に保管されます。デバイスの外に出ることはありません。
- **データ収集なし** — いずれの QoreX アプリにも、アナリティクス、トラッキング、広告はありません。任意のアカウントサインインによって便利な機能が追加されますが（[アカウントとダッシュボード](/qorex/account-and-dashboard)を参照）、ウォレットがそれに依存することはありません。
- **統合された単一残高** — お客様の QOR は Native、EVM、SVM の各レーンをまたいで 1 つの残高として扱われ、QoreX は単一の数値として表示します。
- **複数のリカバリー手段** — 24 語のリカバリーフレーズ（常時）、ガーディアンと 48 時間のタイムロックを用いる任意のソーシャルリカバリー、任意の Legacy 相続機能、そして便利な複数デバイスのリンクがあります。

## はじめる

- QoreX を初めて使う方は、[はじめに](/qorex/getting-started)からウォレットの作成または復元を行ってください。
- 次に、量子耐性のある QOR の[送受信](/qorex/send-and-receive)を学びましょう。
- [セキュリティとリカバリー](/qorex/security-and-recovery)でセーフティネットを設定してください。
- デスクトップでは、[ブラウザ拡張機能](/qorex/browser-extension)をインストールしてください。

:::note ダウンロードと提供状況
- **ブラウザ拡張機能** — 公開・提供中です。[Chrome Web Store、Firefox Add-ons、または Mac App Store（Safari）](/qorex/browser-extension#install)からインストールしてください。
- **Android アプリ** — Google Play で**公開テスト**として利用できます。
- **iOS アプリ** — お試しになりたい場合は、**TestFlight** 経由でテスト版を利用できます。

最新の公式リンクは [qorechain.io](https://qorechain.io) でご確認いただき、QoreX は必ず公式の配布ページからのみインストールしてください。
:::
