# QoreX ウォレット

**QoreX** は、耐量子レイヤー1である **QoreChain**（メインネット `qorechain-vladi`）の公式 **非カストディアル** ウォレットです。秘密鍵は **お使いの端末上でのみ** 生成・保管され、QoreChain Association があなたの資産にアクセスすることは一切ありません。また、各アプリには **解析ツール、トラッキング、広告が一切含まれていません**。Native レーン上のすべての QOR 送金には **ハイブリッド耐量子署名**（ML-DSA-87、NIST FIPS-204、secp256k1 との組み合わせ）が付与されるため、従来型の攻撃者と量子攻撃者の双方から資産が保護されます。

QoreX は、連携して動作する2つの要素で構成されています。

- **ブラウザ拡張機能** — デスクトップ向けウォレットで、**Chrome、Firefox、Safari（macOS）で公開・提供中** です。単体で完結するウォレット（作成／インポート、QOR の保有と送金）であると同時に、あらゆるウェブサイトが QoreX を検出し、すべてのリクエストを明示的な承認に変えるためのコネクタでもあります。[ブラウザ拡張機能](/qorex/browser-extension)をご覧ください。
- **モバイルアプリ**（Android・iOS） — フル機能のウォレットです。作成／復元、耐量子 QOR の送受信、外部ネットワーク、ステーキング、ポートフォリオ、リカバリー、アプリ内 dApp ブラウザを備えています。Android は **Google Play**、iOS は **App Store** で提供しています（提供状況は下記を参照）。

:::caution ウォレットを作成したらすぐにリカバリーフレーズをバックアップしてください
QoreX は非カストディアルです。QoreChain Association が、紛失したウォレットを復旧したり、リセットしたり、代わりに復元したりすることはできません。**アプリをアンインストールする、スマートフォンをリセットする、または拡張機能を削除すると、その端末からあなたの鍵が削除されます。** 24語のリカバリーフレーズを書き留めてください（モバイルアプリはウォレットの作成中にはフレーズを表示しません — **設定 → セキュリティ → リカバリーフレーズを表示** から表示できます。拡張機能は作成時に一度だけ表示します）。可能であれば、[ソーシャルリカバリー](/qorex/security-and-recovery#social-recovery)も設定してください。[今すぐバックアップ](/qorex/security-and-recovery#back-up-now)をご覧ください。
:::

## QoreX が他と違う理由

- **標準で耐量子** — Native レーンの QOR 送金には、常に ML-DSA-87 + secp256k1 のハイブリッド署名が付与されます。従来型の暗号方式が使われる場合（外部チェーン）は必ず明示され、黙って処理されることはありません。
- **真の非カストディアル** — 鍵は端末上で生成され、ハードウェアに裏付けられた保管領域（iOS の Secure Enclave、Android の StrongBox）または暗号化された保管領域（拡張機能）に保存されます。鍵が端末の外に出ることはありません。
- **解析ツールなし、トラッキングなし、広告なし** — QoreX のどのアプリにも含まれていません。任意の追加機能は、あなたが有効にしたときにのみサーバーを使用します。アカウントサインイン（[アカウントと Dashboard](/qorex/account-and-dashboard) を参照）と、プッシュ通知です。プッシュ通知は、QOR が着金したときに QoreX がお知らせできるよう、あなたの端末と*公開*アドレスを登録します。ウォレットがどちらかに依存することはありません。
- **統合された単一残高** — あなたの QOR は Native、EVM、SVM の各レーンをまたいだ1つの残高であり、QoreX はそれを単一の数値として表示します。
- **複数のリカバリー手段** — 24語のリカバリーフレーズ（常時利用可能。モバイルでは 設定 → セキュリティ から表示）、ガーディアンと48時間のタイムロックを用いる任意のソーシャルリカバリー、任意の Legacy による継承、そして便利な複数端末リンクに対応しています。

## はじめる

- QoreX を初めて使う方は、[はじめに](/qorex/getting-started) からウォレットを作成または復元してください。
- 次に、耐量子 QOR の[送受信](/qorex/send-and-receive)の方法を学びましょう。
- [セキュリティとリカバリー](/qorex/security-and-recovery)で、万一に備えた保護策を設定してください。
- デスクトップでは、[ブラウザ拡張機能](/qorex/browser-extension)をインストールしてください。

## ダウンロードと提供状況 {#availability}

- **ブラウザ拡張機能** — 公開・提供中です。[Chrome Web Store、Firefox Add-ons、または Mac App Store（Safari）](/qorex/browser-extension#install)からインストールしてください。必ず公式のストア掲載ページからインストールしてください。
- **Android アプリ** — Google Play で本番提供中です: https://play.google.com/store/apps/details?id=network.qore.qorex（Android 7.0 以降）。
- **iOS アプリ** — **App Store** で提供中です: https://apps.apple.com/us/app/qorex-wallet/id6791256626（iOS 15.1 以降）。

## どのバージョンがどこで提供されているか {#versions}

ストアの審査は各ストアごとのスケジュールで進むため、あるストアが別のストアより古い、または新しいビルドを一時的に配信していることがあります。**2026年10月15日**時点:

| プラットフォーム | 提供中のバージョン |
|---|---|
| Android | 1.1.6 |
| iOS | 1.1.6 |
| Chrome | 0.3.6 |
| Firefox | 0.3.7（0.3.6 の後のポイントリリース） |
| Safari（macOS） | 1.7.6（拡張機能 0.3.6 を搭載） |

このドキュメントは 1.1.6 / 0.3.6 の機能セットについて説明しています。まだ古いビルドを配信しているストアも自動的に追いつきます。ストアには常に現在のバージョンが表示されます。1.0.9 / 0.2.6 以降の主な変更点:

- 1台のスマートフォンまたはブラウザで **複数のウォレット** を利用でき、それぞれが独自のリカバリーフレーズを持ち、ワンタップで切り替えられます — [複数のウォレット](/qorex/getting-started#several-wallets)をご覧ください。
- MetaMask や Dashboard で最初に使われたフレーズ向けに、手動で追加する **イーサリアム形式（coin 60）のアカウント** — [MetaMask または Dashboard からフレーズを復元する](/qorex/getting-started#restore-dashboard)をご覧ください。
- **コントラクトによるトークンの追加**、**任意のネットワークでの受け取り**、グローバル **検索**、初回 **ツアー**、**ホーム画面ウィジェット**、QOR の着金時の **プッシュ通知**（モバイル） — [送受信](/qorex/send-and-receive)をご覧ください。
- **受け取りと再ステーク**、受け取り前の手数料チェック、**アンステーク進行中** リスト、そしてアンステークできなくなるほどステークしてしまう前の警告 — [ポートフォリオとステーキング](/qorex/portfolio-and-staking)をご覧ください。
- すべてのメッセージ、手数料、支出上限、有効期限を表示し、QoreX が表示できないものは拒否する承認画面。dApp 向けの **`signAndBroadcast`**、**接続済みサイト** からの取り消し（拡張機能）、**EVM アクセスウィンドウ** — [セキュリティとリカバリー](/qorex/security-and-recovery)および[ブラウザ拡張機能](/qorex/browser-extension)をご覧ください。
- 修正: 残高のあるアカウントが一時的に「あなたのアカウント」から消えることがある問題（1.0.9）、Android のハードウェア戻るボタンが 1 画面だけ戻るようになりました（1.1.1）、Android 14 以降では、アクセシビリティ以外のサービスに対してリカバリーフレーズが隠されるようになりました（1.1.6）。
