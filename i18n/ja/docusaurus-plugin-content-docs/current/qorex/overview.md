# QoreX ウォレット

**QoreX** は、耐量子性を備えたレイヤー1である **QoreChain**（メインネット `qorechain-vladi`）の公式**非カストディアル**ウォレットです。秘密鍵はお使いの**デバイス上でのみ**生成・保管され、QoreChain Association があなたの資金にアクセスすることは決してなく、アプリは**一切のデータを収集しません**。Native レーン上のすべての QOR 送金には**ハイブリッド耐量子署名**（ML-DSA-87、NIST FIPS-204、secp256k1 と組み合わせたもの）が付与されるため、あなたの資金は古典的攻撃者と量子攻撃者の双方から保護されます。

QoreX は連携して動作する2つの部分から構成されます。

- **ブラウザ拡張機能** — デスクトップ向けウォレットで、**Chrome、Firefox、Safari（macOS）で公開・稼働中**です。単体で動くウォレット（作成/インポート、QOR の保有と送金）であると同時に、任意のウェブサイトが QoreX を検出し、あらゆるリクエストを明示的な承認へと変えるコネクターでもあります。[ブラウザ拡張機能](/qorex/browser-extension)をご覧ください。
- **モバイルアプリ**（Android と iOS） — フル機能のウォレットです。作成/復元、耐量子性を備えた QOR の送受信、外部ネットワーク、ステーキング、ポートフォリオ、リカバリー、アプリ内 dApp ブラウザを備えています。現在は公開テスト中です（下記の提供状況をご覧ください）。

| 機能 | モバイルアプリ（Android と iOS） | ブラウザ拡張機能 |
|---|---|---|
| ウォレットの作成 / インポート | ✅ | ✅（単体） |
| QOR の送受信（耐量子） | ✅ | ✅（ポップアップから） |
| 外部ネットワーク（ETH / BNB / POL / ARB / SOL + トークン） | ✅ | dApp 署名経由 |

| dApp 接続 | ✅（アプリ内ブラウザ） | ✅（任意のウェブサイト） |
| アカウント（@handle、支払いリクエスト） | ✅ | — |
| 複数デバイスのリンク | ✅ | — |
| ダッシュボードのペアリング | ✅ | ✅（接続 + 送金提案、v0.1.5） |

## QoreX が違う理由

- **デフォルトで耐量子** — Native レーンの QOR 送金には常に ML-DSA-87 + secp256k1 のハイブリッド署名が付与されます。古典的なもの（外部チェーン）はすべて明確に表示され、こっそり行われることは決してありません。
- **真に非カストディアル** — 鍵はデバイス上で生成され、ハードウェアに裏打ちされた保管領域（iOS では Secure Enclave、Android では StrongBox）または暗号化された保管領域（拡張機能）に保存されます。鍵がデバイスから出ることはありません。
- **データ収集なし** — いずれの QoreX アプリにも、分析、トラッキング、広告はありません。任意のアカウントサインインによって利便性が加わります（[アカウントとダッシュボード](/qorex/account-and-dashboard)をご覧ください）が、ウォレットがそれに依存することは決してありません。
- **統一された単一残高** — あなたの QOR は Native、EVM、SVM レーンをまたいで1つの残高であり、QoreX はそれを単一の数値として表示します。
- **複数のリカバリー手段** — 24単語のリカバリーフレーズ（常時）、ガーディアンと48時間のタイムロックを用いた任意のソーシャルリカバリー、任意の Legacy 相続、そして便利な複数デバイスのリンク。
