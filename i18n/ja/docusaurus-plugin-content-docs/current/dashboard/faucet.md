# フォーセット

**フォーセット**は、価値のあるものを一切消費せずにダッシュボードを試せるよう、無料のテストトークンを提供します。これは**テストネット専用**のツールです。送金、スワップ、ステーキング、コントラクトのデプロイをテストする前に、テストネット（`qorechain-diana`）上でアドレスに資金を供給するために使用してください。

:::caution テストネット専用 — 実際の価値はありません
テストネットの QOR には**実際の価値はありません**。フォーセットがメインネットに触れることは一切ありません。メインネット QOR 用のフォーセットは存在せず、ここで受け取ったものをメインネットに移動することもできません。
:::

## テストトークンをリクエストする

1. **テストネット**に接続し、**フォーセット**を開きます。
2. 資金を受け取るアドレス（`qor1...`）を入力します。ウォレットが接続されている場合は、**自分のアドレスを使用**を選択すると自動的に入力されます。続行する前に、フォームがアドレスの有効性を確認します。
3. リクエストボタンを選択します。送金は数秒以内に処理されます。

リクエストが成功すると、確認カードに送信された金額とトランザクションハッシュが、コピーボタンおよび[エクスプローラー](/dashboard/explorer)でトランザクションを開くためのリンクとともに表示されます。

## 制限

各アドレスは、クールダウン期間ごとに 1 回だけフォーセットからリクエストできます。ページには、1 回のリクエストあたりの正確な金額と、再度受け取れるようになるまでのクールダウンが表示されます。早すぎるタイミングで再度リクエストした場合、フォーセットは次に受け取り可能になる時期を知らせます。

## テストトークンの使い道

テストトークンを使えば、テストネット上でネットワークをエンドツーエンドで試すことができます。

- [ウォレット](/dashboard/wallet)ページで送受信する。
- AMM で[スワップ](/dashboard/trade)を試す。
- バリデーターに[委任](/dashboard/staking-and-validators)する。
- メインネットに移行する前にコントラクトをデプロイしてテストする。

:::note テスト用の価値のみ
フォーセットのトークンはテストネット上に存在し、実際の価値はありません。本番環境で使用する準備ができたら、メインネット（`qorechain-vladi`）に切り替えてください。
:::
