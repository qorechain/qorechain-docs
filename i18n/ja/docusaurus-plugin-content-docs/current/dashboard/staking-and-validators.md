# ステーキングとバリデーター

このページでは、Dashboardからのステーキングについて説明します。QOR をバリデーターにデリゲートし、アンボンドし、報酬を請求する方法です。これらの操作は、**メインネット**で QoreX ウォレットを接続した状態の **Wallet** ページ(**Stake / Delegate** タブと **Rewards** タブ)にあります。先にバリデーターを比較するには、読み取り専用の [Validators](/dashboard/validators) ページを使用してください。デリゲートと報酬の背景にある概念については、[Staking & Delegation](/user-guide/staking-and-delegation) を参照してください。

## イノベーション {#innovations}

- **Dashboardがステーキング用の鍵を保持することはありません。** リクエスト(どのバリデーターに、どれだけ)はDashboard上で作成し、QoreX がそれを再構築して表示し、ML-DSA-87 ハイブリッド署名で署名してブロードキャストします。Dashboard は `qorex://tx?...` リンクを通じてパラメーターのみを送信し、知るのはトランザクションハッシュだけです。流れは [Send フロー](/dashboard/wallet#send-mainnet)と同じです。
- **恒久的にネイティブレーンのみ。** ステーキング、デリゲーション、バリデーター操作は、ハイブリッドのポスト量子署名を用いたネイティブ(Cosmos)レーンでのみ行われ、EVM プリコンパイル経由で行われることは決してありません。MetaMask に紐づいたアドレスは QOR を受け取ることができ、EVM ウィンドウが開いている場合は送信もできますが、ステーキングはできません。ステーキングできるのは QoreX に接続されたアドレスのみです。
- **バリデーターの並び順がステークを分散させます。** ボンド済みで jail されていないバリデーターのみが、小さい順に表示されます。先頭の枠はサーバー側で規模の小さい方の半数からランダムに選ばれるため、最大のバリデーターがデフォルトになることはありません。
- **ライトノードの閾値は合計で判定されます。** 「Currently bonded」は、すべてのバリデーターを合わせて数えたライトノードのステーク閾値と比較して表示されるため、不足分は複数のバリデーターに分けても構いません。
- **アンボンディング期間は必要な場所に表示されます。** 21日間のアンボンディング期間はチェーンから読み取られ、Delegate では1回、Unbond では意図的に2回表示されます。人々がそれを必要とするのがまさにその場面だからです。
- **署名前の手数料チェック。** パネルは使用可能な QOR(ベスティング中およびボンド済みのコインは除く)を読み取り、手数料を支払えるようになるまで **Continue in QoreX** を無効のままにします。

## 使い方 {#how-to-use}

前提条件: サインイン済みであること、ヘッダーが **Mainnet** であること、[確認事項](/dashboard/overview#risk-acknowledgement)に同意済みであること、そして [メインネットでウォレットを使う](/dashboard/wallet#mainnet) の説明どおりに QoreX ウォレットが接続されていること。

### バリデーターを選ぶ

[Validators](/dashboard/validators) を開き、コミッション、投票力、ステータスを比較します。このページは Dashboard の `/validators` にあります。サインインが必要で、サイドバーにはリンクがなく(アドレスを入力するか、ここのリンクをたどってください)、ヘッダーで選択したネットワークに連動します。APY 列はチェーンから読み取られ、「variable, not guaranteed, lock bonuses not included」という注記が付きます(または「From fees」と表示されます)。いかなる数値も約束されていません。選ぶ際は、次の点を考慮してください。

- **コミッション:** 料率が低いほど自分に残る報酬は多くなりますが、持続可能な運営のためには運営者側にも適切な取り分が必要です。
- **ステータス:** バリデーターは、10,000 ブロックのウィンドウ内で署名したブロックが 5% 未満になると jail されます。これはメインネットで 1 ブロックあたり約 3.1 秒の場合、ブロックを逃した状態がおよそ 8.3 時間続くことに相当します。ダウンタイムによる jail は固定で **600 秒** 続き、バリデーターは**ステークの 1%** を失います。二重署名はこれとは別の、より重大な違反であり、**5%** がスラッシュされます。これらは現行のチェーンパラメーターです(2026年10月27日に確認)。
- **投票力:** 複数のバリデーターにステークを分散させることは分散化を支えます。Delegate パネルの並び順がその助けになります。

### デリゲート {#delegate}

1. **Wallet** で **Stake / Delegate** タブを開き、**Delegate QOR** パネルを見つけます。
2. 情報ボックスを確認します。**Currently bonded** と **Light-node threshold** の比較、およびそれを満たしているかどうかです。この閾値は、すべてのバリデーターにわたるあなたのデリゲート済みステーク合計に対してチェックされます。「ライトノードに直接デリゲートする」方法はありません。デリゲーションは常にバリデーターを対象とし、ライトノードの資格判定は合計額に対する別のチェックです。
3. **Validator** ドロップダウンを開き、1つ選びます。先頭の項目は規模の小さい方の半数のバリデーターからランダムに選ばれ、再読み込みすると変わることがあります。残りはステークの小さい順に表示されます。jail されたバリデーターは表示されません。
4. **Amount (QOR)** を入力します。
5. 金額欄の下にある注記を読んでください。アンボンディングには 21 日かかり、ボンドされた QOR はその期間が終わるまで移動も売却もできません。
6. パネルに、このアドレスには手数料をまかなうのに十分な使用可能 QOR がないという警告が表示された場合は、先にこのアドレスへ少額の使用可能 QOR を送ってください。これが解消されるまで **Continue in QoreX** は無効のままです。
7. **Continue in QoreX** を選択します(リクエスト作成中は **Preparing...** と表示されます)。
8. パネルには「Approve it in QoreX」と、**Open QoreX**、リクエスト ID、そして拡張機能が検出された場合は **Approve in the browser extension** が表示されます。QoreX は署名前にバリデーターと金額を表示します。あなたが承認するまで何も送信されません。
9. QoreX で承認します。QoreX がデリゲーションを構築、署名、ブロードキャストします。

**最小の例:** 一覧の先頭のバリデーターに 10 QOR をデリゲートし、QoreX で承認します。

:::note タイムロック型ステーキングはダッシュボードの対象外です
リリース v3.2.4 でオプションのタイムロック型ステーキングモジュールが追加されます(メインネットでは 2026年10月23日から、テストネットでは 2026年10月19日から)。[タイムロック型ステーキング](/user-guide/staking-and-delegation#time-locked-staking)を参照してください。Dashboard にも QoreX にもそのための画面はありません。ここで行うデリゲーションはロックインのない通常のデリゲーションであり、待ち時間は、引き出す際の21日間のアンボンディングだけです。
:::

### リデリゲート {#redelegate}

Dashboard に Redelegate パネルはありません。**QoreX がバリデーター間でステークを直接移動します**(app 1.0.8 以降、拡張機能 0.2.6 以降)。21日間のアンボンディング待ちも報酬の損失もなく、1回のトランザクションで移動先の複数のバリデーターに分割することもできます。QoreX で **Stake** を開き、離れたいバリデーターをタップして、ステークの移動先を選んでください。[バリデーター間でステークを移動する](/qorex/portfolio-and-staking#move-stake) を参照してください。

この機能のない古い QoreX ビルドでは、代わりに2段階でステークを移動します。[アンデリゲート](#undelegate)し、アンボンディング期間が終わるのを待ち(その間 QOR は移動も報酬の獲得もできません)、その後新しいバリデーターに[デリゲート](#delegate)します。この回避策は21日分の報酬と余分な手数料がかかるため、可能であれば QoreX を更新してください。

### アンデリゲート {#undelegate}

:::caution 21日間のアンボンディング期間
アンデリゲートした QOR はすぐには届きません。まず**21日間のアンボンディング期間**を経る必要があり、その間は報酬が発生せず、移動も売却もできません。このパネルはこの注意をわざと二度表示します。一度はサブタイトルとして、もう一度は確認ボタンのすぐ上に。
:::

1. **Wallet** で **Stake / Delegate** を開き、Delegate の下にある **Unbond QOR** パネルまでスクロールします。
2. このアドレスにアクティブなデリゲーションがない場合、パネルはその旨を表示してそこで終わります。
3. **Unbond from** を開き、減らしたいデリゲーションを選びます。デリゲートしているバリデーターのみが、ボンド済み金額とともに一覧表示されます。
4. 金額を入力するか、**Unbond all X QOR** を選択してボンド済み金額全額を入力します。
5. ボンド額を超える金額を入力すると、送信がブロックされます。
6. 確認ボタンのすぐ上にある2つ目の警告を読んでください。QOR は今日ではなく21日後に届きます。
7. アドレスが手数料をまかなえない場合(ボンド済みのコインでは手数料を支払えません)、パネルが警告を表示し、ボタンを無効化します。
8. **Continue in QoreX** を選択し(リクエスト作成中は **Preparing...** と表示されます)、**Open QoreX** または **Approve in the browser extension** から QoreX で承認します。

QOR は、21日間のアンボンディング期間が終了して初めて再び使用可能になります。

### 報酬を請求する {#claim}

1. **Wallet** で **Rewards** タブを開きます。
2. **Staking rewards** パネルには、デリゲートしているすべてのバリデーターにわたる未受領の報酬が表示されます。このアドレスから何もステークされていない場合は、その旨が表示されます。
3. そうでなければ、請求待ちの合計と、バリデーターごとの行が表示されます。報酬は継続的に発生し、待っても失われることはありません。
4. **Claim in QoreX** を選択します。これは**すべての**バリデーターから一度に請求します。バリデーターごとの個別請求はありません。
5. QoreX で請求を承認します(**Open QoreX**、または **Approve in the browser extension**)。

## アクセス方法 {#how-to-access}

- **場所:** [dashboard.qorechain.io/wallet](https://dashboard.qorechain.io/wallet)、**Stake / Delegate** タブと **Rewards** タブ。サインインが必要です。
- **ネットワーク:** メインネットのみ。QoreX ウォレットが連携されている必要があります。テストネットのウォレットにはステーキング画面がありません。
- **ウォレット:** QoreX(アプリまたは拡張機能)。Keplr と MetaMask では Dashboard からステーキングできません。
- **費用:** ネットワーク手数料。使用可能な QOR から支払われます(下限は 1 ガスあたり 0.1 uqor)。Dashboard が手数料を請求することはありません。
- **資金:** ベスティング中の残高はデリゲートできる額には含まれますが、手数料の支払いには使えません。

## 制限事項と既知の問題 {#limits}

- **Dashboard にないもの:** リデリゲーション(QoreX を使用してください)とタイムロック型ステーキング。
- Dashboard では**テストネットのウォレットでのステーキングはできません**。
- **見積もりは概算です:** パネルに表示される手数料の見積もりとライトノードの閾値は、その時点でチェーンから読み取った値ではなく、Dashboard に組み込まれた値です。QoreX は署名前に正確な手数料を表示します。
- **アンボンディングは21日間**で、短縮することはできません。
- **請求は一括請求です。**
