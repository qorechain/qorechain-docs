# コントラクト監査ツール

**コントラクト監査ツール**は、**QCAI** を活用してスマートコントラクトの AI 駆動型セキュリティ分析を実行します。コントラクトを送信すると、QCAI が脆弱性をレビューし、全体のリスクレベルとセキュリティスコアを割り当て、各発見事項を推奨される修正案とともに説明します。[スマートコントラクトクリエーター](/dashboard/smart-contract-creator)と同様に、監査ツールも AI ツーリングとして **17 のブロックチェーン**に対応しています。

## 監査を実行する

1. サインインして **AI Audit** を開き、**Contract Source Code** にコントラクトを貼り付けます。必要に応じて **Blockchain**（デフォルトは **Auto-detect from code**）と **Name** を設定します。
2. **Run Security Audit** を選択します。QCAI がコントラクトをレビューし、レポートを生成します。**Export PDF** で保存できます。

## レポートを読む

監査レポートは専用のページで開き、次の内容が含まれます。

- **リスクレベル** — 全体の評価（例：critical、high、medium、low）。ひと目で確認できるよう色分けされています。
- **セキュリティスコア** — 0〜100 の総合スコア。
- **重大度の内訳** — 各重大度（critical、high、medium、low、informational）に該当する発見事項の件数。
- **サマリー** — コントラクトのセキュリティ状況の簡単な概要。

### 発見事項

各発見事項には、重大度、タイトル、該当するコード上の場所、問題の説明、推奨される修正案が記載されます。あるレベルで問題がないコントラクトの場合、レポートにその旨が表示されます。

該当する場合、レポートには、一般的な推奨事項、ガスの最適化、ベストプラクティス、コントラクトがすでに適切に行えている点に関するセクションも含まれます。

## 過去の監査を確認する

監査一覧には、過去のレポートが、コントラクト名、ブロックチェーン、リスクレベル、セキュリティスコア、作成日時とともにテーブルで表示されます。検索ボックスでコントラクト名またはブロックチェーンによる絞り込みができます。任意の行を選択すると、完全なレポートを再び開けます。レポートは**デフォルトで非公開**です。自分が所有するレポートでは、上部のスイッチに「This report is private」と表示されます。これをオンにするとレポートが公開され、リンクを持つ誰でも読めるようになります（あなたの名前と IP は決して表示されません）。オフにすると再び非公開になります。

:::tip デプロイ前に監査する
デプロイ前の最後のステップとして監査を実行し、変更があるたびに再実行してください。発見事項は、自動的な保証ではなく、確認すべき指針として扱ってください。レポートを、[テストネット](/getting-started/connecting-to-testnet)での独自のテストと組み合わせてください。
:::
