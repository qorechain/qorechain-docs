# バリデーター

**Validators** ページには、選択したネットワークのバリデーターが、サマリーカード、検索ボックス、そして各バリデーターのランク、投票力、コミッション、ステータス、チェーンから読み取った変動利回りの数値とともに一覧表示されます。これは、どこにデリゲートするかを検討する人のための、読み取り専用の比較ツールです。デリゲートボタンはありません。ステーキングは Wallet ページで行います。[ステーキングとバリデーター](/dashboard/staking-and-validators)を参照してください。

## イノベーション {#innovations}

- **一覧は選択したネットワークに連動します。** このページはヘッダーで選択したネットワークのバリデーターセットを取得するため、メインネットを見ている人にはメインネットのバリデーターが、テストネットを見ている人にはテストネットのバリデーターが表示されます。
- **チェーンから読み取った利回りと、その制限の明示。** APY 列は、チェーンのステーキングティアの基本レートに (1 - バリデーターのコミッション) を掛けたものです。アスタリスクと「variable, not guaranteed, lock bonuses not included」という注記が付いて表示されます。この数値は変動するプロトコルレートのリアルタイムの読み取り値であり、約束でも予測でもありません。
- **発行上限を超えた場合は「From fees」。** 発行上限を超えたネットワークでは、新しい QOR が発行されず、ステーキングの報酬がトランザクション手数料のみから得られるため、パーセンテージの代わりに **From fees** と表示されます。テストネットでは、現在この列は **From fees** と表示されます。不明な値はダッシュで表示され、0.00% になることはありません。
- **投票力によるランク。** ランクは投票力から計算されるため、ランク 1 は最もステークが多いバリデーターです。
- **正直な欠落表示。** リージョン、提案したブロック数、ソフトウェアバージョン、最終確認時刻は、データソースが提供する場合にのみ表示されます。稼働率が不明な場合は 0% ではなく **N/A** と表示されます。

## 使い方 {#how-to-use}

1. サインインし、アドレス `dashboard.qorechain.io/validators` からページを開きます。サイドバーにリンクはありません。
2. ヘッダーでネットワーク（**Mainnet** または **Testnet**）を選択します。ページがそのネットワークのバリデーターで再読み込みされます。
3. サマリーカードを確認します。**Active Validators**、**Total Bonded**、**Avg Commission**、**Avg Uptime** です。
4. 「Search by moniker or address」のボックスで検索します。
5. 各行を確認します。ランクとモニカー（アドレスとコピーボタン付き）、**Voting power**（ステークと全体に占める割合）、**Commission**、**APY**、**Status**（active、jailed、inactive）、続いて稼働率とオプションの詳細です。
6. デリゲートするには、Wallet ページの **Stake / Delegate** タブに移動します（[デリゲート](/dashboard/staking-and-validators#delegate)）。バリデーターをより詳しく見るには、[エクスプローラー](/dashboard/explorer#validators)でそのアドレスのページを開きます。

:::caution APY の注記を確認してください
このパーセンテージは、変更される可能性のあるプロトコルレートと、バリデーターのコミッションに依存します。オプションのタイムロック型ステーキングモジュールによるロックボーナスは含まれていません。保証された収入として扱わないでください。
:::

## アクセス方法 {#how-to-access}

- **URL:** [dashboard.qorechain.io/validators](https://dashboard.qorechain.io/validators)。アドレスを直接指定した場合のみ到達でき、サイドバーには表示されません。
- **サインイン:** 必須です。サインアウト状態では、ページに「Authentication Required」と表示されます。
- **ネットワーク:** ヘッダーの切り替えに連動します。
- **ウォレット:** ページを読むのに必要ありません。
- **費用:** 無料です。

## 制限事項と既知の問題 {#limits}

- **このページは読み取り専用**で、サイドバーからはリンクされていません。
- **APY は変動し、保証されません。** ロックボーナスは含まれず、発行上限に達している場合は **From fees** と表示されます。
- **ノードダッシュボードよりデータ項目が少ない:** リージョン、提案したブロック数、ソフトウェアバージョン、最終確認時刻は、利用可能な場合にのみ表示され、稼働率は N/A と表示されることがあります。
- **ジェイル（jailed）されたバリデーター**は jailed と表示され、Delegate パネルには表示されません。
- **データは短時間（約 30 秒）キャッシュされる**ため、チェーン上の変更が反映されるまで少し時間がかかる場合があります。
