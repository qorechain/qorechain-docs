# ブリッジ

ダッシュボードには、現在ブリッジ画面はありません。以前のプレビューは取り下げられており、現時点ではダッシュボードからクロスチェーン転送を開始することはできません。

:::caution 限定提供ステータス
クロスチェーンブリッジ自体はまだテストネット上にあり、段階的に展開されています。まだ本番のメインネットシステムではなく、そのチェーンルートは両ネットワークでまだ保留中です。どのルートも稼働しているものとして当てにしないでください。
:::

クロスチェーン転送がどのように検証されるかについては、[ブリッジアーキテクチャ](/architecture/bridge-architecture)と[資産のブリッジ](/user-guide/bridging-assets)を参照してください。ブリッジ画面が提供された時点で、このページでダッシュボードでのフローを説明します。
