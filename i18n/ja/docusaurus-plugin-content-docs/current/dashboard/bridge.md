# ブリッジ

Dashboard には、現在ブリッジ画面はありません。このページは、利用できるものとできないものを確認できるように用意されています。現時点では Dashboard からクロスチェーン転送を開始することはできず、`/bridge` ページも存在しません(`dashboard.qorechain.io/bridge` を開くと「not found」が返されます)。

:::caution 限定提供ステータス
クロスチェーンブリッジ自体はまだテストネット上にあり、段階的に展開されています。まだ本番のメインネットシステムではなく、そのチェーンルートは両ネットワークでまだ保留中です。どのルートも稼働しているものとして当てにしないでください。
:::

## イノベーション {#innovations}

Dashboard ではまだ使えるものがないため、挙げられる Dashboard のイノベーションはありません。チェーンがクロスチェーン転送をどのように検証するかについては、[ブリッジアーキテクチャ](/architecture/bridge-architecture)で説明しています。

## 使い方 {#how-to-use}

Dashboard からブリッジ転送を開始することはできません。クロスチェーン転送がどのように機能する予定かについては、[資産のブリッジ](/user-guide/bridging-assets)と[ブリッジアーキテクチャ](/architecture/bridge-architecture)をお読みください。ブリッジ画面が提供された時点で、このページで Dashboard でのフローを説明します。

## アクセス方法 {#how-to-access}

利用できません。ルートも、サイドバーの項目も、これを有効にするサインインやネットワークの設定もありません。

## 公開場所 {#where-published}

Dashboard のどこにもありません。まだ稼働していない機能のための「Bridge」バッジのシリーズが Badges ページに存在しますが、現時点では無視してください。

## 制限事項と既知の問題 {#limits}

- メインネットにもテストネットにも、Dashboard のブリッジ画面は存在しません。
- 以前のプレビューは取り下げられました。
- ブリッジはテストネット上の開発中のシステムであり、そのルートは両ネットワークで保留中です。
