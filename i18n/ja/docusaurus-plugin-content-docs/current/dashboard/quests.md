# クエスト

**クエスト**は、こなしながら QoreChain の使い方を学べるガイド付きのタスクです。各クエストは、ウォレットへの入金、送金、スワップの試用など、1 つ以上のステップをまとめたもので、完了すると報酬を獲得できます。クエストは、ネットワークを機能ごとに実践的に学ぶ方法です。

進捗が記録されるようにサインインしてください — [サインイン](/dashboard/overview#sign-in)をご覧ください。ウォレットが必要なクエストもあります。[ウォレットを接続する](/dashboard/overview#connect-your-wallet)をご覧ください。

## クエストを閲覧する

クエストページは、利用可能なクエストの数、進行中の数、完了した数の簡単なサマリーで開きます。オンボーディング、トレード、ソーシャル、コミュニティ、ラーニング、デイリー、ウィークリーなどの**カテゴリタブ**で一覧を絞り込めます。

各クエストは、次の内容を表示するカードとして表示されます。

- アイコン、タイトル、短い説明。
- **難易度**バッジ（例：easy、medium、hard）。
- 完了までの目安時間。
- 獲得できる**報酬**。
- **ステータス**：完了、進行中、開始済み、ロック中。

ロックされたクエストには、ロックが解除される前に完了する必要があるクエストが表示されます。

## クエストを完了する

1. クエストを開いて、タスクの全一覧を含む詳細ページを表示します。
2. 各タスクを順に進めます。タスクは、操作を行うために関連するダッシュボードのページへ誘導する場合や、検証できるようにステップの確認を求める場合があります。
3. 進捗バーで、完了したタスクの数を確認できます。
4. すべてのタスクが完了したら、**Check Completion** を選択してクエストを検証し、報酬を受け取ります。

デイリーまたはウィークリーのスケジュールでリセットされるクエストもあります。そのようなクエストでは、詳細ページにリセットの周期と現在の連続記録が表示されるため、定期的に戻ってくることで記録を継続できます。
