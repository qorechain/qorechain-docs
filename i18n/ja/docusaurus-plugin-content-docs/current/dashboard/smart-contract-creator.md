# スマートコントラクトクリエーター

**スマートコントラクトクリエーター**は、**QCAI** を活用して、自然な言葉による説明からスマートコントラクトを生成します。作りたいものを記述し、ターゲットとするブロックチェーンを選ぶだけで、QCAI がコントラクトを書いてくれます。AI ツーリングとして **17 のブロックチェーン**をサポートしているため、構築対象のエコシステムに合わせてターゲットを選べます。

**アカウントなし**でお試しいただけます。初めての訪問者は 1 回無料で生成でき、コントラクトの全体を確認できます。次の生成には無料アカウントが必要で、保存、監査、デプロイにも必要です。無料の試行を使い切ると、ページに **Create a free account** が表示されます。

生成したコントラクトを保存・管理するにはサインインしてください — [サインイン](/dashboard/overview#sign-in)をご覧ください。

## コントラクトを生成する

1. **例から始めるか、自分で記述します。** ページは「What would you like to build?」で開きます。**Or start from an example:** の下で **Token**、**NFT collection**、**Locked vault**、**2-of-3 multisig** のいずれかを選ぶと、それぞれが完全な説明を入力し、対応するブロックチェーンとテンプレートを選択します。あるいは **Contract Description** に自分で記述します。具体的に書くほど、結果は良くなります。
2. **ブロックチェーンを選択します。** **Target Blockchain** を使用します。選択したチェーンに対応するコントラクト言語とカテゴリーがセレクターの横に表示されます。
3. **コントラクトタイプを選びます**（任意）。**Contract Type** では、トークン、NFT、ガバナンスコントラクトなどの開始テンプレートを選べます。説明だけに任せる場合は **Custom (describe in prompt)** のままにしてください。
4. **生成します。** **Generate Smart Contract** を選択します。QCAI がコントラクトを生成する間、進行状況インジケーターにステータスが表示されます。

## 結果を確認する

生成が完了すると、ダッシュボードはコントラクトをシンタックスハイライト付きのビューで表示し、コントラクト名、ブロックチェーン、言語、ファイルサイズ、生成日時などの詳細も併せて表示します。使用したプロンプトも参照用に結果と一緒に表示されます。

ここから次の操作ができます。

- コントラクトコードをクリップボードに**コピー**する（**Copy Code**）。
- コントラクトを **PDF としてエクスポート**する（**Export PDF**）。
- 選択したブロックチェーンに適した形式のファイルとしてコントラクトを**ダウンロード**する（**Download File**）。
- コントラクトを**編集**してさらに磨き上げる（**Edit Contract**）。

## コントラクトをデプロイする {#deploy}

### メインネット（EVM）— ノンカストディアルデプロイ {#deploy-mainnet}

メインネットへのデプロイはノンカストディアルです。ダッシュボードはコントラクトをコンパイルし、**未署名**のデプロイデータを返します — あなたの鍵を保持することはなく、あなたに代わって署名することも決してありません。デプロイの署名とブロードキャストはあなた自身のウォレットで行い、その後ダッシュボードが生成されたコントラクトを記録します。

1. デプロイしたいコントラクト（EVM ターゲットのコントラクト）を開き、**Mainnet** で **Deploy** を選択します。メインネットでの操作が初めての場合は、[一度限りのリスク確認](/dashboard/overview#risk-acknowledgement)に同意してください。
2. まだ接続していない場合は **MetaMask** を接続します — [概要とはじめに](/dashboard/overview#connect-your-wallet)をご覧ください。チェーン v3.2.0 以降、EVM レーンでは、アカウントに登録済みのポスト量子鍵と、**開いている EVM 認可ウィンドウ**も必要です。これは QoreX から開きます（[MetaMask での送金](/dashboard/wallet#send-metamask)を参照）。ない場合、チェーンはデプロイを拒否します。
3. ダッシュボードがコントラクトをコンパイルし、未署名のデプロイトランザクションをあなたのウォレットに渡します。
4. MetaMask でトランザクション（ネットワーク、ガス、データ）を確認し、承認して自分自身で署名・ブロードキャストします。
5. デプロイがオンチェーンで確定すると、ダッシュボードは生成されたコントラクトアドレスを保存済みコントラクトと並べて記録します。

ダッシュボードからデプロイできるのは **EVM**（Solidity）コントラクトのみです。CosmWasm と Solana プログラムのデプロイは、現時点ではどちらのネットワークでも利用できません。

### テストネット — ワンクリック {#deploy-testnet}

テストネットでは、ダッシュボード管理のテストウォレットが EVM デプロイをワンクリックで署名・送信するため、メインネットに進む前に[フォーセット](/dashboard/faucet)のトークンで素早く試行を繰り返せます。テストネットはメインネットと同じ EVM レーンのルールを適用するため、アカウントにポスト量子鍵がない場合や、開いている EVM ウィンドウがない場合は、デプロイが拒否されることがあります。

## 共有と再利用

生成された各コントラクトには専用のページがあります。コントラクトは**デフォルトで非公開**です。自分のコントラクトを開けるのは自分だけです。所有者には、コントラクトページに **Public** / **Private** ボタンが表示されます。**Public** に設定すると、リンクを持つ誰でもコントラクトを開く（およびフォークする）ことができ、**Private** に戻すと公開を取り下げられます。所有していない公開コントラクトを開いた場合は、**フォーク**して自分のコピーを作り、そこから続けることができます。

:::tip 必ず確認してテストする
QCAI が生成したコードは強力な出発点ですが、レビューの代わりにはなりません。コントラクトを読み、[テストネット](/getting-started/connecting-to-testnet)でテストし、価値のあるものをデプロイする前に[コントラクト監査ツール](/dashboard/contract-auditor)で確認してください。
:::
