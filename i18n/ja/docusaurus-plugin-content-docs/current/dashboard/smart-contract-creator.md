# スマートコントラクトクリエーター

**スマートコントラクトクリエーター**（サイドバーの **Build**、項目名は **SC Creator**）は、QoreChain の AI アシスタントである **QCAIA** を使い、自然な言葉による説明から、選択したブロックチェーン向けのコントラクトのソースコードを生成します。トークン、NFT コレクション、ボールト、マルチシグの最初のたたき台がほしい方や、普段書かない言語でコントラクトが必要な方向けで、その後のレビュー、テスト、デプロイはご自身で行います。

:::tip 必ず確認してテストする
生成されたコードは強力な出発点ですが、レビューの代わりにはなりません。コントラクトを読み、[テストネット](/getting-started/connecting-to-testnet)でテストし、価値のあるものをデプロイする前に[コントラクト監査ツール](/dashboard/contract-auditor)で確認してください。
:::

## 革新ポイント {#innovations}

- **アカウントなしで 1 回生成できます。** 初めての訪問者は 1 回生成でき、コントラクトの全体を確認できます。訪問者ごとの上限と、全体の 1 日あたりの上限があります。無料お試しの結果には **Deploy** も、動作する **Edit** もありません。その後、ページに **Create a free account** が表示されます。
- **サインインすると UTC の毎日 1 回は無料で生成できます。** UTC の各日の最初の生成は、両ネットワークで無料です。それ以降は、テストネットでは「Generation Cost」を表示する「Confirm Contract Generation」ダイアログの後、テストウォレットのテスト QOR で 1 回ごとに支払います。メインネットではダッシュボードが鍵を保持しないため、次の UTC の日までそれ以上の生成は拒否されます。
- **すべてを入力するスターター。** **Token**、**NFT collection**、**Locked vault**、**2-of-3 multisig** のそれぞれが、完全なプロンプトを入力し、ターゲットを QoreChain に設定し、テンプレートを選択します。
- **17 のターゲットブロックチェーン。** それぞれに専用のテンプレートと「Custom (describe in prompt)」があります。QoreChain、Cosmos、Ethereum、Solana、Avalanche、NEAR、Polygon、BSC、TON、Cardano、Polkadot、Tezos、Arbitrum、Optimism、Sui、Aptos、Tron。
- **メインネット EVM でのノンカストディアルデプロイ。** ダッシュボードはコントラクトをコンパイルし、**未署名**のデプロイデータを返します。注入型の EVM ウォレット（MetaMask、Rabby、Coinbase Wallet）がチェーン 9801 を追加または切り替え、署名してブロードキャストします。その後、ダッシュボードがアドレスを記録します。
- **テストネットではガバナンスで承認された QoreChain Native のコード。** 生成されたコードはアップロードされません。テストネットのガバナンスがすでに承認し、チェーンからライブで読み取られるコードをインスタンス化します。CW20 token (cw20-base)、NFT collection (cw721-base)、Member group (cw4-group)、Multisig (cw3-fixed-multisig)、Counter example (qore-counter) です。インスタンス化メッセージはあらかじめ入力され、編集できます。
- **ダイアログ内でのコンパイルフィードバック。** エラーはその場に表示され、ダイアログは推測できないコンストラクタ引数を尋ね、トークンのフィールドはコードまたはプロンプトから事前に読み取られます。
- **デフォルトで非公開、公開するとフォーク可能。** 所有者は **Public** と **Private** を切り替えられ、公開コントラクトの所有者以外は **Fork** できます。

## 使い方 {#how-to-use}

### コントラクトを生成する

1. **SC Creator** を開きます。ページのタイトルは「What would you like to build?」です。
2. **例から始めるか、自分で記述します。** 「Or start from an example:」の下でスターターを選ぶか、**Contract Description** に自分で記述します。具体的に書くほど、結果は良くなります。
3. **Target Blockchain** を選択します。その下に言語とカテゴリーが表示されます（「Language: ... | Category: ...」）。チェーンを変更すると、そのチェーンの最初のテンプレートが自動的に選ばれます。説明だけに結果を任せたい場合は、**Contract Type** で自分で **Custom (describe in prompt)** を選んでください。
4. サインインしている場合のみ：**Generation Tier**（Standard または Premium）を選びます。Premium はメインネットでは利用できません。
5. **Generate Smart Contract** を選択します。サインインしている場合は、「Confirm Contract Generation」ダイアログが続きます（「Generation Cost」と、本日の無料枠の状況が表示されます）。結果には「Generated by QCAIA Standard」というラベルが付きます。

### 結果を確認する

コントラクトはシンタックスハイライト付きのビューで表示され、次の操作ができます。

- **Deploy**、
- **Edit Now**、
- **Download File**（選択したチェーンに適した形式）、
- **Copy Code**。

詳細と使用したプロンプトは、結果ではなくコントラクト自身のページ（下記）にあります。

### コントラクトページ

保存された各コントラクトには `/smart-contract-creator/<id>` にページがあり、Copy、**Public / Private**、Download、Edit または Fork、統計の行（Created、Lines、Size、Gen Time、Tokens、AI Model）、「Generation Prompt」、「Download from Cloud」（リンクは 24 時間で失効します）が表示されます。公開コントラクトであっても、コントラクトページを開くにはサインインが必要です。

**Edit** ページには、**Save Changes**（所有者）または **Save as New Contract**（フォーク時）と、**Deploy** があります。**Export PDF** は結果ではなく、プロフィールのコントラクト一覧にあります。

### コントラクトをデプロイする {#deploy}

Deploy は結果ページと編集ページにあります。ダイアログには「Target: TESTNET ... 9800」または「Target: MAINNET ... 9801」というバナーが表示されます。

#### メインネット（EVM）、ノンカストディアル {#deploy-mainnet}

ダッシュボードがあなたの鍵を保持することはなく、あなたに代わって署名することも決してありません。

1. ターゲットが QoreChain EVM で動作するコントラクトで、ヘッダーを **Mainnet** にして **Deploy** を選択します。このブラウザーでウォレット、トレード、またはエクスプローラー概要のメインネットを初めて表示する場合は、そこで[一度限りの確認](/dashboard/overview#risk-acknowledgement)に同意します。クリエーター自体に追加のリスク画面はありません。
2. **Deploy from your wallet** を選択します。注入型の EVM ウォレットであれば利用でき、ダイアログ自体がネットワーク（チェーン 9801）を追加または切り替えます。
3. チェーン v3.2.0 以降、EVM レーンでは、デプロイするアカウントが登録済みの ML-DSA-87 鍵と、QoreX から開く**開いている EVM 認可ウィンドウ**を持っている必要があります（[MetaMask での送金](/dashboard/wallet#send-metamask)を参照）。ない場合、チェーンはデプロイを拒否します。
4. ダッシュボードがコンパイルし、未署名のトランザクションをウォレットに渡します。「Confirm in your wallet...」と表示されるのを待ち、ネットワーク、ガス、データを確認します。
5. 確定すると、ダッシュボードはコントラクトアドレスを保存済みのコントラクトとともに記録します。

メインネットのその他のターゲットには「Direct deploy not available for this contract」と表示されます。メインネットでは QoreChain Native と SVM のデプロイは提供されておらず、ダッシュボードからの CosmWasm の公開もありません。

#### テストネット、ワンクリック {#deploy-testnet}

- **EVM：** **Deploy to Testnet** を選択します。ダッシュボードのテストウォレットがデプロイを署名して送信し、成功すると「Deployed on Testnet」と表示されます。メインネットに進む前に、[フォーセット](/dashboard/faucet)のトークンで繰り返し試してください。
- **QoreChain Native：** **Approved contract** を選び、**Label \*** を設定し、**Instantiate message (JSON)** を確認または編集して、**Instantiate on Testnet** を選択します。テストネットでのコントラクトのアップロードはガバナンスを通じて審査されるため、自分のコードをアップロードするのではなく、承認済みのコードをインスタンス化します。ダッシュボードが認識しない承認済みコードは、空のメッセージで表示されます。カスタムコントラクトは QoreChain EVM（Solidity）に送られます。
- ダッシュボードからデプロイできるのは、EVM コントラクトと承認済みの QoreChain Native コードのみです。別の EVM チェーン（Polygon、BSC、Arbitrum など）向けに書かれたコントラクトは、そのチェーン自身のネットワークではなく QoreChain EVM にデプロイされます。EVM 以外のチェーン向けのコントラクトは、ここからはデプロイできません。

**最小限の例（テストネット）：** **Token** を選択し、**Generate Smart Contract**、Confirm、**Deploy** の順に進み、「CW20 token (cw20-base)」を選び、Label を `my-token` にして、**Instantiate on Testnet** を選択します。

### 共有と再利用

コントラクトは**デフォルトで非公開**です。所有者として **Public** に設定すると、サインインしている他のユーザーがコントラクトを開いてフォークでき、**Private** に戻すと公開を取り下げられます。**Fork** は公開コントラクトを自分のアカウントにコピーし、そこから続けられるようにします。

## アクセス方法 {#how-to-access}

- **URL：** [dashboard.qorechain.io/smart-contract-creator](https://dashboard.qorechain.io/smart-contract-creator)（ホームページの **Create Smart Contract** からも開けます）。
- **アカウント：** ランディングページと 1 回の無料生成は、アカウントなしで利用できます。それ以外（追加の生成、保存済みコントラクト、コントラクトページと編集ページ、デプロイ）はサインインが必要です。[サインイン](/dashboard/overview#sign-in)をご覧ください。
- **ネットワーク：** 生成は両方で動作します。テストネットのデプロイはダッシュボードのテストウォレットを使い、メインネット EVM のデプロイはご自身のウォレットを使います。
- **費用：** UTC の各日の最初の生成は無料です。それ以降は、テストネットの生成はテスト QOR で支払い、メインネットの生成は次の UTC の日まで待ちます。デプロイにはネットワークのガスがかかります。

## 制限と既知の問題 {#limits}

- **提供されていないもの：** Solana のデプロイ（サーバーが拒否します）、メインネットでの Native または SVM のデプロイ、他のチェーンのパブリックネットワークへのデプロイ、メインネットでの Premium。
- **テストネットの Native デプロイ**は、ガバナンスで承認されたコードのみをインスタンス化します。生成されたソースはアップロードされません。
- **無料お試しの結果**には Deploy も Edit もありません。
- **デプロイの前にすべてを確認してください。** 生成されたコードに誤りが含まれている可能性があります。
