# トレード（DEX）

**トレード**ページ（タイトルは「QoreChain DEX」）は、**Swap**、**Pools**、**Add Liquidity**、**My Positions** の 4 つのタブを持つ、テストトークン用のスワップ画面です。実際のプールが存在する前に、テストトークンでスワップの流れを最初から最後まで試すためのものです。QoreChain のネイティブな自動マーケットメーカーの設計については、[AMM とオンチェーン流動性](/architecture/amm)を参照してください。

:::caution 現時点ではテストトークンのみ
このページのすべては、ヘッダーに表示されているネットワークにかかわらず**テストネット**で動作します。メインネットでは、ページはサインインと確認事項への同意によるゲートがかかったままですが、表示されるのは `qorechain-diana` とテストネットのトークンです。オンチェーンで決済される QoreSwap テストトークンは 5 つだけで、ここにあるそれ以外はすべて練習用のエリアです。QoreChain のネイティブ AMM モジュールは稼働していますが、どちらのネットワークでもまだプールは作成されていません（`GET /qorechain/amm/v1/pools` は両方で空のリストを返します。2026年10月27日確認）。
:::

## 革新的な仕組み {#innovations}

- **5 つのテストトークンのオンチェーンスワップ。** WQOR、QUSDC、QUSDT、QWETH、QWBTC の間のスワップは、テストネット EVM（チェーン ID 9800）上の QoreSwap AMM コントラクトに対して実行されます。見積もりはコントラクトの `getAmountOut` から取得されます。
- **トランザクション内で強制されるスリッページ。** 取引は approve の後に `swapExactTokensForTokens` を実行する形で行われ、スリッページ設定から導かれる最小出力額が指定され、テストウォレットの EVM 鍵で署名されます。価格が許容範囲を超えて動いた場合、スワップは不利な価格で約定せずにリバートします。
- **必要なときにテストトークンを入手。** **Get test tokens** は 5 つすべてのトークンを、トークンごとに 12 時間に 1 回請求します。
- **実際のものと練習用の誠実な区別。** その他のペア、Pools の一覧、Add Liquidity、My Positions は、テストネット上の練習用エリアであり、オンチェーンではありません。

## 使い方 {#how-to-use}

前提条件: サインイン済みで、テストウォレットがあること（[ウォレット](/dashboard/wallet#testnet)を参照）。ない場合、ページには「Wallet Required for Trading」と表示されます。

### Swap

1. バナーに **Get test tokens** が表示されます。最初にこれを使ってください。
2. 支払いに使うトークンを選び、金額を入力します。デフォルトのペアである QOR から USDC は、オンチェーンでは決済されない**練習用**のペアです。オンチェーンのスワップには、**WQOR** と **QUSDC**（または 5 つのうちの任意のペア）を選んでください。
3. 受け取るトークンを選びます。出力額は自動的に見積もられます。
4. 必要に応じて、**スリッページ許容度**（デフォルトは 0.5%）を調整します。
5. **Swap Now** を選択し、続けて **Confirm Swap** を選択します。結果には「Swap Confirmed」と **View Transaction** が表示されます。

**Recent Swaps** にはすべてのユーザーのスワップが一覧表示され、**Show My History** で自分のものだけに絞り込めます。

**最小限の例:** テストネットで **Get test tokens** を選択し、10 WQOR を QUSDC に売却して、**Swap Now**、**Confirm Swap** の順に選択します。

:::tip スリッページ
スリッページ許容度を高くすると、値動きの速い市場でもスワップが成立しやすくなりますが、受け取る価格は不利になる場合があります。デフォルトはほとんどのペアに適しています。
:::

### Pools

プールカードを閲覧します。取引ペア、流動性の合計、24 時間の出来高、プロバイダー数に加えて、APR、手数料、プール ID、価格、リザーブも表示されます。検索ボックスでトークンシンボルにより絞り込めます。これらは練習用の数値です。利回りとして読み取らないでください。

### Add Liquidity

1. ペアにする 2 つのトークンを選びます（一方はデフォルトで QOR）。新しいペアには **Create Pool** を使用します。
2. 最初のトークンの金額を入力します。2 つ目は、プールの比率に合わせて自動的に入力されます。ページには「Minimum 1000 QOR required」と記載されています。
3. 持分を確認して、確定します。

### My Positions

各エントリには、トークンペア、各トークンの金額、持分、獲得した手数料が表示されます。ポジションから抜けるには、**Withdraw** を選択し、続けて **Request Withdrawal (x%)** を選択します。クールダウン後に **Confirm Withdraw**（または **Cancel Withdrawal**）を選択します。単独の「Remove Liquidity」ボタンはありません。

## アクセス方法 {#how-to-access}

- **URL:** [dashboard.qorechain.io/trade](https://dashboard.qorechain.io/trade)。
- **アカウント:** サインインが必要です。スワップにはテストウォレットが必要です。メインネットでは、ページを開く前に 1 回限りの[確認事項への同意](/dashboard/overview#risk-acknowledgement)も必要です。
- **ネットワーク:** テストネットの内容のみ。ヘッダーの切り替えでは変わりません。
- **費用:** 無料です。テストトークンは **Get test tokens** から入手でき、テストウォレットは[ファウセット](/dashboard/faucet)から得たテスト QOR でガスを支払います。

## 公開場所 {#where-published}

| 画面 | アドレス | ネットワーク | オンチェーンで決済されるか |
| --- | --- | --- | --- |
| WQOR、QUSDC、QUSDT、QWETH、QWBTC のスワップ | `dashboard.qorechain.io/trade` | テストネット EVM、チェーン ID 9800 | はい |
| その他のペア、Pools、Add Liquidity、My Positions | `dashboard.qorechain.io/trade` | テストネット | いいえ、練習用の台帳 |

## 制限事項と既知の問題 {#limits}

- **メインネットでのトレードはありません。** このページはネットワークの切り替えを無視し、メインネットでもテストネットの内容を表示します。
- **オンチェーンで決済されるトークンは 5 つだけです。** [ファウセット](/dashboard/faucet#fest-tokens)のフェスト用トークンは、このページにはありません。
- **ネイティブ AMM にはどちらのネットワークにもプールがありません。** 実際のプールは、存在するようになった時点で説明します。
- **練習用の数値**（価格、APR、出来高）は市場データではありません。
- **テストネットのトークンに価値はなく**、何とも交換できません。
