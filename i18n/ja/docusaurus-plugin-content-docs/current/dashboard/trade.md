# トレード（DEX）

**トレード**ページは、ダッシュボードのトークンスワップ画面です。あるトークンを別のトークンに交換したり、プールに流動性を提供したりできます。オフチェーンのオーダーブックはありません。QoreChain のネイティブな自動マーケットメーカー（AMM）の設計については、[AMM とオンチェーン流動性](/architecture/amm)を参照してください。

:::caution 現時点ではテストトークンのみ
このページのプールとトークンはテストトークンです。スワップはテストネットの EVM にデプロイされたスワップコントラクト上で実行され、ページにはそれらを入手するための **Get test tokens** ボタンがあります。ここに表示されるものを、実際の価値を持つ流動性や市場価格とみなさないでください。QoreChain のネイティブ AMM モジュールは稼働していますが、どちらのネットワークでもまだプールは作成されていません。実際のプールが利用可能になった時点で、このページを更新します。
:::

トレードにはサインイン済みのアカウントとウォレットが必要です。[サインイン](/dashboard/overview#sign-in)と[ウォレットを接続する](/dashboard/overview#connect-your-wallet)をご覧ください。

このページには 4 つのタブがあります。**Swap**、**Pools**、**Add Liquidity**、**My Positions** です。

## Swap

あるトークンを別のトークンに交換します。

1. 支払いに使うトークンを選び、金額を入力します。
2. 受け取りたいトークンを選びます。出力額は自動的に見積もられます。
3. 必要に応じて、**スリッページ許容度**（許容する最大の価格変動。デフォルトは 0.5%）を調整します。
4. **Swap** を選択して確定します。

スワップ履歴パネルには、過去のスワップがトークン、金額、レート、時刻、ステータスとともに一覧表示されます。

:::tip スリッページ
スリッページ許容度を高くすると、値動きの速い市場でもスワップが成立しやすくなりますが、受け取る価格は不利になる場合があります。デフォルトはほとんどのペアに適しています。
:::

## Pools

利用可能な流動性プールを閲覧します。各プールカードには、取引ペア、流動性の合計、24 時間の出来高、プロバイダー数が表示されます。検索ボックスでトークンシンボルによりプールを絞り込めます。

## Add Liquidity

プールに流動性を提供して、そのスワップ手数料の分け前を受け取ります。

1. ペアにする 2 つのトークンを選びます（一方はデフォルトで QOR）。
2. 最初のトークンの金額を入力します。2 つ目の金額は、現在のプール比率に合わせて自動的に入力されます。
3. プールに占める見込みの持分を確認し、**Add Liquidity** を選択して確定します。

ポジションを表す流動性プロバイダー（LP）トークンを受け取ります。

## My Positions

保有している流動性ポジションを表示します。各エントリには、トークンペア、各トークンの金額、プールに占める持分、獲得した手数料が表示されます。ポジションの **Remove Liquidity** を選択すると、受け取れるトークンをプレビューし、自分の持分を引き出せます。
