# ウォレット

**ウォレット**ページでは、残高と取引履歴の確認、QORの受け取りと送金を行います。ページの動作はネットワークによって異なります。

- **メインネット — ノンカストディアル。** ダッシュボードはメインネットの秘密鍵を保持しません。ご自身のウォレット——**QoreX**(QoreChain公式ウォレット、拡張機能またはアプリ)、**Keplr**、または**MetaMask**——を接続すると、実際の残高と履歴がチェーンから直接読み込まれ、どのレールでも資金を受け取れます。**Nativeレール**での送金とステーキングには**QoreXが必須**です。QoreChainアカウントはポスト量子ハイブリッド署名で署名し、QoreXがその署名を生成するウォレットであるため、他にどのウォレットを接続していても、ダッシュボードのSendタブとStakeタブはQoreXを通じて動作します。KeplrはNativeレール(`qor1...`)の残高を表示したり、そこで資金を受け取ったりするために引き続き接続できます。**MetaMask**は**EVMレール**(`0x...`)に接続し、EVMトランザクションに自分で署名しますが、チェーンv3.2.0以降、EVMレーンは、登録済みのポスト量子鍵を持ち、**かつ**EVM認可ウィンドウが開いているアカウントからのトランザクションのみを受け付けます。MetaMaskはその鍵を登録することも、ウィンドウを開くこともできませんが、QoreXにはできます。[MetaMaskで送金](#send-metamask)を参照してください。
- **テストネット — カストディアル。** ダッシュボードがテスト用ウォレットを管理するため、セットアップ不要で送金・スワップ・ステーキングを試せます。[フォーセット](/dashboard/faucet)から資金を入手してください。

アカウントは量子耐性暗号で保護されており、すべてのアドレスのNativeエンコーディングは`qor` bech32プレフィックス(`qor1...`)を使用します。

## 1つのアカウント、3つのエンコーディング {#one-account-three-encodings}

QoreChainアカウントは単一のIDであり、実行レールごとに3通りの表記が可能です。

| レール | エンコーディング | 表示例 |
| --- | --- | --- |
| **Native QOR** | bech32 | `qor1...` |
| **EVM** | hex | `0x...` |
| **SVM** | base58 | 例: `5Gv7...` |

3つのエンコーディングはすべて**同じアカウントの同じ残高**を指します。どのレールで受け取った資金も1つの残高にまとまり、ダッシュボードは`qor1`(Native)エンコーディングを通じて残高と履歴をインデックスするため、すべてのレールのアクティビティがまとめて表示されます。

## メインネットでウォレットを使う {#mainnet}

1. ダッシュボードのヘッダーを**メインネット**に切り替えます。
2. 求められた場合は[一度限りのリスク確認](/dashboard/overview#risk-acknowledgement)に同意します——メインネットは実際の資金を動かし、ダッシュボードはノンカストディアルであり、取引は取り消せません。
3. 接続画面でウォレットを選択します——**Connect with QoreX**(推奨、QoreChain公式ウォレット——Nativeレールでの送金・ステーキングに必須)、**Connect Keplr**(Nativeレールでの表示/受け取り用)、または**Connect MetaMask**(EVMレールでの接続・受け取り用。送金にはEVMウィンドウを開く必要があります。[MetaMaskで送金](#send-metamask)を参照)。それぞれの詳しい手順は以下を参照してください。Phantomはここではウォレットとして接続できません。[Keplrで接続](#connect-keplr)の下の注記を参照してください。
4. ページはチェーンから実際の残高と取引履歴を読み込みます。

接続後、Walletページはすべてを6つのタブに整理します——**Wallet**(残高とアカウント概要)、**Send from QoreX**、**Stake / Delegate**、**Rewards**、**Details**(あなたの`qor1...` / `0x...` / SVMアドレス)、そして**Connect Wallets**(接続済みのすべてのウォレットと、追加接続の場所)。Send、Stake、Rewardsの各タブは、KeplrやMetaMaskを接続していてもQoreXを通じて動作します。これはNativeレールの取引にQoreXが生成するポスト量子ハイブリッド署名が必要なためです。

ウォレットにまだQoreChainが設定されていない場合は、先に追加してください——[ウォレットにQoreChainを追加する](#add-network)を参照。

### QoreXで接続 — ブラウザ拡張機能 {#connect-qorex-extension}

1. Walletページで**QoreX wallet**カードを見つけ、**Connect with QoreX**を選択します。
2. このブラウザでQoreX拡張機能が検出されているため、ダッシュボードは接続方法を尋ねます。**Browser extension**を選択します。
3. QoreX拡張機能が独自の承認ポップアップを開き、接続を要求しているサイトとして`dashboard.qorechain.io`を表示します。
4. ポップアップでリクエストを確認し、承認します——これはあなたが`qor1...`アドレスを所有していることのワンタイム証明に署名するものです。資金は移動せず、他の権限も付与されません。
5. ポップアップが閉じ、ダッシュボードはQoreXカードに**Connected: qor1...**を表示し、あなたのアドレスによってWalletページの残りの機能がアンロックされます。拡張機能/アプリの選択は記憶されるため、次回このブラウザで**Connect with QoreX**を選択すると、確認なしで同じ方法で再接続されます——別の方法に切り替えたい場合は、接続カードの**Use a different method**を使ってください。

同じダッシュボードアカウントに複数のQoreXアドレスをリンクできます——例えば、Firefox拡張機能用とChrome用、あるいはスマートフォン用とノートパソコン用に1つずつなど。**Add another wallet**を選択して、2つ目のアドレスでフローを繰り返します。リンクした各アドレスには個別のラベルを付けられ、そのうち1つを送金用のデフォルトとして設定できます。いずれも**Connect Wallets**タブから行います。

**Walletタブでのウォレット切り替え。** 複数のウォレット——QoreXとMetaMask、あるいは2つのQoreXアドレス——が接続されると、**Wallet**タブの上部に**Viewing**で始まるウォレットチップの行が表示され、接続済みのウォレットごとに1つずつ、現在アクティブなものが示されます。チップをクリックすると、タブを離れたり**Connect Wallets**に移動したりすることなく、表示する残高と履歴の対象ウォレットを切り替えられます。接続されているウォレットが1つだけの場合、切り替えの必要がないためこの行は表示されません。

**QoreX拡張機能内でまだリンクされていないアカウント。** 1つのリカバリーフレーズから複数のアカウントを導出でき、QoreXでアカウントを作成してもダッシュボードには通知されません——リンクは別の署名付きステップです。QoreX拡張機能がアカウントを一覧表示できる場合、**Wallet**、**Details**、**Connect Wallets**の各タブに「2 accounts in your QoreX extension are not linked here」のようなカードが表示され、各アカウントの残高(およびそのうちステーキング中で送金できない額)も示されます。**Link this account**を選択するとペアリングされます。リンクすることでダッシュボードがその残高と履歴を表示できるようになりますが、あなたの鍵に対する制御権は一切付与されません。お使いのQoreXのビルドで証明するアカウントを選択できない場合は、ここからはアクティブなアカウントのみリンクできます——カードは、先にQoreXでそのアカウントに切り替えるよう案内します。

**Details**タブの**Linked addresses**には、アカウントに紐づくすべてのアドレスが由来元のウォレットとともに一覧表示されます。アドレスの名前変更、送金用デフォルトの設定ができ、QoreXで操作可能か閲覧専用か(南京錠アイコン)も確認できます。

### QoreXで接続 — モバイルアプリ {#connect-qorex-app}

1. Walletページで**QoreX wallet**カードを見つけ、**Connect with QoreX**を選択します。
2. 拡張機能の選択画面が表示された場合は、**QoreX app**を選択します(このブラウザで拡張機能が検出されない場合、ダッシュボードは直接このフローに進みます)。
3. ダッシュボードはQRコードと**Open QoreX**リンクを表示します。
4. スマートフォンでQoreXアプリを開き、QRコードをスキャンしてください——あるいは、同じスマートフォンで閲覧している場合は、**Open QoreX**をタップして`qorex://connect`リンク経由で直接アプリを起動します。
5. QoreXがダッシュボードのオリジンとともにペアリングリクエストを表示します。内容を確認し、生体認証(Face ID / Touch ID / PIN)で承認します。
6. ダッシュボードはバックグラウンドで承認を待機しており、数秒以内にQoreXカードに**Connected: qor1...**が表示され、あなたのアドレスによってWalletページの残りの機能がアンロックされます。

### Keplrで接続 {#connect-keplr}

KeplrはNativeレールの残高、履歴、受け取りアドレスを表示するために接続します。Nativeレールでの送金とステーキングはQoreXを使用します(下記参照)——QoreChainアカウントはポスト量子ハイブリッド署名で署名するため、ダッシュボードのSendタブとStakeタブは、ここで接続したウォレットではなくQoreXを通じて動作します。

1. Walletページで**Connect Keplr**を選択します。
2. QoreChainがKeplrにまだ設定されていない場合、ダッシュボードはKeplrの`suggestChain`プロンプトをトリガーします——Keplrのポップアップでネットワークの詳細(チェーンID、RPC/RESTエンドポイント)を確認し、**Approve**を選択して追加します。
3. Keplrは接続するアカウントの選択と接続の承認を求めます——**Approve**を選択します。
4. ダッシュボードはあなたの`qor1...`アドレスを読み込み、残高と履歴をロードします。

Phantomはメインネットのウォレットページではウォレットとして接続できません。以前にリンクしたPhantomアドレスは引き続き**Connected wallets**に表示されます。Phantomの鍵をサイナーとしてリンクする方法については、[リンク済みサイナー(Phantom)](#linked-signers)を参照してください。

### MetaMaskで接続 {#connect-metamask}

1. Walletページで**Connect MetaMask**を選択します。
2. QoreChain EVMネットワークがまだ追加されていない場合、MetaMaskはチェーンID、RPC URL、通貨シンボルがあらかじめ入力された**Add network**プロンプト(EIP-3085)を表示します——内容を確認して**Approve**を選択し、続けて**Switch network**を選択します。
3. MetaMaskは接続するアカウントを尋ねます——アカウントを選択し、**Connect**で確認します。
4. ダッシュボードはあなたの`0x...`アドレスを読み込み、残高と履歴をロードします。

### メインネットで送金する {#send-mainnet}

ダッシュボードはメインネットの秘密鍵を一切保持しないため、すべての送金はダッシュボード上で作成されますが、最終的な確定はご自身のウォレットで行われます。**Nativeレール**では、そのウォレットは常に**QoreX**です——Send・Stakeタブは、他にどのウォレットを接続していても、QoreChainアカウントがポスト量子ハイブリッド署名で署名するため、QoreXを通じて動作します。**EVMレール**では、アカウントがすでにポスト量子鍵を持ち、EVMウィンドウが開いている場合に限り、MetaMaskがトランザクションに署名します([MetaMaskで送金](#send-metamask)を参照)。

:::caution 実際の資金、取り消し不能な送金
メインネットの取引は取り消せません。承認する前に必ず受取先アドレスをよく確認してください。
:::

:::note ベスティング残高について
残高の一部がまだベスティング中の場合、それはステーキングで委任できる額には含まれますが、取引手数料の支払いには使えません——手数料には別途、自由に使えるQORが必要です(PQCキーの登録も同様です)。ベスティング分しか持たないウォレットは委任はできても送金はできません。
:::

#### QoreXで送金 — ブラウザ拡張機能

1. Walletページの**Send from QoreX**カードで、受取先(`qor1...`アドレスまたは`@handle`)、QOR建ての金額、任意のメモを入力します。複数のQoreXウォレットをリンクしている場合は、**Send from**で支払い元を選びます。
2. **Continue in QoreX**を選択します。
3. ダッシュボードに**Approve in browser extension**ボタンが表示されるので、これを選択します。
4. QoreX拡張機能が承認ポップアップを開き、受取先と金額を含む送金内容を完全にデコードして表示します。内容を確認し、拡張機能自体のセキュリティ(生体認証またはパスワードのロック解除)で承認します。
5. 拡張機能がハイブリッドPQC署名で送金に署名し、直接チェーンにブロードキャストします——ダッシュボードは結果のトランザクションハッシュのみを知ります。
6. Walletページに**Transfer confirmed**とトランザクションハッシュが表示され、[Explorer](/dashboard/explorer)で開くことができます。

#### QoreXで送金 — モバイルアプリ

1. Walletページの**Send from QoreX**カードで、受取先(`qor1...`アドレスまたは`@handle`)、QOR建ての金額、任意のメモを入力します。複数のQoreXウォレットをリンクしている場合は、**Send from**で支払い元を選びます。
2. **Continue in QoreX**を選択します。
3. ダッシュボードは`qorex://tx`リクエストを含むQRコードと**Open in QoreX**リンクを表示します。
4. QoreXアプリでQRコードをスキャンするか、同じスマートフォンを使用している場合は**Open in QoreX**をタップします。
5. QoreXがリクエストをデコードし、受取先と金額を完全な形で表示します。内容を確認し、生体認証で承認します。
6. QoreXがハイブリッドPQC署名で送金に署名し、ブロードキャストします。
7. ダッシュボードは結果をポーリングし、チェーン上に反映され次第、**Transfer confirmed**とトランザクションハッシュを表示します。これは[Explorer](/dashboard/explorer)で開くことができます。

#### @handleへの送金

**Send from QoreX**カードの受取先フィールドは、`qor1...`アドレスの代わりに`@handle`も受け付けます。この後の動作は、このブラウザからそのハンドルに以前送金したことがあるかどうかによって異なります。

- **初回**: 解決されたアドレスが「First time sending to @handle from this browser. Check the address before you continue:」とともに全文表示され、**This address is right — continue**を選択しない限り使用できません——アドレスは解決された瞬間ではなく、確認を済ませた後に初めて記憶(ピン留め)されます。
- **以前と同じアドレス**: 軽い確認だけで通過します——再入力は不要です。
- **以前と異なるアドレス**: フローは強制的に停止します。以前のアドレスと新しいアドレスの両方が全文表示され——攻撃者が似せようとする箇所はまさに中間の文字なので、省略表示は絶対に行いません——アドレスが変わったという明示的な警告とともに、そのまま続行するための**I trust this change — continue**ボタンが、意図的に目立たないスタイルで表示されます。

このピン留めはあなた自身のブラウザにのみ保存され、サーバーには保存されません。そのため、別のコンピューターや、ブラウザデータを消去した場合は再び「初回」として扱われます——これは意図的な仕様です。ハンドルは3〜20文字(`a-z`、`0-9`、`_`)で、特定のアドレスに紐づいているため、複数のアドレスを持つユーザーはアドレスごとに異なるハンドルを使えます。ハンドルの検索が一時的に利用できない場合は、フィールドにその旨が表示され、引き続き`qor1...`アドレスへ送金できます。

#### MetaMaskで送金 {#send-metamask}

:::caution チェーンv3.2.0以降、MetaMaskだけではメインネットで送金できません
EVMレーンは、登録済みのポスト量子鍵を持ち、**EVM認可ウィンドウが開いている**アカウントからのトランザクションのみを受け付けます。これは、アカウントがポスト量子署名付きメッセージで開く、時間・回数・金額に上限のある許可です。MetaMaskはそのメッセージを生成できません。ウィンドウなしで送金すると、チェーンはトランザクションを拒否します(典型的なエラー: ウィンドウなし、ウィンドウ使い切り、ポスト量子鍵なし)。
:::

1. **QoreX**(アカウント自身のウォレット)で、アカウントにポスト量子鍵がなければ登録し、その後EVM認可ウィンドウを開きます——[EVMアクセスウィンドウ](/qorex/security-and-recovery#evm-window)を参照してください。納得できる上限を選んでください。新しいウィンドウを開くと前のウィンドウは置き換えられます。
2. MetaMaskを開き、QoreChain EVMネットワークに設定されていることを確認します。
3. MetaMask内で**Send**を選択し、受取先の`0x...`アドレスと金額を入力し、ガス代を確認して確定します。
4. ダッシュボードのWalletページに戻ると、チェーン上に反映され次第、取引が履歴に表示されます(表示されない場合は更新してください)。

各トランザクションはウィンドウの一部を消費します。時間、トランザクション数、または金額の上限に達したら、QoreXで新しいウィンドウを開いてください。

### 特定のレールで受け取る {#receive-mainnet}

1. **Receive**を選択します。
2. 受け取りモーダルで、セレクターからレールを選びます——**Native QOR**、**EVM**、または**SVM**。
3. モーダルには、そのレールのエンコーディング(`qor1...`、`0x...`、またはbase58)によるあなたのアドレスがQRコードとコピーボタンとともに表示されます。
4. アドレスをコピーするか、送金者にQRコードをスキャンしてもらいます。

送金者がどのレールを使っても、資金は同じアカウントに届きます——1つのアカウント、3つのエンコーディング、1つの残高です。

### 取引履歴を確認する {#history}

メインネットでは、履歴の各行に次が表示されます。

- **レールバッジ** — Native、EVM、SVMのいずれか——どのレールで取引されたかを示します。
- 通常の送金には**Sent**または**Received**、その他のアクティビティ(例: *PQC key registration*やコントラクトアクション)には内容を示す種別ラベル。
- 金額、時刻、**Confirmed** / **Failed**のステータス、そして[Explorer](/dashboard/explorer)で開けるトランザクションハッシュ。

## テストネットでウォレットを使う {#testnet}

テストネット(`qorechain-diana`)では、ダッシュボードがテスト用ウォレットを管理するため、何も接続せずにエンドツーエンドでフローをテストできます。

### ページに表示される内容

- ウォレットのラベルとアクティブなアドレス(省略形)、ワンクリックのコピーボタン付き。
- QOR建ての**合計残高**。
- 量子耐性暗号化と接続中のネットワークを示すセキュリティパネル。
- 更新コントロール付きの最終更新インジケーター。
- **Transaction history**タブと**Tokens**タブを持つ**Assets & Activity**セクション。

いつでも更新コントロールを使って、チェーンから現在の残高と最新のアクティビティを取得できます。

:::caution テストネットのアドレスはメインネットのアドレスとまったく同じ見た目です
テストネットとメインネットは同じ`qor1...`形式を使うため、テストネットのアドレスを取引所の出金先や別のウォレットに貼り付けても何の警告も出ません——そこに送られた実際のQORは、そのアドレスの**メインネット**に着金し、このテストネットのページでは確認できません。実際のQORをテストネットのアドレスに送らないでください。ダッシュボードは、Walletページのアドレスの横、**My Wallets**リスト、**Receive**画面でこの警告を繰り返し表示します。実際のQORにはメインネットに切り替えて、そこに表示されるアドレスを使ってください。すでに実際のQORをテストネットのアドレスに送ってしまった場合は、サポートに連絡してください——自分で移動しようとしないでください。
:::

### QORを送金する(テストネット)

1. **Send**を選択します。
2. **Recipient Address**(`qor1...`)を入力します。
3. **Amount**(または**MAX**)と、任意の**Memo**を入力します。
4. **Review Transaction**を選択し、内容と見積もりのネットワーク手数料を確認してから、**Confirm & Send**を選択します。

受取先を入力すると、保存済みの連絡先や最近使用したアドレスが候補として表示され、入力ミスを防げます。送金が送信された後、トランザクションハッシュを含む確認が表示され、[Explorer](/dashboard/explorer)で開くことができます。

### QORを受け取る(テストネット)

1. **Receive**を選択します。
2. アドレスまたはそのQRコードを送金者と共有するか、ワンクリックでアドレスをコピーします。
3. 任意で希望金額とメモを入力すると、支払いリンクとダウンロード可能なQRコードが生成されます。

### テストウォレットを管理する

**My Wallets**を選択してアドレス一覧を開きます。ここから、ウォレットの切り替え、新しいウォレットの作成、既存ウォレットのインポート、不要になったウォレットの削除ができます。アクティブなウォレットは、テストネット上のダッシュボード全体で送金、スワップ、ステーキング、その他の署名アクションに使用されるウォレットです。

### テストウォレットのリカバリーフレーズをバックアップ/エクスポートする {#reveal-recovery-phrase}

テストネットではダッシュボードがウォレットを管理しますが、ウォレットの24語のリカバリーフレーズをエクスポートして、QoreXなどのセルフカストディウォレットにインポートできます。

1. テストネットの**Wallet**ページで、**Recovery phrase**カードを見つけます。ダッシュボードが管理する各ウォレットが**メインネット**残高とともに一覧表示され(残高のあるウォレットが先頭)、実際にトークンを保有しているウォレットを選べます。
2. ウォレットの横の**Reveal**を選択し、警告(「Reveal the phrase for …?」)を読んで、**Continue**を選択します。
3. アカウントのサインインページで再度サインインするよう案内されます(新たなパスワード確認が必要です。ダッシュボードがパスワードを見ることはありません)。サインイン後は自動的にウォレットに戻ります。
4. 24語が60秒間表示されます。書き留めてオフラインで保管してください。確認ボックスにチェックを入れたり、確認用フィールドに入力したりしている間は、カウントダウンが一時停止します。
5. **I have written down my recovery phrase and stored it somewhere safe**にチェックを入れ、書き留めたコピーから**3**、**5**、**9**番目の語(*Required*と表示)を入力して、**Confirm backup**を選択します。「Recovery phrase saved」と表示されます。
6. **Hide without confirming**で離れた場合(またはタイマーが切れた場合)、カードには「Backup not confirmed」と表示されます——フレーズを書き留めたという記録は残りません——そして**Reveal again and confirm**が表示されます。

この24語を持つ人は誰でもウォレットを制御できます。QoreChainがこれらを復元またはリセットすることは決してできず、サポートがこれらを尋ねることもありません。

## ウォレットにQoreChainを追加する {#add-network}

Walletページの**Add QoreChain to your wallet**パネル(メインネットでは**Connect Wallets**タブ内、およびウォレットが接続されるまでは接続ボタンの下にあります。テストネットではページの下部にあります)には、接続方法ごとに4つのカードが並んでおり、ワンクリックでご自身のウォレットにQoreChainを追加できます。

| カード | 得られるもの |
| --- | --- |
| **Native (Cosmos) wallets** | RPCおよびRESTエンドポイントとチェーンID(それぞれコピーボタン付き)——KeplrなどNativeレールのウォレット向け。 |
| **EVM wallets** | すぐに使えるEIP-3085ネットワークパラメーター——ワンクリックでMetaMaskなどのEVMウォレットにQoreChainを追加。 |
| **SVM wallets** | SVM互換のウォレットやツール向けのSVM RPC URL。 |
| **Mobile wallets (WalletConnect)** | 対応ウォレットのモバイル版向けのWalletConnect v2ペアリングQRコード。 |

QoreChainを追加するには:

1. **Wallet**ページを開き、**Add QoreChain to your wallet**を見つけます。
2. お使いのウォレットのレールに合ったカードを選びます。
3. 追加ボタン(**Add to Keplr** / **Add to Cosmostation**、**Add to MetaMask**またはその他のEVMウォレット、あるいはWalletConnectペアリング)を選択するか、エンドポイントとチェーンIDをウォレットのネットワーク追加フォームにコピーします(SVMカードは、カスタムRPC設定に貼り付けるSVM RPC URLを提供します)。
4. ウォレットで新しいネットワークを承認します。

パブリックエンドポイントは`rpc.qore.host`(Native RPC)、`api.qore.host`(REST)、`evm.qore.host`(EVM JSON-RPC)、`svm.qore.host`(SVM RPC)で、テストネット用に`*-testnet`のバリアント(例: `rpc-testnet.qore.host`)があります。チェーンID: メインネット`qorechain-vladi`(EVMチェーンID`9801`)、テストネット`qorechain-diana`(EVMチェーンID`9800`)。

### リンク済みサイナー(Phantom) {#linked-signers}

**SVM wallets**カードでは、Phantomの鍵を**リンク済みサイナー**としてアカウントにリンクすることもできます——これは期間限定(30日)で取り消し可能なオーソライザーであり、QoreX、Keplr、MetaMaskのような独立したプライマリウォレット接続ではありません。**Connect Phantom**を選択し、次に**Register authenticator**を選択します。登録には既存のウォレットが署名し、Phantomがそれ自体の独立したIDになることはありません。

:::caution リンク済みサイナーの登録は現在チェーン上で無効化されています
チェーンのスマートアカウントおよびリンク済みウォレット機能は実装されていますが、両ネットワークで無効化されており(`abstractaccount.enabled = false`。`GET /qorechain/abstractaccount/v1/config`で確認できます)、その間チェーンは新しいリンク済みサイナーの登録を拒否します。現時点ではこのカードをプレビューとして扱い、登録が成功することを期待しないでください。
:::

:::caution リンク済みサイナーはアカウントに対する実際の権限です
この機能が有効になった場合、付与する権限は、鍵がどのレーンで動作できるかを決めるものであり、どれだけの額を動かせるかを決めるものではなく、登録は30日間有効です。アカウント自体と同じくらい信頼できるPhantomの鍵だけをリンクし、不要になったら取り消してください。
:::

オンチェーンの権限・支払い上限モデルについては、QoreXドキュメントの[リンク済みサイナーと支払い上限](/qorex/security-and-recovery#linked-signers)を参照してください。
