# ウォレット

**ウォレット**ページでは、残高と取引履歴の確認、QORの受け取りと送金を行います。ページの動作はネットワークによって異なります。

- **メインネット — ノンカストディアル。** ダッシュボードはメインネットの秘密鍵を保持しません。ご自身のウォレット——**QoreX**(QoreChain公式ウォレット、拡張機能またはアプリ)、**Keplr**、または**MetaMask**——を接続すると、実際の残高と履歴がチェーンから直接読み込まれ、どのレールでも資金を受け取れます。**Nativeレール**での送金とステーキングには**QoreXが必須**です。QoreChainアカウントはポスト量子ハイブリッド署名で署名し、QoreXがその署名を生成するウォレットであるため、他にどのウォレットを接続していても、ダッシュボードのSendタブとStakeタブはQoreXを通じて動作します。KeplrはNativeレール(`qor1...`)の残高を表示したり、そこで資金を受け取ったりするために引き続き接続できます。**MetaMask**は**EVMレール**(`0x...`)で独立して署名・送信を行い、これは従来型の署名を使うため今回の変更の影響を受けません。
- **テストネット — カストディアル。** ダッシュボードがテスト用ウォレットを管理するため、セットアップ不要で送金・スワップ・ステーキングを試せます。[フォーセット](/dashboard/faucet)から資金を入手してください。

アカウントは量子耐性暗号で保護されており、すべてのアドレスのNativeエンコーディングは`qor` bech32プレフィックス(`qor1...`)を使用します。

## 1つのアカウント、3つのエンコーディング {#one-account-three-encodings}

QoreChainアカウントは単一のIDであり、実行レールごとに3通りの表記が可能です。

| レール | エンコーディング | 表示例 |
| --- | --- | --- |
| **Native QOR** | bech32 | `qor1...` |
| **EVM** | hex | `0x...` |
| **SVM** | base58 | 例: `5Gv7...` |

3つのエンコーディングはすべて**同じアカウントの同じ残高**を指します。どのレールで受け取った資金も1つの残高にまとまり、ダッシュボードは`qor1`(Native)エンコーディングを通じて残高と履歴をインデックスするため、すべてのレールのアクティビティがまとめて表示されます。

## メインネットでウォレットを使う {#mainnet}

1. ダッシュボードのヘッダーを**メインネット**に切り替えます。
2. 求められた場合は[一度限りのリスク確認](/dashboard/overview#risk-acknowledgement)に同意します——メインネットは実際の資金を動かし、ダッシュボードはノンカストディアルであり、取引は取り消せません。
3. **Connect Wallet**を選び、ウォレットを選択します——**QoreX**(推奨、QoreChain公式ウォレット——Nativeレールでの送金・ステーキングに必須)、**Keplr**(Nativeレールでの表示/受け取り用)、または**MetaMask**(EVMレールでの接続・送金・受け取り用)。それぞれの詳しい手順は以下を参照してください。
4. ページはチェーンから実際の残高と取引履歴を読み込みます。

接続後、Walletページはすべてを6つのタブに整理します——**Wallet**(残高とアカウント概要)、**Send from QoreX**、**Stake / Delegate**、**Rewards**、**Details**(あなたの`qor1...` / `0x...` / SVMアドレス)、そして**Connect Wallets**(接続済みのすべてのウォレットと、追加接続の場所)。Send、Stake、Rewardsの各タブは、KeplrやMetaMaskを接続していてもQoreXを通じて動作します。これはNativeレールの取引にQoreXが生成するポスト量子ハイブリッド署名が必要なためです。

ウォレットにまだQoreChainが設定されていない場合は、先に追加してください——[ウォレットにQoreChainを追加する](#add-network)を参照。

### QoreXで接続 — ブラウザ拡張機能 {#connect-qorex-extension}

1. Walletページで**QoreX wallet**カードを見つけ、**Connect with QoreX**を選択します。
2. このブラウザでQoreX拡張機能(0.1.4以降)が検出されているため、ダッシュボードは接続方法を尋ねます。**Browser extension**を選択します。
3. QoreX拡張機能が独自の承認ポップアップを開き、接続を要求しているサイトとして`dashboard.qorechain.io`を表示します。
4. ポップアップでリクエストを確認し、承認します——これはあなたが`qor1...`アドレスを所有していることのワンタイム証明に署名するものです。資金は移動せず、他の権限も付与されません。
5. ポップアップが閉じ、ダッシュボードはQoreXカードに**Connected: qor1...**を表示し、あなたのアドレスによってWalletページの残りの機能がアンロックされます。拡張機能/アプリの選択は記憶されるため、次回このブラウザで**Connect with QoreX**を選択すると、確認なしで同じ方法で再接続されます——別の方法に切り替えたい場合は、接続カードの**Use a different method**を使ってください。

同じダッシュボードアカウントに複数のQoreXアドレスをリンクできます——例えば、Firefox拡張機能用とChrome用、あるいはスマートフォン用とノートパソコン用に1つずつなど。**Add another wallet**を選択して、2つ目のアドレスでフローを繰り返します。リンクした各アドレスには個別のラベルを付けられ、そのうち1つを送金用のデフォルトとして設定できます。いずれも**Connect Wallets**タブから行います。

**Walletタブでのウォレット切り替え。** 複数のウォレット——QoreXとMetaMask、あるいは2つのQoreXアドレス——が接続されると、**Wallet**タブの上部にウォレットごとのチップが並んで表示され、現在アクティブなものが示されます。チップをクリックすると、タブを離れたり**Connect Wallets**に移動したりすることなく、表示する残高と履歴の対象ウォレットを切り替えられます。接続されているウォレットが1つだけの場合、切り替えの必要がないためこの行は表示されません。

### QoreXで接続 — モバイルアプリ {#connect-qorex-app}

1. Walletページで**QoreX wallet**カードを見つけ、**Connect with QoreX**を選択します。
2. 拡張機能の選択画面が表示された場合は、**QoreX app**を選択します(このブラウザで拡張機能が検出されない場合、ダッシュボードは直接このフローに進みます)。
3. ダッシュボードはQRコードと**Open QoreX**リンクを表示します。
4. スマートフォンでQoreXアプリを開き、QRコードをスキャンしてください——あるいは、同じスマートフォンで閲覧している場合は、**Open QoreX**をタップして`qorex://connect`リンク経由で直接アプリを起動します。
5. QoreXがダッシュボードのオリジンとともにペアリングリクエストを表示します。内容を確認し、生体認証(Face ID / Touch ID / PIN)で承認します。
6. ダッシュボードはバックグラウンドで承認を待機しており、数秒以内にQoreXカードに**Connected: qor1...**が表示され、あなたのアドレスによってWalletページの残りの機能がアンロックされます。

### Keplrで接続 {#connect-keplr}

KeplrはNativeレールの残高、履歴、受け取りアドレスを表示するために接続します。Nativeレールでの送金とステーキングはQoreXを使用します(下記参照)——QoreChainアカウントはポスト量子ハイブリッド署名で署名するため、ダッシュボードのSendタブとStakeタブは、ここで接続したウォレットではなくQoreXを通じて動作します。

1. Walletページで**Connect Wallet**を選択し、**Keplr**を選びます。
2. QoreChainがKeplrにまだ設定されていない場合、ダッシュボードはKeplrの`suggestChain`プロンプトをトリガーします——Keplrのポップアップでネットワークの詳細(チェーンID、RPC/RESTエンドポイント)を確認し、**Approve**を選択して追加します。
3. Keplrは接続するアカウントの選択と接続の承認を求めます——**Approve**を選択します。
4. ダッシュボードはあなたの`qor1...`アドレスを読み込み、残高と履歴をロードします。

### MetaMaskで接続 {#connect-metamask}

1. Walletページで**Connect Wallet**を選択し、**MetaMask**を選びます。
2. QoreChain EVMネットワークがまだ追加されていない場合、MetaMaskはチェーンID、RPC URL、通貨シンボルがあらかじめ入力された**Add network**プロンプト(EIP-3085)を表示します——内容を確認して**Approve**を選択し、続けて**Switch network**を選択します。
3. MetaMaskは接続するアカウントを尋ねます——アカウントを選択し、**Connect**で確認します。
4. ダッシュボードはあなたの`0x...`アドレスを読み込み、残高と履歴をロードします。

### メインネットで送金する {#send-mainnet}

ダッシュボードはメインネットの秘密鍵を一切保持しないため、すべての送金はダッシュボード上で作成されますが、最終的な確定はご自身のウォレットで行われます。**Nativeレール**では、そのウォレットは常に**QoreX**です——Send・Stakeタブは、他にどのウォレットを接続していても、QoreChainアカウントがポスト量子ハイブリッド署名で署名するため、QoreXを通じて動作します。**EVMレール**では、MetaMaskが独立して署名・送信します。

:::caution 実際の資金、取り消し不能な送金
メインネットの取引は取り消せません。承認する前に必ず受取先アドレスをよく確認してください。
:::

:::note ベスティング残高について
残高の一部がまだベスティング中の場合、それはステーキングで委任できる額には含まれますが、取引手数料の支払いには使えません——手数料には別途、自由に使えるQORが必要です(PQCキーの登録も同様です)。ベスティング分しか持たないウォレットは委任はできても送金はできません。
:::

#### QoreXで送金 — ブラウザ拡張機能

1. Walletページの**Send from QoreX**カードで、受取先(`qor1...`アドレスまたは`@handle`)、QOR建ての金額、任意のメモを入力します。
2. **Continue in QoreX**を選択します。
3. ダッシュボードに**Approve in browser extension**ボタンが表示されるので、これを選択します。
4. QoreX拡張機能が承認ポップアップを開き、受取先と金額を含む送金内容を完全にデコードして表示します。内容を確認し、拡張機能自体のセキュリティ(生体認証またはパスワードのロック解除)で承認します。
5. 拡張機能がハイブリッドPQC署名で送金に署名し、直接チェーンにブロードキャストします——ダッシュボードは結果のトランザクションハッシュのみを知ります。
6. Walletページに**Transfer confirmed**とトランザクションハッシュが表示され、[Explorer](/dashboard/explorer)で開くことができます。

#### QoreXで送金 — モバイルアプリ

1. Walletページの**Send from QoreX**カードで、受取先(`qor1...`アドレスまたは`@handle`)、QOR建ての金額、任意のメモを入力します。
2. **Continue in QoreX**を選択します。
3. ダッシュボードは`qorex://tx`リクエストを含むQRコードと**Open QoreX**リンクを表示します。
4. QoreXアプリでQRコードをスキャンするか、同じスマートフォンを使用している場合は**Open QoreX**をタップします。
5. QoreXがリクエストをデコードし、受取先と金額を完全な形で表示します。内容を確認し、生体認証で承認します。
6. QoreXがハイブリッドPQC署名で送金に署名し、ブロードキャストします。
7. ダッシュボードは結果をポーリングし、チェーン上に反映され次第、**Transfer confirmed**とトランザクションハッシュを表示します。これは[Explorer](/dashboard/explorer)で開くことができます。

#### @handleへの送金

**Send from QoreX**カードの受取先フィールドは、`qor1...`アドレスの代わりに`@handle`も受け付けます。この後の動作は、このブラウザからそのハンドルに以前送金したことがあるかどうかによって異なります。

- **初回**: 解決されたアドレスが全文表示され、**Confirm address**を選択しない限り使用できません——アドレスは解決された瞬間ではなく、確認を済ませた後に初めて記憶(ピン留め)されます。
- **以前と同じアドレス**: 軽い確認だけで通過します——再入力は不要です。
- **以前と異なるアドレス**: フローは強制的に停止します。以前のアドレスと新しいアドレスの両方が全文表示され——攻撃者が似せようとする箇所はまさに中間の文字なので、省略表示は絶対に行いません——アドレスが変わったという明示的な警告とともに、そのまま続行するための**意図的に目立たないスタイルの**ボタンが表示されます。

このピン留めはあなた自身のブラウザにのみ保存され、サーバーには保存されません。そのため、別のコンピューターや、ブラウザデータを消去した場合は再び「初回」として扱われます——これは意図的な仕様です。ハンドルは3〜20文字(`a-z`、`0-9`、`_`)で、特定のアドレスに紐づいているため、複数のアドレスを持つユーザーはアドレスごとに異なるハンドルを使えます。

#### MetaMaskで送金

1. MetaMaskを開き、QoreChain EVMネットワークに設定されていることを確認します。
2. MetaMask内で**Send**を選択します。
3. 受取先の`0x...`アドレスと金額を入力します。
4. ガス代を確認し、確定して署名・ブロードキャストします。
5. ダッシュボードのWalletページに戻ると、チェーン上に反映され次第、取引が履歴に表示されます(表示されない場合は更新してください)。

### 特定のレールで受け取る {#receive-mainnet}

1. **Receive**を選択します。
2. 受け取りモーダルで、セレクターからレールを選びます——**Native QOR**、**EVM**、または**SVM**。
3. モーダルには、そのレールのエンコーディング(`qor1...`、`0x...`、またはbase58)によるあなたのアドレスがQRコードとコピーボタンとともに表示されます。
4. アドレスをコピーするか、送金者にQRコードをスキャンしてもらいます。

送金者がどのレールを使っても、資金は同じアカウントに届きます——1つのアカウント、3つのエンコーディング、1つの残高です。

### 取引履歴を確認する {#history}

メインネットでは、履歴の各行に次が表示されます。

- **レールバッジ** — Native、EVM、SVMのいずれか——どのレールで取引されたかを示します。
- 一般的なラベルの代わりに、*Send*、*PQC key registration*、*contract deploy*などの**実際の取引種別ラベル**。
- 金額、時刻、ステータス、そして[Explorer](/dashboard/explorer)で開けるトランザクションハッシュ。

## テストネットでウォレットを使う {#testnet}

テストネット(`qorechain-diana`)では、ダッシュボードがテスト用ウォレットを管理するため、何も接続せずにエンドツーエンドでフローをテストできます。

### ページに表示される内容

- ウォレットのラベルとアクティブなアドレス(省略形)、ワンクリックのコピーボタン付き。
- QOR建ての**合計残高**。
- 量子耐性暗号化と接続中のネットワークを示すセキュリティパネル。
- 更新コントロール付きの最終更新インジケーター。
- 保有資産と取引履歴を表示する**Assets**タブと**Activity**タブ。

いつでも更新コントロールを使って、チェーンから現在の残高と最新のアクティビティを取得できます。

### QORを送金する(テストネット)

1. **Send**を選択します。
2. 受取先アドレス(`qor1...`)を入力します。
3. 金額と任意のメモを入力します。
4. 内容と見積もり手数料を確認し、確定します。

受取先を入力すると、保存済みの連絡先や最近使用したアドレスが候補として表示され、入力ミスを防げます。送金が送信された後、トランザクションハッシュを含む確認が表示され、[Explorer](/dashboard/explorer)で開くことができます。

### QORを受け取る(テストネット)

1. **Receive**を選択します。
2. アドレスまたはそのQRコードを送金者と共有するか、ワンクリックでアドレスをコピーします。
3. 任意で希望金額とメモを入力すると、支払いリンクとダウンロード可能なQRコードが生成されます。

### テストウォレットを管理する

**My Wallets**を選択してアドレス一覧を開きます。ここから、ウォレットの切り替え、新しいウォレットの作成、既存ウォレットのインポート、不要になったウォレットの削除ができます。アクティブなウォレットは、テストネット上のダッシュボード全体で送金、スワップ、ステーキング、その他の署名アクションに使用されるウォレットです。

## ウォレットにQoreChainを追加する {#add-network}

**Add Network**ページには、接続方法ごとに4つのカードが並んでおり、ワンクリックでご自身のウォレットにQoreChainを追加できます。

| カード | 得られるもの |
| --- | --- |
| **Native** | RPCおよびRESTエンドポイントとチェーンID(それぞれコピーボタン付き)——KeplrなどNativeレールのウォレット向け。 |
| **EVM** | すぐに使えるEIP-3085ネットワークパラメーター——ワンクリックでMetaMaskなどのEVMウォレットにQoreChainを追加。 |
| **SVM** | SVM互換のウォレットやツール向けのSVM RPC URL。 |
| **WalletConnect** | WalletConnect対応の任意のウォレットとリンクするためのWalletConnectペアリング。 |

QoreChainを追加するには:

1. ダッシュボードから**Add Network**ページを開きます。
2. お使いのウォレットのレールに合ったカードを選びます。
3. 追加ボタン(EVM、WalletConnect)を選択するか、エンドポイントとチェーンIDをウォレットのネットワーク追加フォームにコピーします(Native、SVM)。
4. ウォレットで新しいネットワークを承認します。

パブリックエンドポイントは`rpc.qore.host`(Native RPC)、`api.qore.host`(REST)、`evm.qore.host`(EVM JSON-RPC)、`svm.qore.host`(SVM RPC)で、テストネット用に`*-testnet`のバリアント(例: `rpc-testnet.qore.host`)があります。チェーンID: メインネット`qorechain-vladi`(EVMチェーンID`9801`)、テストネット`qorechain-diana`(EVMチェーンID`9800`)。

### リンク済みサイナー(Phantom) {#linked-signers}

**SVM**カードでは、Phantomの鍵を**リンク済みサイナー**としてアカウントにリンクすることもできます——これはQoreX、Keplr、MetaMaskのような独立したプライマリウォレット接続ではなく、委任された取り消し可能な支払い用オーソライザーです。登録には既存のウォレットが署名し、Phantomがそれ自体の独立したIDになることはありません。その背後にあるオンチェーンの権限・支払い上限モデルについては、QoreXドキュメントの[リンク済みサイナーと支払い上限](/qorex/security-and-recovery#linked-signers)を参照してください。
