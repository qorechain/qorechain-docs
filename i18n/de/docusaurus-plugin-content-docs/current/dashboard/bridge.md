# Bridge

Das Dashboard enthält derzeit keinen Bridge-Bildschirm. Diese Seite gibt es, damit Sie herausfinden können, was verfügbar ist und was nicht: Cross-Chain-Transfers können heute nicht über das Dashboard gestartet werden, und es gibt keine Seite `/bridge` (das Öffnen von `dashboard.qorechain.io/bridge` liefert „not found“).

:::caution Qualifizierter Status
Die Cross-Chain-Bridge selbst befindet sich noch im Testnet und wird schrittweise ausgerollt. Sie ist noch kein produktives Mainnet-System, und ihre Chain-Routen sind auf beiden Netzwerken noch ausstehend. Verlassen Sie sich nicht darauf, dass eine Route live ist.
:::

## Innovationen {#innovations}

Im Dashboard gibt es noch nichts zu nutzen, daher gibt es keine Dashboard-Innovationen aufzulisten. Wie die Chain Cross-Chain-Transfers validiert, ist unter [Bridge-Architektur](/architecture/bridge-architecture) beschrieben.

## Anleitung {#how-to-use}

Sie können im Dashboard keinen Bridge-Transfer starten. Wie Cross-Chain-Transfers funktionieren sollen, lesen Sie unter [Assets bridgen](/user-guide/bridging-assets) und [Bridge-Architektur](/architecture/bridge-architecture). Diese Seite wird den Dashboard-Ablauf beschreiben, sobald ein Bridge-Bildschirm erscheint.

## Zugang {#how-to-access}

Nicht verfügbar. Es gibt keine Route, keinen Seitenleisteneintrag und keine Anmelde- oder Netzwerkeinstellung, die ihn einschaltet.

## Wo es veröffentlicht ist {#where-published}

Nirgends im Dashboard. Auf der Badges-Seite gibt es eine „Bridge“-Badge-Serie für eine Funktion, die nicht live ist; ignorieren Sie sie vorerst.

## Grenzen und bekannte Probleme {#limits}

- Im Mainnet und im Testnet existiert kein Bridge-Bildschirm im Dashboard.
- Eine frühere Vorschau wurde zurückgezogen.
- Die Bridge ist ein Testnet- und in Arbeit befindliches System; ihre Routen sind auf beiden Netzwerken ausstehend.
