# Bridge

Das Dashboard enthält derzeit keinen Bridge-Bildschirm. Eine frühere Vorschau wurde zurückgezogen, und Cross-Chain-Transfers können heute nicht über das Dashboard gestartet werden.

:::caution Qualifizierter Status
Die Cross-Chain-Bridge selbst befindet sich noch im Testnet und wird schrittweise ausgerollt — sie ist noch kein produktives Mainnet-System, und ihre Chain-Routen sind auf beiden Netzwerken noch ausstehend. Verlassen Sie sich nicht darauf, dass eine Route live ist.
:::

Wie Cross-Chain-Transfers validiert werden, finden Sie unter [Bridge-Architektur](/architecture/bridge-architecture) und [Assets bridgen](/user-guide/bridging-assets). Diese Seite wird den Dashboard-Ablauf beschreiben, sobald ein Bridge-Bildschirm erscheint.
