# Bridge

Le Dashboard ne comporte actuellement aucun écran Bridge. Cette page existe pour que vous sachiez ce qui est disponible ou non : les transferts inter-chaînes ne peuvent pas être lancés depuis le Dashboard aujourd'hui, et il n'existe aucune page `/bridge` (ouvrir `dashboard.qorechain.io/bridge` renvoie « not found »).

:::caution Statut qualifié
Le bridge inter-chaînes lui-même est toujours en testnet et déployé progressivement. Ce n'est pas encore un système de production sur mainnet, et ses routes de chaîne sont toujours en attente sur les deux réseaux. Ne comptez sur aucune route comme étant active.
:::

## Innovations {#innovations}

Il n'y a encore rien à utiliser sur le Dashboard, donc aucune innovation du Dashboard à lister. La manière dont la chaîne valide les transferts inter-chaînes est décrite dans [Architecture du Bridge](/architecture/bridge-architecture).

## Comment l'utiliser {#how-to-use}

Vous ne pouvez pas lancer de transfert via le bridge depuis le Dashboard. Pour comprendre comment les transferts inter-chaînes sont censés fonctionner, lisez [Transfert d'actifs (bridging)](/user-guide/bridging-assets) et [Architecture du Bridge](/architecture/bridge-architecture). Cette page décrira le flux du Dashboard une fois qu'un écran Bridge sera livré.

## Comment y accéder {#how-to-access}

Non disponible. Il n'existe ni route, ni entrée dans la barre latérale, ni réglage de connexion ou de réseau qui l'active.

## Où c'est publié {#where-published}

Nulle part sur le Dashboard. Une série de badges « Bridge » existe sur la page Badges pour une fonctionnalité qui n'est pas active ; ignorez-la pour l'instant.

## Limites et problèmes connus {#limits}

- Aucun écran Bridge du Dashboard n'existe sur le mainnet ni sur le testnet.
- Un aperçu antérieur a été retiré.
- Le bridge est un système en testnet et en cours de développement ; ses routes sont en attente sur les deux réseaux.
