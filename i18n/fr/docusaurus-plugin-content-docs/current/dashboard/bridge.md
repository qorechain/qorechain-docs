# Bridge

Le Dashboard ne comporte actuellement aucun écran Bridge. Un aperçu antérieur a été retiré, et les transferts inter-chaînes ne peuvent pas être lancés depuis le Dashboard aujourd'hui.

:::caution Statut qualifié
Le bridge inter-chaînes lui-même est toujours en testnet et déployé progressivement — ce n'est pas encore un système de production sur mainnet, et ses routes de chaînes sont toujours en attente sur les deux réseaux. Ne comptez sur aucune route comme étant active.
:::

Pour comprendre comment les transferts inter-chaînes sont validés, consultez [Architecture du Bridge](/architecture/bridge-architecture) et [Transfert d'actifs (bridging)](/user-guide/bridging-assets). Cette page décrira le flux du Dashboard une fois qu'un écran Bridge sera livré.
